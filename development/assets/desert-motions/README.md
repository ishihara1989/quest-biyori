## 素材構成

| 敵 | 状態・専用動作 | 書き出しコマ | 移動 |
| --- | ---: | ---: | --- |
| サンドスコーピオン | 6 | 20 | 脚の交互移動4コマ |
| 包帯兵 | 6 | 22 | 左右3コマずつ、計6コマ |
| 砂蛇 | 6 | 20 | 蛇行4コマ |
| オブシディアンスコーピオン | 8 | 26 | 脚の交互移動4コマ |
| 黄金のファラオ | 8 | 26 | 浮遊4コマ |
| ラミア | 8 | 26 | 蛇行4コマ |
| 砂喰いベヒモス | 9 | 32 | 左右3コマずつ、計6コマ |

合計51モーション・172コマ。さらに砂の衝撃、毒針・毒液、王墓の砂魔法、地割れの4エフェクト・16コマを保存。

全敵に `idle`、`move`、`hit`、`down` がある。待機・移動はループ、被弾は復帰、撃破は最終コマで静止。休息は待機原画を再利用する。鋏と尾の毒針は別原画。ベヒモスは四足の突進と、前脚を上げて叩きつける動作を分けた。各攻撃のタイミングは本編の `DesertCombat.ACTIONS` と一致する。

## 原画・登録

`references/` は静止デザイン `../mid-late-design/v1/desert/monsters-v3.png` から切り出した7枚。追加・分割生成でも同じ基準画像を参照した。足元をセル高さの84%、胴体の中心を幅の55%に指定し、武器・尾・前脚の軌道をコマごとに設計した。

`*-generated.png` は生成原画、`generation.json` は各原画と全文プロンプトの対応。歩行は `move-1` / `move-2` の各3コマ。`reaction` の前半2コマが被弾・復帰、後半2コマが倒れる・倒れた状態。色・alphaは保持し、透明な隙間で分割、接地点を合わせ、最近傍で縮小している。

ゲーム用PNG・個別コマ・GIF・JSONは `../enemies/<id>/motions/<motion>/`、エフェクトは `../effects/desert-*/`。各JSONに原画・基準画像・プロンプトへの相対パスと発動時刻を記録。各セルの外周と武器・尾・角の見切れを検査し、確認画面でコマ送り・連続再生・最終コマを確認した。

```sh
npm run build:desert
npm run test:desert
npm run audit:desert
# npm start でサーバー起動後
npm run check:desert-ui
```

再構築は保存済み原画の機械的な切り出し・登録。原画の再生成は行わない。
