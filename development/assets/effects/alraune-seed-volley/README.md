# アルラウネの種・弾群

左向きの種25粒を3段 (8/9/8) にまとめた、透過PNG1枚の投射物です。
alraune-seed-volley.png と alraune-seed-volley-01.png は同じ320×128px。中心pivotは (160,64)。
尖った茶・金色の種に緑の葉状の尾、右側へ伸びる短い軌跡が付いています。画像全体を左へ移動させて使います。

本体のseed-burstは400msループで、0msと200msにこの画像を発射するためのイベントを持ちます。
25粒を1枚として描くため、粒ごとの当たり判定は含みません。必要な当たり判定はゲーム側で設定してください。

組み込みimage_genで生成。元原画はsource/、全文プロンプトはPROMPT.md。
プロンプトでは24粒を指示しましたが、採用原画の実際の粒数は25で、manifestも実数を記載しています。
PNGはRGBA透過、GIFは確認用。再構築は node tools/assets/build-alraune.cjs。
