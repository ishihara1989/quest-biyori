# fruit-bomb

組み込み image_gen で生成。樹の実・爆発は既存ドット絵、根はトレントの原画を画風参照に使用。

Use case: stylized-concept. Asset type: ONE single transparent pixel-art game projectile sprite, forest treant's explosive tree fruit.
Reference image is ONLY the pixel-art style of existing RPG. Subject: a compact round ochre/brown acorn-like woody seed pod, orange amber cracks indicating volatile energy, a short curved twig stem and one small dark olive-green leaf. Organic tree fruit bomb, distinctive round silhouette, no metallic body, no string fuse, no text, no explosion. Side-view 3/4 angle compatible with a left-facing tree monster. Designed to read clearly as approximately 32x36 game pixels, visible chunky deliberate pixels and a dark brown 1-pixel outline. Limited warm brown/ochre/amber and olive palette. Exactly ONE isolated fruit centered with abundant transparent margin, no duplicated variants or frames.
True alpha transparent background, opaque hard-edged sprite only. No diffuse glowing aura, no colored haze, no background wash, no drop shadow, no checkerboard, no ground, no lettering, no watermark. Not smooth vector art, not photo.
