# 泡弾

Built-in image_gen

Use case: stylized-concept. Transparent pixel-art effect spritesheet for a side-view fantasy RPG. Exactly FOUR chronological isolated frames in 2x2 equal cells TL,TR,BL,BR, at least 12% transparent margin per cell, same pixel size, palette and origin. Crisp polished 16-bit pixel clusters. One luminous cyan iridescent soap bubble flying LEFT, transparent center, pale cyan rim and tiny white glints, four wobbling flight-loop frames. Genuine transparent alpha including all interior gaps, NO checkerboard, black backdrop, haze, characters, hands, weapons, lettering or labels. The emerging body-part assets contain only the explicitly described tail/tentacle.
