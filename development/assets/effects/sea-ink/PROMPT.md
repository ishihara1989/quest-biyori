# 墨・目潰し

Built-in image_gen

Use case: stylized-concept. Transparent pixel-art effect spritesheet for a side-view fantasy RPG. Exactly FOUR chronological isolated frames in 2x2 equal cells TL,TR,BL,BR, at least 12% transparent margin per cell, same pixel size, palette and origin. Crisp polished 16-bit pixel clusters. Deep black/deep violet ink splatter cloud, frame1 compact glob, frame2 burst, frame3 swirling dark droplets with open transparent gaps, frame4 dispersing ink, no octopus. Genuine transparent alpha including all interior gaps, NO checkerboard, black backdrop, haze, characters, hands, weapons, lettering or labels. The emerging body-part assets contain only the explicitly described tail/tentacle.
