# 吸血

Built-in image_gen

Use case: stylized-concept. Transparent pixel-art effect spritesheet for a side-view fantasy RPG. Exactly FOUR chronological isolated frames in 2x2 equal cells TL,TR,BL,BR, at least 12% transparent margin per cell, same pixel size, palette and origin. Crisp polished 16-bit pixel clusters. Crimson luminous life-force ribbons streaming from LEFT x20,y50 to RIGHT x80,y50, frame1 motes, frame2 ribbons, frame3 swirling crimson orb at right, frame4 motes fade, no bodies, no gore. Genuine transparent alpha including all interior gaps, NO checkerboard, black backdrop, haze, characters, hands, weapons, lettering or labels. The emerging body-part assets contain only the explicitly described tail/tentacle.
