# 地中から出る尻尾

Built-in image_gen

Use case: stylized-concept. Transparent pixel-art effect spritesheet for a side-view fantasy RPG. Exactly FOUR chronological isolated frames in 2x2 equal cells TL,TR,BL,BR, at least 12% transparent margin per cell, same pixel size, palette and origin. Crisp polished 16-bit pixel clusters. One attackable rust-brown armored segmented worm TAIL emerging vertically from a small cracked-stone rim, attached underground at (50,84), pointed amber tip directed LEFT. Four braced swaying loop frames, same thickness/palette as Large Worm. NO head, no worm body, no extra tail, no terrain beyond tiny rim. Genuine transparent alpha including all interior gaps, NO checkerboard, black backdrop, haze, characters, hands, weapons, lettering or labels. The emerging body-part assets contain only the explicitly described tail/tentacle.
