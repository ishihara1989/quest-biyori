# アルラウネ

左向きの花型ボス。緑肌の女性の上半身が大きな赤紫の花の中心から生え、小花3輪とピンクのトゲを持つ長いツルが周囲に付いています。人の脚はなく、根で這って移動します。

素材ページ: [アルラウネ](http://127.0.0.1:4191/enemies.html#alraune)、[種の弾群](http://127.0.0.1:4191/effects.html)。

| id | 動作 | コマ | 周期 | 再生後 |
| --- | --- | ---: | ---: | --- |
| idle | 呼吸・花と髪の揺れ | 4 | 1600ms | ループ |
| move | 根を交互に伸ばして這う | 4 | 800ms | ループ |
| hit | 右へのけぞる・立て直す | 4 | 600ms | 待機へ |
| down | 花の中へ崩れ込み、花も萎れて倒れる | 4 | 1500ms | 最終姿勢を保持 |
| vine-slam | 振りかぶり・振り下ろし・地面への叩きつけ・復帰 | 4 | 800ms | 待機へ |
| seed-burst | 小花の種の発射・反動を繰り返す | 4 | 400ms | ループ |

各 motions/<id>/ に横4コマの透過PNG、個別4枚のPNG、2倍表示のGIF、manifest.jsonを保存。全24コマ。
1コマ640×384px、シート2560×384px、共通接地基準は (360,367)。通常の本体は約240px高。大きなツルの軌道に合わせて透明余白を広く取っています。

元の生成原画をsource/、組み込みimage_genに渡した全文をPROMPT.mdに保存。切り出し座標・花の中心の補正・モーション単位の共通倍率はlayout.json。最近傍サンプリングで、採用した画素のRGBとアルファを保存します。hitとvine-slamの最終コマは待機1コマ目を共有し、待機復帰を揃えています。

ツルの2・3コマ目には半透明の残像2本。PNGでは元のアルファを保持します。このモーションだけalphaCutoff=64、他の素材は192で背景の薄い生成マットを除きます。GIFは256色の確認用なので、ゲームにはPNGを使用します。

## 攻撃の発生

ツルの叩きつけは3コマ目開始、370msにvine-impactイベント。左の地面に接触するタイミングです。攻撃範囲・対象・ダメージはゲーム側で設定してください。

種の連射は1・3コマ目開始、0msと200msに弾群を1枚ずつ発射。400ms周期で同じイベントを繰り返します。4→1では待機へ戻さず、発射姿勢を続けます。

弾群は ../../effects/alraune-seed-volley/alraune-seed-volley.png。320×128pxで、種25粒を3段 (8/9/8) にまとめています。種単体の素材ではなく、画像全体を左へ移動させる用途です。中心pivotは(160,64)。

seed-burstのevents.originは本体フレーム内の推奨配置中心 (140,260)。左向きで描く場合、弾群の中心のワールド位置は (bossX + 140 - 360, bossY + 260 - 367)。弾群自体もpivotを引いて描画します。追加の種は本体PNGに焼き込んでいません。

```js
ctx.imageSmoothingEnabled = false;
ctx.drawImage(sheet, frame.x, frame.y, frame.width, frame.height,
  bossX - manifest.pivot.x * scale, bossY - manifest.pivot.y * scale,
  frame.width * scale, frame.height * scale);
```

素材ページには6種類を接続済みです。種の連射プレビューには「発射された種を表示」（初期オン）があり、小花3輪の口から左へ飛ぶ種を重ねて確認できます。
発射タイミングは0ms・200msで400msループ。25粒の弾群PNGを3段の帯として描き、それぞれの小花の口へ合わせています。口より前の部分を見せながら画像全体を左へ480px/sで移動し、1600ms後に消去します。
プレビューは左に240pxの表示余白を追加した880×384pxで、初回は1倍表示。本体素材のサイズは640×384pxです。オン／オフ、停止、コマ送り、速度変更、左右反転、待機を挟む再生に対応します。
表示中の弾群は経過時間から算出するため、停止・コマ送りで重複発射しません。manifestのprojectilePreviewとlayout.jsonに口の位置・速度・寿命を保存しています。
戦闘のAI・当たり判定・弾群の移動は今後ゲームに接続するための素材仕様です。

再構築: node tools/assets/build-alraune.cjs または npm run build:enemies -- alraune。
検査: node --test tests/alraune-assets.test.cjs。
