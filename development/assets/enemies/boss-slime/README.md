# ボススライム

既存の青い通常スライムと同じデザインを、組み込み `image_gen` で大きなボスとして制作。左向き、全6種類×4コマ＝24コマ。

プレビュー: <http://127.0.0.1:4191/enemies.html#boss-slime>。連続分裂: <http://127.0.0.1:4191/enemies.html#boss-slime/split>。

| id | 動作 | コマ | 時間 | 再生後 |
| --- | --- | ---: | ---: | --- |
| `idle` | 膨らむ・ゆるむ待機 | 4 | 1280ms | ループ |
| `move` | つぶれる・小さく跳ねる・着地 | 4 | 680ms | ループ |
| `hit` | 衝撃・右へのけぞり・立て直し | 4 | 520ms | 待機へ |
| `attack` | 右へためる・左への体当たり | 4 | 640ms | 待機へ |
| `down` | 崩れる・溶ける・水たまり | 4 | 1200ms | 最終コマを保持 |
| `split` | 膨らむ・押し出す・くびれる・ちぎれる | 4 | 880ms | ループ |

各 `motions/<id>/` に透過PNGシート、個別PNG4枚、2倍表示のGIF、フレーム情報の `manifest.json` を保存。
1コマ576×320px、横シート2304×320px。全動作の接地基準は `(288, 303)`。通常姿勢の本体は約283×157pxで、通常スライム（約85×55px）より大きい。

## 分裂と召喚

1. 0〜200ms: 左下から小さな膨らみが出て分裂を始める。
2. 200〜420ms: 小さな塊を左へ押し出す。まだ太い首でつながっている。
3. 420〜660ms: 首が細い糸状になる。まだ本体と接続している。
4. 660〜880ms: 首がちぎれ、透明な隙間ができる。本体は通常の輪郭へ戻る。

**通常スライムを実体として出すのは4コマ目を見せ終わった880ms。** `events` の `spawn-slime` は `frame: 3`（0始まり）、`boundary: "end"`、`timeMs: 880`。4コマ目の開始時刻660msとは異なる。
左向きの召喚位置は接地点から `(-218, -5)`。右向きならXを反転。召喚される素材は既存の `../slime/`。
ちぎれた塊は4コマ目だけ本体PNGに含み、次の周期の1コマ目では消える。同じ場所に通常スライムの独立した実体を出し、その後は本体と別に更新・描画する。
ループ中の発生時刻は880ms、1760ms、2640ms…、各周期に1回。フレームを表示するたびに生成せず、前回時刻と現在時刻の間でイベント時刻を越えたか判定する。時間が大きく進んだ場合は越えた周期すべてを処理する。
一連の分裂回数はゲーム側で決め、最後の4コマ目が終わった後に `idle` へ戻す。

素材ページの「分裂後の召喚を表示」は、分裂ループの終了ごとに通常スライムの移動素材を独立して描く検証用表示。停止・再開・速度変更で重複して出ないよう経過時間から算出する。「待機を挟んで再生」では待機1周期→分裂2周期→待機1周期。コマ送りの静止表示では本体素材だけを表示する。
本体のGIFにも独立した召喚後の実体は含めない。既存の1対1戦闘シーンへのボス・召喚AIの組み込みは別途行う。

## 描画

```js
ctx.imageSmoothingEnabled = false;
const frame = manifest.frames[index];
ctx.drawImage(sheet, frame.x, frame.y, frame.width, frame.height,
  x - manifest.pivot.x * scale, y - manifest.pivot.y * scale,
  frame.width * scale, frame.height * scale);
```

体当たりの衝突候補は2コマ目の開始180msに `melee-impact`。撃破は4コマ目の水たまりを保持する。
移動の跳ね上がり、被弾の右へのずれ、攻撃の左へのずれはPNGに含めてある。追加のフレームオフセットは不要。実際の移動距離や攻撃範囲はゲーム側で設定する。

## 原画と検証

生成方法は組み込み `image_gen`。参照と全文プロンプトは [PROMPT.md](PROMPT.md)、原画6枚は `source/`、切り出しと時間の仕様は `layout.json`。
原画のRGBは描き直さず、最近傍で縮小。アルファ192未満の背景にじみを除外し、残ったRGBとアルファを保持する。各動作の基準姿勢を約283px幅にそろえるため原画倍率を動作別に指定し、同一動作内では共通倍率を使う。
移動の1コマ目と被弾・攻撃の4コマ目は待機1コマ目を共用。分裂は塊の成長で本体が横にずれないよう、本体の中心を原画座標で固定する。攻撃原画の上段はセル境界が中央からずれているため、透明な隙間に合わせて列境界を設定した。
生成由来の細かな輪郭やハイライトの変化は残る。素材ページでコマ送り・ループ・待機への接続を確認できる。

```powershell
node tools/assets/build-boss-slime.cjs
node tools/assets/build-enemies.cjs boss-slime
node --test tests/boss-slime-assets.test.cjs
```

24コマの寸法・透過・余白・重複・PNGシートと個別PNGの一致・GIFの時間とループを検査。分裂1〜3コマ目の接続、4コマ目の分離、本体の大きさ、待機復帰と撃破保持、周期ごとの召喚時刻を検査する。
