Layout: exactly FOUR equally sized cells in a TWO-by-TWO grid, chronological reading order top-left, top-right, bottom-left, bottom-right. Each cell contains one complete independent pose of the SAME character at the SAME body scale. Never make a contact sheet with extra figures. Local root x=55%, virtual ground y=87%. Whole character and weapon/wing/tail tips fit within each cell with minimum 8% transparent margin, no touching neighboring cells. Facing LEFT in the same side/three-quarter battle perspective throughout.
Motion plan BEFORE drawing: All feet remain grounded y=87%. Subtle breathing/weight cycle: neutral, slight rise, neutral, slight settle; original guard and weapon retained. Fourth reconnects first.
Constraints: Actual alpha transparency everywhere outside sprites; NO drawn checkerboard, floor, background, shadow, text, labels, grid lines, panel borders, extra limbs, duplicated weapons or cropped tips. Same neutral lighting and original colors all poses. Tiny detached rune fragments only if essential. No smooth illustration or 3D shading.
