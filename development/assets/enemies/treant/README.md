# 森のボス・トレント

既存の戦士・スライムを画風参照に、組み込み `image_gen` で制作。左向きのドット絵テイスト。
プレビュー: <http://127.0.0.1:4191/enemies.html#treant>。攻撃エフェクト: <http://127.0.0.1:4191/effects.html>。

| id | 動作 | コマ | 時間 | 再生後 |
| --- | --- | ---: | ---: | --- |
| `idle` | 呼吸と枝・葉の揺れ | 4 | 1600ms | ループ |
| `move` | 根の先を交互に巻き込み、低く伸ばして這う | 4 | 880ms | ループ |
| `attack` | 枝腕を振りかぶり、左下へ叩きつけ | 4 | 680ms | 待機へ |
| `hit` | ひるむ → のけぞる → 立て直す | 4 | 520ms | 待機へ |
| `down` | 幹が割れる → 崩れる → 倒木 | 4 | 1400ms | 最終コマを保持 |
| `throw-fruit` | 構え → 下げてためる → 上へ放る → 空の手で振り抜く | 4 | 700ms | 待機へ |
| `root-bury` | 指根を下へ向ける → 突き込む → 地中へ押し込む → 維持 | 4 | 900ms | 待機へ |

各 `motions/<id>/` に `treant-<id>.png`（横4コマ）、`<id>-01.png`〜`<id>-04.png`、2倍表示のプレビューGIF、`manifest.json` を保存。
1コマ448×320px、横シート1792×320px、RGBA透過。立ち姿の本体は約230〜240px高で、既存の人型より大きいボス。
共通接地基準は `(224, 303)`。樹の実と攻撃エフェクトは `../../effects/` に独立して保存。

## ゲームへの描画

```js
ctx.imageSmoothingEnabled = false;
const frame = manifest.frames[index];
ctx.drawImage(sheet, frame.x, frame.y, frame.width, frame.height,
  x - manifest.pivot.x * scale, y - manifest.pivot.y * scale,
  frame.width * scale, frame.height * scale);
```

左向きを標準にし、右向きは接地点を基準に描画コンテキストを左右反転。倍率は整数を推奨。
本体PNGに動作の位置変化を含むため、フレームごとの追加オフセットは不要。
待機・移動は4コマのループ。移動は上半身の揺れを控え、根の先が地面をつかむように少し蠢きます。PNGはその場で再生するため、実際の移動距離・速度はゲーム側の座標で制御します。
撃破後は4コマ目で停止。ほかの単発動作は4コマを再生して待機へ戻します。

## 特殊攻撃の接続

- 枝腕攻撃: 3コマ目開始、340msに `melee-impact`。
- 樹の実: 3コマ目開始、380msに `release-fruit`。本体の1・2コマ目だけ樹の実を描き、3・4コマ目は空の手。別素材 `fruit-bomb` を出して、上への初速と放物線をゲーム側で設定。manifestの発射オフセットと初速は倍率1・左向きの仮設定。
- 根: 3コマ目開始、340msに `roots-inserted`。標的の接地点に `root-eruption` を1回再生し、伸長・最大突出のコマを攻撃判定の候補にする。本体の指根は接地線より下を切り、地面にめり込ませた見え方。

プレビューは本体とエフェクトを個別に確認する画面です。樹の実の飛行・着地やボスの戦闘判定はゲーム側で接続してください。

## 原画と再構築

全文の生成・修正プロンプトは [PROMPT.md](PROMPT.md)。生成原画は `source/` に保存し、初稿も保持。
採用版: 待機v2、投げ上げv2、移動とほかの動作はv1。移動の全文プロンプトは [motions/move/PROMPT.md](motions/move/PROMPT.md)。`layout.json` に原画・共通倍率・切り出し・接地・時間を記録。
移動は上半身の位置で各コマをそろえ、根が巻き込むときに幹まで横にずれないよう補正。
原画の薄い背景にじみを、書き出し時のアルファ閾値192で除去。残ったピクセルのRGB・アルファを保存し、最近傍で縮小。
生成由来の細かな枝・葉の輪郭差は残ります。投げ上げは同じ腕でつながるよう修正済み。

```powershell
node tools/assets/build-treant.cjs
node tools/assets/build-enemies.cjs treant
node --test tests/treant-assets.test.cjs
```
