## 動作設計と実測の区別

生成前の目標座標は全文プロンプトに記載。待機は呼吸・髪・袖・目の4段階で、4→1へ接続する。ターンは現在の正面左向きから、左側面→左後方→右後方の順に60度ずつ、計180度回す。最後は顔を見せず、背を向けて帰る。画面内で画像を平面回転・左右反転させて代用しない。

実際の待機原画は1254×1254の2×2セル、ターンは2172×724の横3セル。目標512座標を実測と扱わず、原画のセル矩形・アルファ外接矩形・登録倍率・平行移動を `registration.json` に保存する。変更前の待機の可視高さ239pxを基準に、区間ごとに固定した最近傍倍率で縮小する。ターンの髪の横広がりを本体の移動と誤認しないよう、足の軸の観察値を登録に用いる。脚や衣装の描き足し、画素消去、個別の拡縮はしない。

## 帰還の時刻

| 動作 | 本体クリップ内の開始時刻 |
| --- | --- |
| 微笑み | 0ms |
| 会釈 | 180ms |
| 手振り | 360ms |
| 側面へターン | 660ms |
| 左後方 | 840ms |
| 180度を終えて右後方、門へ移動 | 1020ms |

第1フェーズの決着は座位から接続するため、本体クリップを300ms遅らせる。どちらのフェーズもターン完了時は完全不透明。本体は1500〜1850msで消え、門は1850msから閉じ、2100msで完全消失する。勝利確定は従来どおり2200ms、報酬は1回のみ。
