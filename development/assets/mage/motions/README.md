# 魔法使いの杖・詠唱モーション

組み込み `image_gen` で生成した透過PNG。基準リファレンスは既存の待機スプライトと元デザイン。
原画・全文プロンプト・切り出し設定・個別コマ・シート・GIFを各ディレクトリに保存。全プロンプトは [PROMPT.md](PROMPT.md)。

| ID | 動作 | コマ | 再生 |
| --- | --- | --- | --- |
| attack-staff | 構え → 振りかぶり → 前へ振る → 振り抜き | 4 | 680ms・単発 |
| chant | 閉眼、髪が浮いて揺れる | 4 | 640ms・ループ |
| cast-forward | 詠唱の構え → 杖を前へ伸ばす | 4 | 400ms・前方維持へ |
| cast-forward-hold | 杖を前へ出し、髪が揺れる | 4 | 640ms・ループ |
| cast-up | 詠唱の構え → 杖を頭上へ振り上げる | 4 | 400ms・上方維持へ |
| cast-up-hold | 杖を上に向け、髪が揺れる | 4 | 640ms・ループ |

1コマ256×224px、右向き。接地基準は全モーション共通 `(128,207)`。体の高さは約139px。
上方の杖も見切れず、左右反転は接地基準を中心に行う。詠唱・維持ループの髪は上 → 外 → 下 → 戻る順。

`cast-forward` と `cast-up` の先頭は `chant` の先頭と同じPNGピクセル。
各維持ループの先頭は対応する構えの終点と同じPNGピクセル。
`layout.json` の `connectionSource` で一般のモーション再構築時もこの接続を維持する。

## 連続動作

[/mage-lab.html](../../../labs/mage-lab.html) で待機 → 詠唱 → 構え → 維持 → 杖を戻す → 待機を再生。
戻す動作は構えを逆順に再生し、詠唱の構えへ戻す。通常攻撃も振り抜き後に逆順の回復を入れる。
スロー、50ms送り、時間指定、左右反転、エフェクト切替、個別ループを確認できる。
個別コマは [/index.html#mage/chant](../../../labs/index.html#mage/chant)。

共通サンプラーは `public/js/skills/mage-motions.js`。通常攻撃940ms、詠唱を含む構えと維持は2240ms。
本編の通常攻撃と風刃は同じサンプラーを使い、戦闘の発射340ms・終了680msに時間を合わせる。攻撃速度にも連動。
発射位置は杖の青い結晶の中心。上方の動作と維持も確認ページで接続して再生できる。

## 独立エフェクト

| ID | コマ | 時間 | 描画基準 |
| --- | --- | --- | --- |
| mage-wind-bolt | 4 | 320msループ | `(190,128)`・右向き、進行方向へ回転 |
| mage-chant-aura | 4 | 640msループ | `(128,168)`・魔法陣中心をキャラ接地点へ |
| mage-wind-impact | 4 | 440ms単発 | `(128,128)`・着弾位置、最後に消去 |

各1コマ256×256px、`public/assets/effects/` に保存。本編の風の弾・詠唱・着弾はこれらのPNGを使用。
魔法陣はキャラの背面に描き、中心を空けてキャラが見えるようにする。
動きを減らす設定では魔法陣と弾を先頭コマに固定。

再構築: `npm run build:mage-motions`。検査: `npm run test:mage-motions`、`node tools/assets/check-motion-assets.cjs mage`。
