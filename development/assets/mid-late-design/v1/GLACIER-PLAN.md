# 氷河：蒼氷の聖域／氷牙マンモス

2026-10-12 JST。高原の次、地域8／通算71〜80。静止デザインと行動企画。戦闘AI・当たり判定・モーションは未実装。危険行動の予備動作・妨害値は [後半3地域の危険行動企画](../../../../docs/design/late-stage-danger-actions.md) を正本とする。

## 地域の狙い

氷河は「重い巨獣が氷の地形を砕く」景観と、妨害・自動防護で広範囲攻撃を受け止める戦闘にする。前衛に牙、後衛に氷塊、隊列全体に段階的な氷震が届く。攻撃範囲が広がることで後半入りを感じさせる。深青の氷壁、雪面、奥のオーロラを背景に、強攻撃時だけ青白い結晶とミント色の光を大きく立ち上げる。

雑魚・通常ボスは既存の6種を維持する。フロストウルフは接敵、氷殻ゴーレムは重い一撃、雪の精は後衛への冷気。フェンリルは直線跳躍、クリスタルゴーレムは扇と装甲、雪女は複数地点と短い凍結を担当する。個別の危険技・予告形状・妨害開始値は別表に揃える。

## 氷牙マンモスのデザイン

- 巨大な肩の盛り上がり、短く太い4本脚、長い鼻、2本の湾曲した氷牙。顔と牙が左へ張り出す、幅のある象の輪郭。
- 白銀の長い毛に紺の陰影。腹と足元は濃紺、牙は象牙色の根元から透明な蒼氷へ変化する。背中に大きな氷塊を3枚載せる。
- 小さく明るい青の目、丸い耳、凍った毛束。威圧感は体重と接地で出す。通常ボスのゴーレムより横に長く、狼より肩が高い。
- 本体表示の開始案は幅320px・高さ250px、足元の楕円影150×40px。戦闘空間は1024×576、接地面は概ねy=330〜500。本体の氷塊・牙・鼻を含めて画面内へ収める。
- 大技の光は牙→足→背中→鼻の順に切り替える。HP50%以下は背中の氷塊に光るひびを追加し、毛・顔・牙の形は維持する。

## 行動サイクル

登場時は雪を踏みしめて止まり、8.5秒以上の追加待機を置く。前ウェーブからのMP・防護の準備を確保する。通常攻撃は鼻の打撃または小さな牙突きで、前衛1人に当てる。

```text
100〜50%：通常攻撃2回 → 氷牙大薙ぎ → 隙3秒
         → 氷震踏砕 → 隙3秒 → 氷塊天落 → 隙3.5秒 → 戻る
50〜0% ：現在の技と休息を終える → 背の氷が光る
         → 同じ順序を1周 → 白夜の氷冠 → 隙4秒 → 戻る
```

HPをまたいだ瞬間には追加攻撃しない。白夜の氷冠は後半サイクルの末尾にだけ追加する。通常攻撃の差し込みは休息が終わってから。危険技の中断時はその技を飛ばして休息し、同じ技を即座に再試行しない。技ごとの開始間隔は、予備動作＋表の攻撃時間＋休息以上とする。

## 攻撃と演出

威力は実際の味方最大HPへ追従させず、固定のLv.80・主道装備基準から算出する。初撃・後続の被害予算は危険行動企画の共通規則を用いる。下の半径・距離は1024×576での開始案。

| 技 | 範囲・時間 | 予備動作と本体 | 発動時の見せ方 | 中断時 |

| 氷震踏砕 | 足元中心の半径160→330px、2 Hitを0.9秒ずらす、動作1.3秒、休息3秒 | 4.6秒。前脚を上げる。二重円を最初から表示し、内→外に順序印 | 踏み込みで中央衝撃、次に外周の氷柱が一斉に跳ね上がる。雪煙は低い層、中央は透ける | 上げた脚を静かに下ろす。亀裂と氷柱の予約を破棄 |

| 白夜の氷冠 | 半径180→330→450pxの3帯、間隔1.0秒、動作2.4秒、休息4秒。HP50%以下 | 5.4秒。鼻を上げ、背の氷3枚が点灯。三重輪の外周と点1〜3を表示 | 踏み込みから氷冠状の柱、次いでミントのオーロラが外へ巻き上がる。各帯で1回だけ判定。最外帯の凍結は1秒・最大2人 | 背のひびから細い光が逃げる。全帯・柱・凍結の予約を破棄 |

氷震の2 Hitは内円・外帯で分割し、同じ味方へ二重に初撃倍率を適用しない。氷塊の円は中心距離260px以上、空間不足時は数を減らす。白夜の帯は互いに重ならず、移動して別帯に入った場合も1人1回を上限とする。範囲を画面端で切った場合は、表示した輪郭と判定を同じ形へ切る。技の見た目の破片・光には追加ダメージを付けない。

冷気は移動−30%・3秒、凍結は白夜の最外帯だけ。凍結後は4秒休息し、連続強攻撃を確定で当てない。生存2人なら凍結1人まで、1人なら付与なし。解除後3秒免疫、蓄積凍結なし。浄化未使用でも自動回復・防護で立て直せることを検証する。

## 派手さと判読性

予告の紫の外周・斜線・順序印を、味方の通常攻撃光や雪煙より前に出す。発動時の中心発光は0.10〜0.15秒、画面揺れは4〜7px・0.15秒を開始案。大きな破片は判定の外へ抜け、雪煙は味方の胴体まで覆わない。敵・味方の輪郭とHP表示を最後まで残す。全画面の白塗りは使わず、外周の光と局所衝撃で強さを出す。

撃破は牙の光消失→背の氷の崩落→膝を折る→低い雪煙。最後に希少ドロップの氷牙を大きく浮かべ、細い金と青の光を一度走らせる。
