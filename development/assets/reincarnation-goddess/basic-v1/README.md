# 転生の女神：基本モーション v1

2026-10-20。**敵キャラ用の制作候補・本編未登録**。このチャットで方向性を確認した金髪・白金の衣装・青い宝石・生意気な笑顔を固定し、既存の雪女をドット絵の密度と輪郭の参考にした。異次元の女神とは別素材。

[検収画面](../../../labs/reincarnation-goddess.html) / [制作・検収記録](../../../../docs/production/reincarnation-goddess-basic-motions.md) / [全文プロンプト](PROMPTS.md)

| モーション | コマ | 時間 | 動き |
| --- | ---: | ---: | --- |
| idle | 4 | 1120 ms・ループ | 左向き、腰に手、得意げな表情。上下動・髪・袖・瞬き |
| move | 4 | 720 ms・ループ | 左向き浮遊。髪と袖が右へ流れる。歩行なし |
| hit | 3 | 480 ms・単発 | 両手を頬に当てる→涙が飛び出すギャグ調ののけぞり→涙目の不満顔 |
| return | 6 | 1320 ms・単発 | 涙目で腕組み、左→正面→右→側面→振り返り→背面。再生側で右上へ帰還 |

## 配置と再生

- references/：承認したイラスト、固定した左向きスプライト、同じ原画から切り出した顔と衣装、既存素材の画風参照。
- source/：採用候補の生成PNG。source/rejected/ は余分な手・衣装差のあった修正前原画。
- motions/：512×512の透過フレームPNG・横シート・マニフェスト。
- review/：4種のGIF、全コマ比較、測定・検収記録。GIFは検収用で本編から読まない。
- generation.json / PROMPTS.md：内蔵 image_gen の入力・参照・修正履歴。
- layout.json / registration.json：生成前の目標と区別した、原画の実測切り出し位置・腰の観測位置・固定倍率・平行移動。

腰の登録基準は (248,257)、床の仮想基準は (256,448)。浮遊のため足先を床へ固定しない。シートの等分線を髪がまたぐ箇所は、実際に透明な隙間を測って切り出す。区間ごとに一様な最近傍縮小を使用し、return後半は前半と同倍率。原画RGBAは維持し、色変更・アルファ閾値処理・手描き補完・反転は行わない。

移動量・帰還の右上移動とフェードは検収画面の再生側で扱い、原画に焼き込まない。

## 再構築

専用ワークツリーで npm ci 後、node tools/assets/build-reincarnation-goddess.cjs を実行。
画像はGit管理外なので、このディレクトリ全体を保持する。Gitだけから原画・PNG・GIFは復元できない。ブラウザ検収は npm start 後、上記画面で通常／低速・暗色／明色／透過・全17コマを確認する。
