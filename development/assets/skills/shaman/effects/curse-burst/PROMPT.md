# curse-burst

Built-in image_gen. Transparent RGBA preserved, common registration and nearest-neighbor sampling.

Use case: stylized-concept. Asset type: RPG game VFX spritesheet. Crisp detailed pixel art with hard pixel clusters, teal source magic, black violet curses and luminous ivory bone impacts. Genuine transparent RGBA background, no checkerboard painted, no text, labels, grid, ground, character or borders. Equal-width horizontal cells in ONE row. Each frame centered in its own cell with at least 8% empty margin all sides. Same framing/scale across frames. Exactly 4 animation frames. Spectacular high-level bone/violet magical rupture, four frames: tight ivory nucleus; huge jagged violet flower-shaped blast with ivory core; expanding angular purple shock ring with flying skull/bone shards; scattered teal embers. Brilliant but holes/transparency so enemies readable.
