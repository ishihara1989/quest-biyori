# curse-collapse

Built-in image_gen. Transparent RGBA preserved, common registration and nearest-neighbor sampling.

Use case: stylized-concept. Asset type: RPG game VFX spritesheet. Crisp detailed pixel art with hard pixel clusters, teal source magic, black violet curses and luminous ivory bone impacts. Genuine transparent RGBA background, no checkerboard painted, no text, labels, grid, ground, character or borders. Equal-width horizontal cells in ONE row. Each frame centered in its own cell with at least 8% empty margin all sides. Same framing/scale across frames. Exactly 3 animation frames. Spectacular purple black curse implosion gathering inward, transparent hollow center. Three frames: broad hooked rune petals; petals draw inward along teal threads; tiny brilliant ivory core with tight violet spiral. Keep envelope 80% cell.
