# grand-shatter

Built-in image_gen. Transparent RGBA preserved, common registration and nearest-neighbor sampling.

Use case: stylized-concept. Asset type: RPG game VFX spritesheet. Crisp detailed pixel art with hard pixel clusters, teal source magic, black violet curses and luminous ivory bone impacts. Genuine transparent RGBA background, no checkerboard painted, no text, labels, grid, ground, character or borders. Equal-width horizontal cells in ONE row. Each frame centered in its own cell with at least 8% empty margin all sides. Same framing/scale across frames. Exactly 4 animation frames. Ultimate giant hollow curse rune, oval ground projection, dramatically shattering into flying bone rune shards and teal-violet lightning. Four frames: intact multi-ring glyph; bright cracked rings; jagged explosion outward; scattered fragments. Empty center, no opaque background.
