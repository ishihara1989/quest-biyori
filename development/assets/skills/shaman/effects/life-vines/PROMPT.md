# life-vines

Built-in image_gen. Transparent RGBA preserved, common registration and nearest-neighbor sampling.

Use case: stylized-concept. Asset type: RPG game VFX spritesheet. Crisp detailed pixel art with hard pixel clusters, teal source magic, black violet curses and luminous ivory bone impacts. Genuine transparent RGBA background, no checkerboard painted, no text, labels, grid, ground, character or borders. Equal-width horizontal cells in ONE row. Each frame centered in its own cell with at least 8% empty margin all sides. Same framing/scale across frames. Exactly 3 animation frames. Slender black-violet spectral vines wrapping a hollow silhouette-sized circular opening. Teal veins, bone flakes fall. Loop stages curl clockwise; tightened loop; loosening again. Empty transparent center so character visible.
