## 女神の指定

全身を左へ向け、肩・胸・腰・膝・足先の向きを揃えた。銀髪ショートボブ、ダークスキン、細身の人体、3分割の軌道リング、2枚の浮遊フィンを保持。目は淡い氷紫色と白いハイライトで光沢・局所的な発光感を出し、濃いまつ毛と眉で眼力を強めた。待機中は目を開けたまま保つ。

references/outer-space-goddess.png が現在の固定参照。先行する胴体が右へねじれた版や濃い紫目の待機原画は source/rejected/ に理由付きで保持する。references/goddess-left-eye-base.png も修正前履歴で、以後の基準にはしない。

## 再構築と保全

作業ワークツリーで npm ci 後、node tools/assets/build-trial-intruder-idles.cjs を実行。原画は組み込み ImageGen で生成し、加工は実測した余白での切り出し、各敵共通倍率の最近傍拡縮、平行移動、シート／GIF化だけ。反転、色変更、アルファの閾値加工、手描き補完は行わない。原画プレビューで見える色付きの外周画素には極小アルファがあり、実際の暗色・明色・市松の合成表示で確認する。

位置合わせの観測値はアルファ領域の中心・最下点を使う代理基準であり、解剖学上の腰の実測値ではない。計画上の目標座標とは registration.json で区別する。浮遊型は位置合わせ後に計画の微小上下動を平行移動で反映し、原画に描かれた部品の動きは保持する。

npm start 後、検収画面で通常・0.35倍、全体／個別のコマ送り、3背景、基準線、全43枚を確認できる。ゲームのセーブを読み書きしない。

画像・GIFはGit管理外で、原画から生成物までこのディレクトリに保持する。Gitにはプロンプト、計画、配置、マニフェスト、ツールと検収記録を保存する。マージ・ワークツリー整理前にローカル画像を保全する。本編への敵登録・戦闘統合・公開は今回行っていない。
