# エピックジェム関連アイコン

2026-10-15制作・本編採用。内蔵image_gen、透過背景。12職別エピック（全6職×武器・防具）、被弾MP／クール回復レジェンダリー2点、エピック破片、星界の残滓、女神強化ページの計17点。

- 原画は `source/`、全プロンプト・生成元パス・本編対応は [generation.json](generation.json)。
- [全17点の一覧](review.png)、透過と余白の数値は [review.json](review.json)。
- 本編の128px透過PNGは `public/assets/ui/gems/`。固定の縮小・透明余白の追加だけを行い、原画の形や色は描き替えない。
- 再登録は `npm run build:epic-gems`。静止アイコンのためコマ検収・連続再生は不要。全17点と64〜128pxでの形・配色・透過・余白、通常幅／390pxの本編表示を確認済み。
- 星界の残滓は抽象的な紫青・金の光と空間の残響。女神は倒されずに帰還するため、身体・装備の破片にはしない。

仕様と確認対象は [実装記録](../../../../docs/implementation/epic-gems.md)を参照。
