# 予備動作・行動妨害の設計と割り当て候補

2026-10-12 JST。初回の検討用仕様を保存した文書。現在は本編へ適用済み。採用値・累積抵抗・予備動作と危険度・生成素材・検証は[実装記録](../implementation/action-interference-implementation.md)を参照する。以下の表は検討時点の候補。

[バランス方針](../policies/balance-policy.md)、[ジェムの再設計案](gem-system-design.md)、AGENTS.mdの表示方針を前提とする。回避AIの改善は今回の対象から外す。

**設計の中心**

妨害抵抗力は「毎ヒットを受け止める硬さ」、妨害抵抗容量は「同じ行動の準備中に削り切る量」。低抵抗・大容量の詠唱は多段技で、高抵抗の突進や重量攻撃は強い一撃で止める。複数キャラの削りを合算でき、呪術師は抵抗力を下げて連携を助ける。

パラディンを主担当、戦士を重量攻撃の補助、忍者を速い詠唱妨害の補助、呪術師を抵抗低下の担当とする。魔法使いは一部の雷・衝撃技だけ、巫女は初期実装では妨害0とし、霊軍進撃などへの追加を拡張候補とする。

**現状の確認**

- `paladin-skills.js` の `canInterrupt` は、大ボス以外の `chant` とボスイノシシの `windup` を対象とする。現行の敵行動ではリッチの詠唱と森のボスイノシシの突進準備が該当する。一般ボスには既に例外的な中断がある。
- `forest-simulation.js` のホーリーハンマー命中処理で、その行動プランを破棄し、350msのよろめきと最低650msの待ちを付ける。
- `enemy-control.js` の拘束・技封じ・行動停止はボス／大ボスに無効。雑魚の行動停止は、進行中の行動プランを消すのではなく一時停止する。
- 森の状態遷移、沼の `swampPlan`、洞窟・海岸の `expansionPlan`、遺跡の `ruinsPlan`、砂漠の `desertPlan` に行動管理が分かれている。後続地域まで対象にするには共通の中断窓とキャンセル入口が必要。
- 後半の多くの技は命中まで0.4〜0.6秒。現行パラディンの初回命中は、槌0.76秒、槍0.18秒、バッシュ0.52秒、ジャッジメント1.31秒、リベンジ2.60秒、終式2.48秒（ランク1・専用強化0・攻撃速度1）。大きい妨害力だけを付けても、遅い技は反応して間に合わない。
- 加入は森10後にパラディン、沼20後に忍者、洞窟30後に呪術師、海岸40後に巫女。早い地域の初回攻略に、後から加入する職の妨害連携を要求しない。

**判定式**

```text
P = そのヒットの基礎妨害力 × (1 + 0.05 × (スキルランク − 1))
    × (1 + 装備・ジェム由来の妨害力増加率の合計)
R = 行動の基礎妨害抵抗力 × (1 − 有効な抵抗低下率)
削り = max(0, P − R)
残り容量 = max(0, 残り容量 − 削り)
残り容量が0 → 現在の行動をキャンセル
```

- 表のPはランク1・補正なしの値。ランク5では1.20倍。専用強化は初期案では既存の威力・時間・範囲などだけを強化し、妨害力を自動で上乗せしない。
- 毎ヒットでRを引く。技全体の妨害力を合計してからRを1回引く方式にはしない。
- 同一行動の準備中は、全キャラの削りが同じ容量へ入る。時間回復は入れない。
- 次の行動では満容量へ戻す。通常時の攻撃で先に削ったり、前の行動の削りを次へ持ち越したりしない。
- 妨害力はHPダメージ、攻撃力、防御貫通、属性相性、会心、通常のスキル威力から独立する。高火力の通常攻撃で自動的に大ボスを止める仕様にはしない。
- 敵のR/CもHPやプレイヤーの装備へ追従させず、行動定義に固定する。後続地域の通常詠唱まで一律に高抵抗化せず、低Rの敵も残す。
- P=0の技は倍率を掛けても0。全ヒットへ固定値を加える強化は初期案から外す。これにより多段技や召喚の数で高抵抗を突破する抜け道を抑える。
- 内部では小数を保持し、判定に微小誤差対策を使う。毎ヒットを整数へ切り捨てて、表示と必要ヒット数を食い違わせない。

**行動のライフサイクル**

1. 行動開始時に、その行動の固有ID、開始時刻、中断窓、R、C、残りCを確定する。
2. 予備動作の中断窓内だけ、有効な命中による削りを受ける。
3. 容量0なら行動プランと未発動のイベント・照準警告を破棄する。キャンセルの演出は1回だけ出す。
4. 発動まで耐えたら、中断窓を閉じて残り容量を破棄する。発動・後隙は削れない。
5. キャンセル後は雑魚／一般ボス350ms、大ボス200msの短い立て直しを初期候補とする。これは当該行動の後隙であり、継続スタン付与ではない。
6. 消費した行動順と再使用時間は戻さない。既存の再使用待ちを保持し、残りが短い場合だけ最低650msへ延ばす。キャンセルした技を即座に再詠唱しない。

中断窓は敵名やモーション名から推測せず、行動定義に明示する。複合行動では、沼の `charge → breath`、海岸の `shell → spin` のような準備区間を指定する。洞窟の急降下は今は開始直後から移動するため、新たな準備区間を追加して、その区間だけを対象とする。

遺跡の連射や砂漠の連続攻撃は、最初の射出／攻撃開始で窓を閉じる。2発目・3発目の前に容量を復活させない。砂漠の突進は `warn=1400ms` で移動開始、1640msでダメージとなるため、1400msまでを中断窓とする。潜行も地中への移動開始までとする。

命中時刻が窓の終了時刻と等しい場合は発動側を優先する。60fpsの更新順だけで結果が変わらないよう、イベントの実際の発生時刻と窓の終了時刻を比較する。

既に射出済みの弾、発生済みの設置効果、召喚済みの敵は消さない。対象が死亡した場合は死亡処理を優先し、同時に中断成功を重複通知しない。

**既存の拘束・スタンとの関係**

- ボスの押し出し・打ち上げ・拘束・通常スタン無効を維持し、中断判定から `boss` / `majorBoss` による一律除外をなくす。ボスの難しさは行動のR/Cで表す。
- 雑魚の移動拘束、未来の特殊技を選択させない技封じなどは独立効果とする。
- 新しい中断対象の特殊行動を準備／実行している間は、既存の行動停止・打ち上げ・押し出しを使ってその行動の時計を止めない。準備のキャンセルは容量0の判定へ統一し、容量を削れない多段技で予備動作だけを延長する迂回を防ぐ。通常攻撃や待機中への既存効果は維持する。
- 技封じは将来の行動選択に作用し、開始済みの行動を無条件キャンセルしない。移動拘束も中断成功とは扱わない。
- 既存の制限耐性2.5秒と、新しい妨害抵抗は別に管理する。通常スタンへの耐性時間を理由に妨害力の削りまで無効にしない。
- 初期案にボスの完全妨害無効時間は付けない。妨害特化で抑え過ぎる場合の追加候補は「中断後4秒間、C×1.5、重複なし」。導入判断は実測後とする。

**ヒットの数え方**

- 命中判定に成功したヒットだけを数える。空振り、目眩ましによる失敗、無敵への接触は削らない。
- 単体技は主対象、範囲技は命中した各敵の容量を別々に削る。主対象への強い値と巻き込みへの弱い値を分けて持てる。
- 主対象の指定は発動時に固定する。途中で死亡したからといって巻き込み対象へ強い主対象値を移さない。
- 本体と分離部位は本体の同じ容量へ集約する。`castId + impactIndex + ownerId + enemyActionId` を重複防止キーにし、同じ範囲攻撃が本体と部位へ重複加算されないようにする。
- 実際に連続命中する多段は各ヒットを数える。一方、紫電連鎖・呪鎖は複数の別の敵へ跳ぶため、「連鎖数」を単体への多段数として加算しない。
- 分身の通常投擲、影写し、呪いDoT、反応追撃、反射、ジェム追撃は初期案ではP=0。持続陣も開始時に明示した妨害パルスだけを対象とする。
- 忍者の奥義終撃、巫女の霊軍進撃などを採用する場合は、明示的な妨害イベントとして許可する。既存コードでは召喚や補助効果にも `secondary` を使うため、`secondary` だけで採否を決めず、専用の `interferenceEligible` とヒット由来を持たせる。
- ダメージ0の呪術は、既存の状態効果命中判定に成功すれば抵抗低下を付けられる。DoTのダメージ発生から抵抗低下を毎回再付与しない。同じ命中に抵抗低下とPがある場合は、抵抗低下を適用してからPを判定する。

**自動戦闘での妨害技の選び方**

回避AIの改善とは別に、妨害技の選択には最低限の中断窓の参照が必要。パラディンの現行「槌で中断できる敵なら高い優先点」を、スキル共通の見積もりへ置き換える。

- 使用可能な技について、射程・実際の命中形状・初回命中時刻・飛翔時間を確認し、中断窓の終了前に当たる段だけを評価する。窓が閉じるまでに1発も当たらない技へ妨害目的の優先点を付けない。
- `窓内の各ヒットの max(0,P−R)` を合計する。容量を削り切れる技を優先し、複数ある場合は命中が早い技、必要十分な技を選ぶ。削り0の技を妨害目的では選ばない。
- 単独で削り切れなくても、削りが正なら他職との協力候補になる。パラディンは危険な特殊技への寄与を大きく評価し、戦士・忍者は本来の攻撃選択へ補助点を付ける。
- 呪術師は、抵抗低下で味方の削りが増える敵を優先する。既に最大の低下が有効なら無駄に重ねない。低下技自身が命中するまでの時間も考慮する。
- 仲間が既に放った、対象と命中時刻が明確な妨害ヒットは見積もりへ加えられる。確実な予定だけで容量が尽きる見込みなら、別の敵や通常の役割を優先する。未発動の仲間の技を完全に予測する予約AIは初期実装に要求しない。
- 進行中の味方の攻撃を途中で取り消して妨害へ切り替える処理は初期案に含めない。浄化・致死防御などの既存の緊急支援との優先順位を保ち、妨害を常に最優先にしない。

この選択処理を使わず候補値だけを追加すると、使用可能な高Lv技を選ぶ既存AIが、間に合わない大技を優先する場合がある。数値の実測では「命中した時の削り」と「AIが窓内へ命中させた回数」を分けて評価する。

**装備強化・ユニーク以上のジェム**

| 接続先 | 初期効果候補 | 取り扱い |
| --- | --- | --- |
| 武器の特別な枝効果 | 行動妨害力＋10%、＋15%、＋20%など | 既存の100ノード内で一部を置き換える。初回攻略必須にしない |
| ユニーク | 行動妨害力＋20〜30% ＋ 適合する基礎効果 | 最低レア度ユニーク。P>0のスキルを使える職へ適合 |
| レジェンダリー | 行動妨害力＋35〜45%、または予備動作への主対象一撃を強化 | 単なる高値と、条件付き固有效果を別テンプレートで比較 |
| エピック・パラディン専用 | 槌／断行槌など特定技の主対象P増幅、または重量終撃の前倒し | 既存の専用変更枠案に従う。全範囲・毎段への高P化は避ける |
| 呪術師向けユニーク候補 | 抵抗低下の効果時間＋20% | 同種最大値・低下上限35%を維持。低下率の上限突破は初期案では行わない |

通常の威力ジェムから妨害力を暗黙に増やさず、独立した効果IDを用意する。装備とジェムの妨害力増加率は加算してから1回掛ける。P0への新規妨害付与を行う場合は、別の固有效果として対象スキル・回数・予算を定義する。

妨害は今回の固定スケールではLv非依存の機能系統に置く。地域Lvが上がっただけで低抵抗の詠唱が止められなくなる設計を避ける。後に妨害スケール自体を拡張する場合は、敵のR/Cとスキル・装備の共通基準表を同時に更新する。

ジェム案の効果予算へ妨害を含め、無料の追加効果にはしない。妨害は閾値を越えると価値が急変するため、DPSの割合だけでは換算せず、妨害成功率・防いだダメージ・阻止した召喚・周回時間を測る。上の％値と必要容量は戦闘実測で確定する。

初期の強化検証は装備・ジェム合算＋100%までを重点的に調べる。これは採用済みの恒久上限ではない。無上限の重複を実装する前に、最高構成での連続中断率と上限の必要性を決める。

既存の取得コスト、100ノード構造、素材ABCの対称性、ドロップ率、初回攻略で枝・ジェム・パッシブを必須にしない方針を守る。ユニーク以上の新しい効果プールへ接続できるようにするが、ジェム生成全体の再実装をこの中断設計に混ぜない。

**表示と演出**

- 敵の予備動作中だけ、HPバーの下へ妨害抵抗容量の細いバーと盾アイコンを出す。ボスは同じ形式で大きく見せる。
- 削れた時はバーに亀裂と短い衝撃、PがR以下なら盾に小さな弾かれ演出、容量0なら盾破砕・警告消失・敵の姿勢崩れを出す。ダメージ数値と区別できる色を使う。
- 硬い行動は厚い盾、低抵抗の詠唱は薄い盾の形状を使い、色だけに依存しない。詳細は敵のマウスオーバーで「妨害抵抗力 60」「妨害抵抗容量 90」「残量 30」「予備動作 1.92秒」のように表示する。
- スキルは「行動妨害力 12 / Hit」「主対象妨害力 100」「範囲妨害力 20」「終撃妨害力 140」「妨害抵抗力 −30%」「効果時間 10秒」など効果名・数値・パラメータのみ。0の行は省略する。
- ジェムも「行動妨害力 ＋25%」「効果時間 ＋20%」などの行だけ。比較文、適用スキルの説明文章、役割の解説をツールチップへ追加しない。
- ホーリーハンマーの現行「中断 1回」は妨害力の値へ置き換える。連刃の専用強化は今後も「動作時間」表記。

**データと実装の接続案**

```text
スキル側
  interference: { perHit, primary, splash, byImpact, eligibleSourceKinds }
  interferencePowerBonus: 装備・ジェムの増加率
  resistanceDown: { rate, duration, refreshRule }

行動定義側
  interrupt: { resistance, capacity, windows, recoveryMs }

実行中の敵側
  actionInterference: {
    actionId, startedAt, windows, resistance, capacity, remaining,
    phase, interrupted, processedHitKeys
  }
```

`windows` は開始からの時刻区間。初期実装は1行動1窓を基本とし、複合プラン全体の安定した `actionId` を使う。現行の `state()` がモーション切替ごとに更新するIDだけへ依存すると、準備から本動作への遷移で容量が復活するため専用の行動IDが必要。

共通モジュールの入口は `beginAction`、`applyImpact`、`closeWindow`、`cancelAction`、`clear` とする候補。共通の命中結果へ妨害メタデータを渡すか、各職の命中成功後に同じ入口を呼ぶ。描画側で削りやキャンセルを判断しない。

各地域は共通判定を使い、キャンセル時のプラン破棄だけをアダプターで行う。砂漠の潜行深度、移動予定、ヒット済み集合、予告エフェクトも消す。ロード・ウェーブ終了・敗北・死亡で実行時状態を破棄し、セーブへ行動途中の容量を保存しない。抵抗低下も適用元と寿命を持ち、元キャラの死亡などで現行の解除方針へ揃える。

**実装する際の順序と検証**

1. 共通のP/R/C判定と、森・沼の行動窓・キャンセルを導入する。既存のホーリーハンマー確定中断を移す。
2. パラディン・戦士・忍者の候補値を付け、多段と重量一撃の差、仲間との合算、部位重複、空振りを検証する。
3. 洞窟〜砂漠の行動窓を共通化する。危険な重量技・詠唱から予備動作時間の調整を適用する。
4. 呪術師の抵抗低下、魔法使いの一部技を接続する。巫女の追加は別の選択肢として扱う。
5. 装備の特別効果とユニーク以上のジェム向け効果IDを接続し、時間や容量のUI・演出を追加する。

必要な検証は、P≤Rで削り0、毎ヒット減算、容量0で1回だけキャンセル、次行動で回復、発動済み弾の維持、境界時刻、別地域プランの消去、大ボスへの成立、部位の重複防止、DoTや分身による迂回なし、抵抗低下の非加算・寿命・上限。

戦闘評価では「準備中に当たったヒット数」「削り0になった割合」「技別の中断成功」「削りへの職別寄与」「止めた攻撃・召喚」「回避・防御が必要な残りの技」「勝率と周回時間」を集計する。予備動作延長だけの場合と、妨害を有効にした場合を分けて測る。

初回攻略は想定レベル・解放順アクティブ・当該段階または前段階メイン装備・枝／ジェム／パッシブなしで確認する。森・沼の既存バランス、および洞窟以降の大ボスに装備主道5段階遅れで敗北またはまれな辛勝となる基準を再検証する。敵HP・火力の再調整は、この仕組みの影響を測ってから行う。

採用判断として先に決める候補は、(1) 既存技への値追加だけで始めるかLv30の断行槌も採用するか、(2) 衰弱の呪いへ抵抗低下を追加するか専用技へ分けるか、(3) 巫女は初期0を維持するか命令時だけ補助を許すか。推奨する開始点は「既存技へ追加＋衰弱の呪いへ抵抗低下＋巫女0」。命中時間の検証で不足が出た場合は断行槌を優先する。
