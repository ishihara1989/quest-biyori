## 核になる見せ方

「指先であしらっていた女神が、玉座を離れ、空間そのものを動かし始める」。

第1フェーズでは味方が頑張って戦っているのに、女神は頬杖をついたまま。指を鳴らすだけで、これまで戦った女性型ボスや大ボスが現れ、代表的な大技を一度放って消える。歴代の強敵まで軽く扱う姿で、最終ボスとしての格を見せる。

第2フェーズでは体が浮き、髪・袖・天環が広がる。幻影の多彩な攻撃・状態異常から、女神自身の追尾流星と空間攻撃によるダメージへ切り替える。姿勢、動作量、輪郭、光の強さで、本気になった瞬間が伝わる構成にする。

正式名は「異次元の女神」。固有名・長い設定・新しい属性相性表は現時点で設けない。

決着では、十分に楽しんだ女神が満足げに微笑み、軽く会釈して手を振り、異次元へ帰る。姿勢を起こしたまま上昇し、1体の本体が扉の向こうへ消えてから帰還口が閉じる。脱力・転倒・天環の破砕は使わない。ゲーム上はHP0で勝利し、撃破報酬は1回だけ処理する。[帰還の制作・検収](../production/extradimensional-goddess-repair-review.md)を参照する。

## ステージ：界外の御座（仮称）

足場は広い円形の浮遊神殿。戦闘面に柱・階段・大きな瓦礫を置かない。浮遊する柱や破片は奥だけに置き、画面右側の女神、画面左側の味方、足元の予告を読めるようにする。玉座は女神側の素材に含め、背景には焼き込まない。

## 女神の形と共通デザイン

- 成人女性、銀白の長髪、薄い紫の髪の影、青い瞳。
- 白と深紺の衣装、金の縁、青い菱形の宝石、星模様の裏地。
- 左を向いた浅い斜め横視点。顔・両腕・両脚は同じ個体として維持する。
- 第1フェーズの玉座は白石・金・紺。三日月の背と環状装飾を目印にする。
- 第2フェーズの天環は羽ではなく、金の環と青い節点。玉座背面と同じ形の語彙を使う。
- 主体はドット絵。拡散光だけで輪郭を消さず、顔・手・予告は明瞭に残す。

### 第1フェーズ：気だるげな御座

頬杖と組んだ脚を基本姿勢にする。攻撃に使うのは主に頬杖をついていない腕。待機は呼吸・小さな瞬き・袖先の遅れだけ。被弾でも玉座から大きく跳ばず、目線と肩が少し動く。

通常攻撃の小さな星弾を挟み、主役は空いた手の指パッチンによる幻影の呼び出しにする。顔・頬杖・組んだ脚はほとんど動かさない。小さな動作から歴代ボスの大技が出る落差で、余裕と支配力を見せる。

### 第2フェーズ：覚醒・浮遊

目を開き、頬杖を外し、脚をほどいて上体を起こす。立ち上がりから浮遊へ移り、髪・袖が遅れて開き、天環が展開する。表情は冷静な威圧感を保つ。

浮遊中は全職の攻撃が届く。通常行動では両腕で上空に3つの星を灯し、ランダムな味方3人へ追尾する流れ星を落とす。危険技は両腕と天環を使う大きな動きへ変わる。浮遊の上下移動は描画の高さで表現し、接地点・当たり判定が床を離れて操作不能になる設計にはしない。

## 2フェーズの戦闘構成案

移行の開始案は共有HPの50%。別個体に交換せず、残HP・状態・妨害成功回数を引き継ぐ。第1フェーズ終了で撃破報酬を出さず、最終撃破で1回だけ処理する。

移行は約2.4秒の演出案。未発動の幻影・攻撃予約を解除し、発射済みの攻撃が終了したところで始める。残る星鏡が一斉に閉じて、女神の天環へ光が戻り、女神が玉座を離れる。移行中は女神からの新しい攻撃を出さず、味方の攻撃は届く。HPが0になれば撃破を優先する。長い無敵や全画面被害を移行そのものへ追加しない。

| フェーズ | 戦闘上の役割 | 見た目の主役 |
| --- | --- | --- |
| 1 / 玉座 | 控えめな被害、多彩な形状、短い状態異常 | 指パッチン、歴代ボス、各地域の大技 |
| 2 / 浮遊 | 後衛も含めた継続的な火力、妨害できる大技 | 追尾流星、女神の大きな身振り、天環と空間 |

### 第1フェーズ：星鏡の呼び出し（仮称）

ユーザー指定の「防げない」は、**呼び出しと幻影の攻撃を妨害・幻影撃破で止められず、受ける前提で調整する**方針とする。防御・軽減・バリア・攻撃弱化・既存の無敵は通常どおり適用する開始案。防御を貫通する大火力にはしない。

- 呼び出すのは各地域の女性型ボスと大ボス。1回に1体・代表技1つ。連撃型の代表技は一連の攻撃を1技として扱う。
- 姿は表示専用の幻影。敵一覧・攻撃対象・当たり判定・接触判定・移動障害・HPバーを持たず、味方のターゲットは女神へ維持する。撃破・ドロップ・召喚数へも算入しない。
- 攻撃判定を持つのは幻影が放つ技だけ。ダメージ源・状態付与元・親行動IDは女神へまとめる。元ボスのHP・火力・妨害残量・AI・報酬は持ち込まない。
- 最後の発射または直接攻撃の判定直後から、0.20〜0.25秒で姿を消す。発射済みの弾・波はそのまま届く。待機・歩行・休息を挟んで場に居残らない。
- 幻影は同時1体。指パッチンの開始間隔は7〜9秒、前の技の最終被害から次の開始まで最低1.5秒を開始案とする。長い技では間隔を延ばす。
- 各地域をランダムな順で一巡する袋から選び、その地域の女性型／大ボスをランダム選択する。同じ地域の連続を避け、片方の区分が3回以上続かないようにする。袋の一巡はフェーズ終了の条件にしない。
- 短い出現予告と攻撃の形は見せる。妨害残量バーは出さず、共通の星鏡印とツールチップ「妨害不可」で扱いを示す。

#### 低威力と状態の開始案

数値は女神戦の固定育成基準に対するHP相当であり、現在の味方最大HPへ追従させない。実装時は既存の防御・軽減を通した実測で調整する。

- 単体中心の技は1人あたり12〜18%、広い技は6〜10%から始める。連撃・継続被害・残留光も含め、1回の呼び出しで同じ味方へ合計20%相当以下を初期予算とする。元ボスの危険初撃50%を流用しない。
- 無被害の封輪などは状態だけ。毒・火傷・呪い・砂縛りは最大3秒、拘束・凍結は最大1秒。新しい状態名・属性相性は追加しない。
- 同一状態は重複しない。行動不能は最大2人、生存2人なら1人、1人ならなし。回復・防護役2人を同時に止めず、解除後3秒の行動不能免疫を維持する。
- 行動不能中や免疫中の対象に新たな行動不能を予約しない。状態解除前へ次の呼び出しの大きい被害を重ねない。制御系候補が成立しない場合は、同地域の低威力な攻撃を選ぶ。
- 後衛への呪い・継続被害と防護の停止が重なった条件も測る。浄化なしでも自然解除と自動回復で成立させる。

### 出現・消失の共通演出案：星鏡

全地域を金青の星鏡で統一し、鏡の内側では元ボスの色と輪郭を保つ。別世界の強敵を、女神が一瞬だけ取り出す見せ方にする。女神の姿勢と舞台の基準画像は変更しない。

| 段階 | 時間案 | 見せ方 |
| --- | --- | --- |
| 指パッチン | 0.00〜0.12秒 | 空いた手の指先に小さな十字光。背後の日蝕縁が一度だけ脈打つ |
| 鏡が開く | 0.12〜0.45秒 | 金の縦線が左右へ開き、青紫の星空と地域色の紋章が現れる |
| 幻影が現れる | 0.25〜0.60秒 | 足元から頭へ輪郭が満ちる。元の配色、細い金の外縁、薄い鏡片。姿を認識できる濃さを残す |
| 大技 | 0.60秒以降 | 短い構えから代表技を放つ。斧・牙・翼・掌などの起点と技FXを接続 |
| 幻影が消える | 最後の発射／判定から0.20〜0.25秒 | 輪郭に金のひび→小さな菱形の鏡片→鏡の中心へ吸い戻す。鏡も縦線へ閉じる |
| 残光 | 消失後0.15秒程度 | 小さな星が1つ消える。発射済みの技FXとは別に終わる |

共通の出現基準は舞台 P=(632,464) の案。味方と女神の顔・手を避ける位置を、本編縮尺で確認して決める。大ボスは鏡の縁を二重にして開口を広げ、低い衝撃光で重さを出す。消失を撃破モーションや報酬光と混同させず、全幻影で同じ回収の演出にする。

幻影の手前に攻撃FX、足元の予告と味方の輪郭はさらに優先する。幻影全体を真っ白にしたり、毎回全画面を暗転させたりせず、歴代の姿が一目でわかる時間を確保する。

### 第2フェーズ：三連の追尾流星（通常行動）

- 生存中の味方キャラクターから均等・重複なしで3人を選ぶ。巫女の式神などの召喚体は抽選に入れない。生存者が3人未満ならその人数だけを選び、余りの星を同じ人へ重ねない。
- 前衛・後衛を区別しない。6人生存なら各人の選択率は1回につき3/6。対象の頭上に小さな星印、上空に対応する3つの星を灯す。
- 約0.45秒の身振りで星を放ち、約0.75秒かけて弧を描きながら追尾する。3発の発射は0.15秒ずつずらす。対象IDは選択時に固定し、着弾まで対象の現在位置へ追尾する。
- 1人1発・1 Hit。爆発の見た目は大きくしても、周囲への巻き込み判定は付けない。対象が死亡・退場した星は消え、別の味方へ飛び移らない。既存の無敵・防護判定は維持する。
- 通常行動として妨害残量は持たない。位置を固定する危険技とは管理を分け、動く対象印・星の軌道・命中対象を同じIDで結ぶ。自動防護にも選択対象と予定着弾を渡す。
- 1人あたり固定基準HPの8〜12%相当、開始間隔5〜6秒を初期案とする。3発を含めて通常行動1回の予算とし、別の通常弾を同時に加算しない。連続で同じ後衛が選ばれた条件も検証する。
- 追尾流星・第2フェーズの危険技は新たな状態異常を付与しない。第1フェーズで付いた状態は残り時間で自然解除されるが、行動不能の解除前には第2フェーズの初弾を始めない。

光は青白い芯、金の長い尾、着弾時の小さな星冠で統一する。女神が左右の掌を上げて3つの節点を点灯し、下へ払うと星が落ちる。後衛にも軌道が伸びることを見て、火力の及ぶ範囲が変わったとわかる演出にする。

### 攻撃とエフェクトの対応

以下は素材設計用の仮秒数と範囲。ダメージ・抵抗力・容量・使用頻度はバランス実装時に決める。

| フェーズ / 行動 | 本体の動き | 別素材のエフェクト | 予告 → 発動 → 隙の案 |
| --- | --- | --- | --- |
| 1 / 指先の星 | 頬杖を残して空いた指を小さく弾く | 青い菱形星弾、短い金の軌跡、着弾星 | 通常攻撃。発射位置は指先 |
| 1 / 星鏡の呼び出し | 頬杖を残して指パッチン | 指先の光、星鏡、ボス幻影、既存の大技、鏡片への消失 | 約0.60秒で姿が揃う → 代表技1つ → 即回収。妨害不可・低威力 |
| 2 / 三連の追尾流星 | 両掌を上げて星を灯し、下へ払う | 対象星印、3つの星、曲がる尾、着弾星冠 | 通常行動。対象3人、重複なし・各1 Hit、状態付与なし |
| 2 / 界面断裂 | 両腕を寄せてから大きく左右へ開く | 2本の交差裂け目、開口縁、流れる光片 | 5.0秒 → 長さ700・幅100の固定帯2本、0.9秒差・1人2 Hitまで → 3.5秒 |
| 2 / 天環の裁定 | 両腕を下げ、天環を正面へ揃える | 同心の金青波、外周の菱形節点 | 5.4秒 → 半径160/280/400の帯、1秒差・1人2 Hitまで → 4秒 |
| 2 / 零界収束（大技） | 掌を胸前へ集め、頭上へ上げ、両腕を開く | 収束球、空間の縁、固定地点の光柱、崩れる星片 | 6.2秒 → 開始時に固定する半径180の円、1 Hit → 4.5秒 |

第2フェーズの危険技の位置・順序・帯の向きは予備動作開始時に固定する。第1フェーズの幻影技も形状・向き・地点を呼び出し開始時に決める。追尾流星だけは通常行動の専用追尾として対象IDを固定し、位置へ追従する。色だけに頼らず、帯は切れた縁、流星は頭上の星印、波は同心輪で区別する。天環の裁定の中心も開始時に固定し、後から女神が動いても追尾しない。

放置で楽しむゲームとして、自動支援と攻撃後の隙で立て直せる設計にする。既存の妨害は第2フェーズの危険技へ適用し、全中断をクリア条件にしない。抵抗力と容量の上昇、未発動予約の一括破棄、連撃・残留演出を含む被害予算は [危険行動の共通仕様](late-stage-danger-actions.md) を維持する。星鏡と追尾流星には危険技の初撃50%を付けず、上記の専用予算を使う。新しい育成・希少ジェム・クリック回避を必須にしない。

## 演出の優先順位

1. 床の予告と味方・女神の輪郭。
2. 顔と手、発射・着弾の瞬間。
3. 星鏡・歴代ボスの輪郭、追尾流星・天環・裂け目の主エフェクト。
