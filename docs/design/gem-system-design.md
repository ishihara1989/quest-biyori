# ジェムの地域レベル・生成・素材経済の設計案

2026-10-11 JST。ユーザー原案をもとにした検討用の仕様。2026-10-12にレジェンダリーまで実装した。[採用値・適用範囲・検証](../implementation/gem-system-implementation.md)を参照。以下は検討時点の案で、現在の採用値とは区別する。

[既存のバランス方針](../policies/balance-policy.md)を維持する。Lv.100までの初回攻略にはジェムを必須にしない。レア5%、ユニーク0.5%の絶対確率は維持し、砂漠以降のレジェンダリー0.05%は追加候補として計算する。レア度の順序はユーザー原案どおり、レア→ユニーク→レジェンダリー→エピック。

## 1. 分けて持つ4つの情報

| 情報 | 決めるもの | 初期案 |
| --- | --- | --- |
| レア度 | 効果予算・容量効率・固有效果の解放 | 上位品の収集を強化の中心にする |
| ジェムLv | 地域の基礎能力に対応する数値 | 森1、沼2、洞窟3、海岸4、遺跡5、砂漠6… |
| 系統・主効果 | 意味のあるオプションの組み合わせ | 物理、魔法、呪い、召喚、防御、回復、探索など |
| 品質 | 同じ種類の小さな数値差 | 共通係数0.95〜1.05。各数値を独立抽選しない |

キャラLv.100とジェムLv.10は別の情報。地域内の1〜10ステージは同じジェムLvとし、細かなステージ差よりレア度と効果の厳選を優先する。容量は地域Lvで増やさない。同じ良品をアップグレードして使い続けられる。

アップグレードは個体ID・レア度・主効果・オプション・品質・容量を保持し、Lvに依存する数値だけを更新する。再抽選しない。Lvに依存しない効果しか持たない個体は、性能上のアップグレード対象にしない。

## 2. 容量を100倍の整数単位へ

現状の容量1を100、典型的なレアの容量2を200にする。攻撃・物理・魔法・防御・補助・共通容量はすべて同じ倍率で移す。容量ボーナスの+1も+100。

現状は容量2から割引1で半額になり、地域ごとの取得数ボーナスによる割引も加算される。新案では対象方向の必要容量を割合で減らす。

```text
割引倍率 = max(0.60, Π(1 − 各割引率))
方向別必要容量 = ceil(その個体の同方向の基本容量合計 × 割引倍率)
共通容量使用量 = Σ方向 max(0, 全装着ジェムの方向別必要容量 − 方向別保有容量)
```

たとえば200→180（10%）、200→162（10%を2回）。加算で20%にしない。既存の地域ごとの割引取得は、10%ずつ・合成後最大40%を出発点として再評価する。40%は未検証の調整値。

複合効果を方向へ配分してから、**同じジェムの同じ方向をまとめて1回だけ切り上げる**。効果ごとの切り上げはしない。共通容量は不足分の合計を払う既存方式を維持する。割引の対象は装備・キャラの得意な方向で、MP消費軽減とは別。

## 3. 固定値を地域基準から作る

### 3.1 1種類ずつ手で決めず、効果の換算器を作る

基準は、その地域の終盤レベル・メイン装備のみ・ジェムなし・枝なし・パッシブなしの固定ビルド。各地域の基準表を生成して保存し、装着者の現在能力には追従させない。敵もプレイヤーへ追従させない。

最初の計算例では、容量200のレア1つを「対応軸の約8%」とする。これは説明用の出発点で、すべての効果が8%になる仕様ではない。

```text
攻撃力増加 = 地域基準攻撃力 × 0.08 × 効果予算 × 品質
最大HP増加 = 地域基準HP × 0.08 × 効果予算 × 品質
防御力増加 = (K + 地域基準防御力) × 0.08 × 効果予算 × 品質
```

最後の式は現行の軽減式K/(K+防御)、K=80に対して、固定被害条件で実効耐久を8%増やす換算。防御力そのものの8%ではない。[比率による防御式の案](balance-formulas.md)を適用する場合はKを基準敵攻撃力×換算係数へ置き換える。

現行の戦士・地域終端メインのみの実測基準では次の初期値になる。共通ジェムの説明用基準を戦士に固定した例で、採用時には全6職の差を検証する。

| 地域／ジェムLv | 基準攻撃力 | 攻撃ジェム | 基準HP | HPジェム | 防御ジェム |
| --- | ---: | ---: | ---: | ---: | ---: |
| 森／1 | 108 | +9 | 984 | +79 | +8.2 |
| 沼／2 | 207.5 | +17 | 1,729 | +138 | +10.4 |
| 洞窟／3 | 334 | +27 | 2,660 | +213 | +13.4 |
| 海岸／4 | 487.5 | +39 | 3,777 | +302 | +17.0 |
| 遺跡／5 | 668 | +53 | 5,080 | +406 | +21.4 |
| 砂漠／6 | 875.5 | +70 | 6,569 | +526 | +26.4 |

攻撃力+9の森ジェムは、砂漠で新しい攻撃ジェム+70へ置き換えるか、素材を使ってLv.6へ上げる。後半の装備成長率を変更しても、基準表を作り直せばジェムを一括調整できる。

物理・魔法の特化も、常に現在攻撃力へ同じ割合を掛ける方式にするか、対応する固定攻撃力を足す方式にするかを統一する。旧地域品がいつまでも同じ率で強い問題を解く目的には、**地域基準から作る固定増加量**が適する。物理特化は物理成分、魔法特化は魔法成分へ1回だけ反映し、召喚・DoTへの二重適用を避ける。

### 3.2 単位が違う効果は実測で換算する

「攻撃+8%とMP回復+8%が同価値」とはしない。MP回復、速度、会心、回復、バリア、範囲などは、候補値vを入れたときの固定ビルドの変化から求める。

```text
火力予算 = log(DPS(v) / 基準DPS) / log(1.08)
耐久予算 = log(EHP(v) / 基準EHP) / log(1.08)
```

単調に増える効果は二分探索で「割り当て予算に収まるv」を求める。AIの選択変更、MPの枯渇、再召喚などで単調性がない効果は、候補値のグリッドを試し、条件を満たす範囲から選ぶ。初期値生成の換算器は効果ごとに用意するが、各地域・各個体の数値を手入力する必要はない。

火力・耐久・探索を無理に1つの点数へ潰さない。複合品は予算を各軸へ配り、最終的な火力と耐久を両方検査する。範囲は単体・通常配置・密集、MP回復は短期・長期、支援は6人全体で評価する。回復+防御のような相乗効果も完成品で検査する。

Lv.100までは基準表をメイン装備成長から作れる。Lv.100以降に装備とキャラ成長が止まるなら、別途「到達深度ごとの基準攻撃力・耐久」の表を固定生成し、ジェムLvをその深度へ対応させる。固定値をLv.100の能力からずっと作ると、再び成長が止まる。

既存文書の「ジェム最終倍率1.5倍」は未実装の提案。Lv.100以降の主な成長手段にする場合、全期間に固定1.5倍の天井を適用する案は更新が必要。成長可能な基礎数値と、速度・拘束・軽減などの上限を分ける。

### 3.3 Lvに依存しない効果

範囲・再使用回復速度・トレジャーハント・追加弾・貫通・契約枠などは、地域Lvで伸ばさない。威力付き追撃は「攻撃力参照の係数」、吸収・回復は「参照値と上限」を持つ。係数は固定でも、攻撃力の成長に従って威力が自然に増える。

単純なクールダウン−10%は、複数装着で0へ向かうため基本形にしない。

```text
再使用時間 = 基本再使用時間 / (1 + 合成再使用回復速度)
```

速度・範囲・クリティカル・軽減は、軸ごとの加算／乗算と最短時間・上限を先に決める。例としてジェム由来の再使用回復速度+60%、範囲+60%、直接軽減40%などから検証を始めるが、これらは最適解や採用値ではない。上限の対象はジェムだけか全効果合算かを実装前に明文化する。

## 4. レア度の基本予算と容量効率

まず純粋な数値複合の比較基準を作る。

| レア度 | レア換算の効果予算 | 代表基本容量 | 下位2個との関係 |
| --- | ---: | ---: | --- |
| レア | 1 | 200 | 基礎効果1個 |
| ユニーク | 2×1.15 = 2.30 | 340 | レア2個より効果15%増・容量15%減 |
| レジェンダリー | 2×2.30×1.12 = 5.152 | 580 | ユニーク2個より効果12%増・容量約15%減 |
| エピック | 効果ごとに評価 | 仮700〜850 | 専用効果の予算を先に取り、残りへ基礎効果を配分 |

品質0.95〜1.05なら、最低品質ユニークの予算2.185は最高品質レア2個の2.10より高く、最低品質レジェンダリー4.8944は最高品質ユニーク2個の4.83より高い。同じLv・同じ効果構成での比較であり、敵との相性や異なるLvまで優劣を保証するものではない。

純数値ユニークは各基本効果へレアの1.15倍、レジェンダリーは1.15×1.12倍を割り当てる。同一効果が重複したら1行へ統合する。上位の数値だけを弱くする再調整は避ける。完成品の相乗効果が予算を超えた場合、組み合わせの除外・専用の容量補正などを使い、下位2個を上回る条件も再確認する。

固有效果を追加で無料付与しない。たとえばレジェンダリー固有效果に2.0予算を割り当てたら、通常オプションへ使えるのは3.152。専用効果品は純数値品と全場面で同じ序列を保証せず、その戦い方で強いものにする。

容量は個体の合計容量を、効果の予算比で各方向へ配分する。ユニークの攻撃+MP回復を均等予算にするなら攻撃170・補助170。同じ総予算で効果数を増やしても強くならず、容量も増減しない。品質は容量を変えない。容量と数値を同時に好条件へ再抽選しない。

## 5. オプションは「主効果→適合する副効果」で生成する

全オプションを均等に混ぜると、無意味な複合と組み合わせ爆発が起こる。固有效果そのものは設計した小さな部品集とし、種類・副効果・数値をランダム生成する。

### 5.1 生成する構成

| レア度 | 初期の生成構成 |
| --- | --- |
| レア | 基礎効果1個。容量埋め用に小型も生成可能 |
| ユニーク | 基礎効果2個の強化複合、または固有效果1個+基礎効果1個 |
| レジェンダリー | レジェンダリー固有效果1個+基礎効果2〜3個 |
| エピック | キャラ・スキル変更の専用効果1個+基礎効果3〜4個 |

前節の「レジェンダリー=ユニーク2個分」は強度・容量の比較基準。固有效果を必ず付ける生成案では、その予算を含めて同等以上の価値になるよう換算する。純数値4効果モードも追加できるが、必ず固有效果を付ける方針とは別の選択肢。

ユニークの複合型は「複合増幅と容量圧縮」がレアにはない性質。固有效果を全高レアで必須にする場合、複合型もその性質を持つテンプレートとして扱い、レジェンダリー・エピックは専用の効果枠を保証する。

### 5.2 効果の定義に持たせる情報

```text
id / 最低レア度 / 方向 / 系統タグ / 適用対象タグ
使えるキャラ集合 / 必要なスキル能力 / 排他グループ / 禁止する相手
Lv依存か / 数値換算器 / 最小・最大値 / 予算
重複ルール / 発動イベント / 内部再使用 / 派生攻撃の発動権
```

例：物理攻撃、魔法攻撃を`damage-specialization`の排他候補へ置く。共通の基礎攻撃力は別であり、「共通攻撃力+魔法特化」は有効。忍者などの混成ビルドへ両特化を出したい場合は、専用のハイブリッド系統を明示的に追加し、両方を使う固定ビルドで予算を測る。

### 5.3 生成手順

1. ドロップ源からレア度・地域Lvを確定する。
2. レア度に応じた主効果／固有效果を重み付き抽選する。
3. 主効果を使えるキャラ・ビルドの集合を求める。エピックはキャラもここで確定する。
4. 候補副効果について、禁止ペア・排他グループ・重複を除外し、全効果を有効利用できるビルドが1つ以上残るものだけを候補にする。
5. 残った候補から、主効果と関連するものを優先して必要数を抽選する。HPやMP回復などの汎用候補を少量残し、同じ組み合わせへの固定を避ける。
6. レア度の予算を配り、共通品質1回と換算器から数値を作る。副効果の数だけ予算を増やさない。
7. 方向別容量を配分する。完成品の成立・数値上限・相乗効果を検査する。失敗時は回数上限付き再抽選、最後は検証済みテンプレートへ戻す。
8. 生成済み効果・品質・参照表の版を個体へ保存する。ロードや着脱で再抽選しない。

「攻撃タグとHPタグの交差がないから除外」のような単純なタグ交差では、攻撃+HPまで消してしまう。必要なのは**全効果を使えるキャラ／ビルド集合**と、個別の禁止ペアの両方。

有効例：物理攻撃+会心、スキル威力+MP回復、HP+防御、呪い+持続時間、召喚+回復、バリア+防御。除外例：混成系統以外の物理特化+魔法特化、通常攻撃限定+スキル限定の同一主効果の変更、対応行動が存在しない反撃や連鎖、同じスキルの相互排他的なエピック変更。

小型レアは容量50〜100、効果予算も同比率にする。小型だから効率がよい仕様にしない。高レアだけで容量の大部分を使い、残った細かな容量をレアで埋められる。

## 6. 解体・合成・アップグレードの費用生成

遺跡最終クリアで解体・合成を解放する案。地域Lvは、その地域を解放／到達した範囲まで。上位破片への変換は対応レア度の解放以降にする。砂漠前からレジェンダリー装備を作る抜け道を作らない。

### 6.1 解体と変換

```text
標準解体破片 D(L) = 10 × L
下位破片10 → 上位破片1
小型・低予算品の解体量 = floor(D(L) × その個体の基準予算比)
```

レア度ごとに別の財布を持つ。同じLvの標準品はレア10L、ユニーク10L、レジェンダリー10Lのそれぞれの破片へなる。Lv.1は10、Lv.6は60。品質は解体量を変えない。同じレア度・Lvでも小型品を標準品と同じ量で解体しない。

10Lは最初の生成値。旧地域の高速周回が最善になった場合は、基準ビルドの「安定して倒せる対象ボス数/時間」Kを使い、後続地域の破片産出を補正する。

```text
D(L) = 10単位へ切り上げ(max(10L,
          1.15 × max旧地域(D(j) × K(j)) / K(L)))
```

同じレア度の確率が地域で同じ場合の式。異なる場合はKに確率も掛ける。Kは一番効率のよい安定周回ルートで測り、到達時と育成後の両方で古い地域への逆戻りを検査する。補正表は固定保存し、個人の周回速度で解体量を変えない。以下の費用はD(L)へ追従させるので、補正しても「同地域何個分」は維持できる。

### 6.2 合成：合計価値は同レア10個分

```text
合成予算 F = 10 × D(L) × 個体の基準予算比
自レア破片 = ceil(F × a)
1段下の破片 = ceil(F × (1 − a) × 10)
a = 0.60 + 0.40 × 固有效果が占める予算比
破片の流量換算周数 T = F / (D(L) × 1周の対象ボス数 × 下位変換込みの破片相当確率)
地域レア素材 = 5単位へ切り上げ(min(100, 0.5T) × 基準1周の期待レア素材数)
```

レアは下位ジェム破片を要求せずa=1。純数値複合はa=0.60、固有效果しかない品はa=1。混合品は間を取る。解体10個分より安くせず、固有效果のない複合型は下位の破片も吸収できる。小型品は合成費用も同比率にし、素材収支を再検査する。

素材だけが合成の主な負担にならないよう、破片を集める流量換算の半分、最大100周分を地域レア素材へ割り当てる。ボス4体の基準ならレアは25周分を切り上げて素材10個、ユニーク以降は上限100周分で30個になる。

| 地域Lv.6の標準品 | 合成要求例 |
| --- | --- |
| レア | レア破片600 + 砂漠レア素材10 |
| 純数値ユニーク | ユニーク破片360 + レア破片2,400 + 砂漠レア素材30 |
| 純数値レジェンダリーの比較用レシピ | レジェンダリー破片360 + ユニーク破片2,400 + 砂漠レア素材30 |

下位レア度の材料は、その下位の標準ジェム40個分。360+2,400/10=600で、上位破片だけの600と同じ価値。**ユニーク6個+レア4個ではない。** 固有效果付きレジェンダリーの実レシピはa>0.60になり、この表より上位破片の比率が高い。

合成では主効果／系統を選び、その主効果を保証する。エピックはキャラと専用効果を選べる案。副効果・品質は通常抽選と同じ。完全ランダムなもう1個を10個分の費用で作るだけでは、特定効果が出ない救済になりにくい。最高品質の保証はしない。

なお、Dと合成費用だけでなく、各主効果の抽選重みも管理する。全体ドロップの10個分は、狙う主効果の確率が10%ならその主効果1個の平均待ちに相当する。合成は狙いを絞るために使う。

### 6.3 アップグレード：同地域品約3個分＋クリスタル

```text
Lv a → b の標準破片要求 = 3 × Σ(l=a+1…b) D(l)
必要クリスタル = 5単位へ切り上げ(20周 × 目標地域の1周期待クリスタル数) × (b − a)
```

基準1周がボス4体・クリスタル期待1.9個なら1段階40個。レアLv.1→2はレア破片60+沼クリスタル40。Lv.5→6は同レア破片180+砂漠クリスタル40。飛び級は各段階の破片費用を合計し、目標地域のクリスタルで支払う。旧地域クリスタルの取り直しを必須にしない。

Lvに依存する効果予算の割合gが小さい混合品は、破片費用へmax(0.35,g)を掛けて切り上げる案。全効果がLv非依存なら性能アップグレードは不要。小型品は基準予算比も掛ける。

最後に必ず `アップグレード費用 > 解体量の増加分` を検査し、破片を増やすための強化・解体を禁止する。合成後の解体、上位変換を含む各閉路も材料収支が負になることを確認する。飛び級・端数・小型品でも同じ検査を使う。

## 7. 0.05%と破片変換が作る周回量

召喚援軍を除く基本編成の対象ボス4体を1周とする。現行の地域最終ステージはこの条件。砂漠レジェンダリーを追加する場合、排他的な絶対確率をレア5%、ユニーク0.5%、レジェンダリー0.05%とし、合計5.55%。下位の既存確率を削らない。

| レア度 | 1個の平均待ち | 95%が1個以上拾うまで | 10個分の破片を自レアだけで集める期待量 | 下位変換も使う破片の流量換算 |
| --- | ---: | ---: | ---: | ---: |
| レア | 5周 | 15周 | 50周 | 50周 |
| ユニーク | 50周 | 150周 | 500周 | 約250周 |
| レジェンダリー | 500周 | 1,498周 | 5,000周 | 約1,667周 |

平均は「ボス1体に対する確率pなら1/(4p)周」。95%は `ceil(log(0.05)/(4×log(1−p)))`。平均には最終周の端数があり、整数の初回獲得周数の期待値は `1/(1−(1−p)^4)`。レジェンダリーでは約500.4周。

下位変換列は**現在地域で全対象ジェムを解体し、ロスなく破片を振り分けられると仮定した平均流量の目安**。必要量を初めて満たす期待停止時刻や保証周数ではない。残す良品、離散的な10対1変換、混合レシピの材料不足で実際は増える。

```text
ユニーク相当の破片流量 / D = 0.005 + 0.05/10 = 0.01 / 対象ボス
レジェンダリー相当 / D = 0.0005 + 0.005/10 + 0.05/100 = 0.0015 / 対象ボス
```

砂漠の主効果10%を狙うと、直接ドロップの平均は約5,000周。主効果指定の合成は、何も出なかった期間に下位ドロップからも進捗を作れる。一方、変換は直接入手以外の上位供給でもあるので、0.05%の希少性を評価するときに供給の合計を数える。

エピックの確率は未決定。レジェンダリーからさらに10対1を続けるなら、エピック直接確率を決める前に下位変換経由の供給を計算する。

初期レシピを2,000試行ずつ、離散的な破片変換と地域レア素材も含めて検算すると、全解体・主効果指定の合成はレア平均約52周、複合ユニーク約261周、比較用の純数値レジェンダリー約1,693周。レジェンダリー固有效果へ2.0予算を使う例は約1,705周。実際に良品を残す場合はさらに長くなる。これらも戦闘時間ではなく周回数の検算である。

トレジャーハントはユニーク限定候補。パーティー単位で効果を集計し、各キャラで同じ報酬を再抽選しない。ジェム各レア度・地域レア素材の**基本確率へ同じ倍率を1回だけ掛ける**。レジェンダリー0.05%に+20%なら0.06%であり、20.05%ではない。破片変換・合成・確定素材・経験値には掛けない。ジェム抽選の合計確率が1を超えない上限も検査する。

## 8. レジェンダリーの効果候補

数値はパラメータ化する。発動条件・係数・対象上限・内部再使用は最初から定義する。表は効果部品の候補で、全種類を実装する決定ではない。

| 効果候補 | 起きること | 予算・制約の要点 |
| --- | --- | --- |
| 残響 | スキルの直接命中後、威力を落とした追撃 | 元動作につき1回。追撃から再発動しない |
| 連鎖 | 直接攻撃から近くの敵へ跳ねる | 跳躍数・距離・減衰。単体相手にも有効かを区別 |
| 貫通 | 弾が複数の敵を通る | 貫通数・同一対象1回。多段技との相乗効果を測る |
| 蓄勢 | 使用待ちの間に次の一撃を強める | 最大蓄積・上限時間。全スキルへの独立蓄積を避ける |
| 撃破循環 | 撃破で残り再使用時間を回復 | 動作ごとの発動数・秒あたり上限。大ボスでの低価値を許容 |
| 会心連動 | 会心で短い自己強化 | 自己強化の重複と稼働率を制限 |
| 守勢反撃 | 防御・バリア吸収の成立後に反撃 | 防御イベントの単位を定義。反撃から再発動しない |
| 余剰回復 | 余った回復を小さなバリアへ変換 | HP比上限・寿命。既存バリアと加算するか明記 |
| 呪い反応 | 呪い対象への直接攻撃で追加ダメージ | 呪術師の既存追撃上限へ統合。DoTは再発動しない |
| 霊獣共鳴 | 本体と召喚の連携で短い強化 | 本体動作1回を単位にし、召喚数だけ抽選を増やさない |
| 覚悟 | 再使用を遅くして威力・範囲を増やす | 単体DPS・MP効率・範囲火力をまとめて測る |

攻撃系の派生イベントは `secondary=true` 相当で元攻撃と区別し、派生からジェム・分身複写・吸収・別追撃の抽選を起こさない。複数ジェムが同時に元攻撃へ反応する場合にも、1動作・1秒あたりの合計予算を設ける。ヒット数が多い技だけが抽選回数で圧勝しないようにする。

## 9. エピックの専用効果候補

専用効果は1個だけ生成し、同じ専用効果は重複させない。副効果はそのキャラが使えるものから抽選する。複数エピック装着の可否は、まず「キャラごとにスキル変更枠1つ」で検証する案。これは高レア全体への個数上限ではない。

| キャラ | 専用効果候補 | 検証ポイント |
| --- | --- | --- |
| 戦士 | 連刃の終撃が衝撃波へ変化／斬撃後に短い剣気を残す | 同一対象の重複・通常連撃との合計火力。専用強化は「動作時間」表記 |
| 魔法使い | 連鎖弾が終端で小爆発／設置魔法が追従する領域へ変化 | 単体と密集時の差・設置の多重発動 |
| パラディン | 守護領域を自身へ追従させる／防御中に受けた攻撃を蓄積して解放 | 全員への永続保護・回復・反撃を同時に無制限化しない |
| 忍者 | 分身が投擲を時間差で再現／帰還する風魔が短い周回へ変化 | 分身総数・同一対象ヒット上限・複写からの再複写 |
| 呪術師 | 呪印消費後に一部を残す／呪爆が近隣へ弱い呪印を渡す | 消費技の連発・寿命継承・既存の追撃上限 |
| 巫女 | 攻撃契約上限2→3／回復か補助の契約枠を1つ追加する択一 | 契約枠は召喚個体数ではない。AI・再召喚・支援の稼働率も調整 |

巫女の現行制限は攻撃契約2種、回復1種、補助1種。狐3体など「1契約から出る個体数」とは別。枠解放は全役割をまとめて無制限にせず、攻撃・回復・補助のいずれかを指定する。契約1つ追加の価値は単純に+50%とは限らず、MP・寿命・AIの発動選択を含めて測る。

専用の挙動は設計が必要だが、1挙動×副効果の抽選×品質×地域Lvで多数の個体を作れる。完全ランダムな文章・トリガーの連結より、検証済みの部品を組み合わせる方が無意味な個体を排除しやすい。

## 10. 実装前に調整する少数の係数と検証

手で設定するのは「レア1単位の目標効果」「レア度の予算倍率」「容量圧縮率」「品質幅」「固有效果の予算」「解体・合成・アップグレードの個数換算」「地域素材の周回換算」「主効果の出現重み」。個体と地域の値はここから生成する。

検証の順序：

1. 現行6地域の基準表からレアの数値を作る。全職でDPS・EHP・MP消費、序盤の相対価値が崩れないか確認する。
2. 同じ構成・同Lvで、最低品質の上位品が最高品質の下位2個より高い数値・低い容量になることを検査する。
3. ランダム品を大量生成し、禁止組み合わせ、空の適合キャラ集合、同方向の容量端数、予算超過がないことを検査する。
4. 基本編成・固定ビルドの周回時間から、破片・素材の時間供給を求める。旧地域への逆戻りが最善にならないか検査する。
5. 合成・解体・飛び級・小型品・上位変換の材料収支を検査する。変換の端数は財布に残し、捨てない。
6. 固有效果を単体・密集・長期・大ボス・6人支援で計測する。最強品の組み合わせと、希少効果なしの攻略可能性を別々に確認する。

ゲーム内の効果表示はAGENTS.mdどおり、効果名と数値・パラメータのみ。例は「攻撃力 +70」「再使用回復速度 +15%」「攻撃契約上限 +1」。この文書の比較解説や生成ルールをジェムのツールチップへ追加しない。

数式と現行基準値の再確認：`node tools/balance/audit-gem-design.cjs`。[計算結果](../../output/balance/gem-design-audit.json)。これは経済・数値の初期案の検算であり、本編での戦闘効果の実測検証ではない。
