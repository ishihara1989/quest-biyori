# 氷河・火山・魔王城の危険行動と妨害企画

2026-10-12 JST。砂漠は実装済み、高原は素材制作中のため、本書の対象は地域8〜10／通算71〜100。戦闘への登録前の開始案であり、表の数値は実測済みではない。既存の [行動妨害実装](../implementation/action-interference-implementation.md) と `public/js/combat/action-interference.js` を引き継ぎ、地域ごとの新しい妨害ルールは追加しない。

## 共通仕様

通常攻撃は短く、妨害の対象は表の危険行動だけにする。雑魚の危険技は予備動作2秒以上、ボス・大ボスは3.8秒以上。発動までの長さを本体の溜め・氷や炎の凝集・残量バーで読ませる。途中に装飾光を出しても、予備動作終了前に被害を発生させない。

```text
1 Hitの削り = max(0, スキルの妨害力 − 有効抵抗力)
個体の抵抗力 = 表の基礎抵抗力 × (1 + 0.25 × 成功中断回数)
個体の容量   = 表の基礎容量 × (1 + 0.15 × 成功中断回数)
```

現在の実装どおり抵抗低下は最大35%、妨害抵抗貫通は最大40%。通常攻撃・継続被害・巫女支援には妨害力を追加しない。中断回数は個体共有で、技を変えても継続し、HPフェーズ変更でリセットしない。上限・時間減衰なし。新しい個体では0へ戻る。

照準・向き・円中心・本数・着弾順は**予備動作開始時**に固定する。残量が0になったら、まだ発動していない弾・範囲・召喚・装甲・状態異常の予約を全て破棄する。発動済みの弾を通常スタンで消す処理は追加しない。開始と同時に複数の攻撃予約を1つの妨害残量へ結びつけ、初弾だけ消えて後続が残る不整合を防ぐ。

中断時は0.2秒（大ボス）／0.35秒（その他）の怯み演出の後、表の休息へ進む。これは追加の行動不能時間ではなく再行動待ち。再使用待ちは巻き戻さない。別の危険技への即時切替・中断された技の即再試行はしない。通常ボスは開始から予備動作＋9秒以上、雑魚は予備動作＋5秒以上、大ボスは予備動作＋攻撃時間＋休息以上を空ける。

初撃の被害は固定の育成基準に対し雑魚10%、ボス・大ボス50%相当を開始値とする。実際の防御・軽減・バリア・攻撃弱化を適用し、味方の現在最大HPへ追従しない。後続は通常ボスが合計20%、大ボスが合計60%相当の予算内、後続単発40%以下。同一パーティーメンバーに最大予算を全部配ることを目標にせず、形状・着弾間隔・再命中上限と合わせて調整する。危険行動ごとに最初のヒット番号を振り直して50%を重ねない。継続被害・残留床も同じ行動の予算へ算入する。

表の「無被害」の封輪・睡眠・沈黙、装甲と召喚には危険初撃の被害を付けない。攻撃と同じ妨害開始・予約破棄の管理を使い、被害イベントを持たない技として実装する。

妨害が成功し続けない長期戦でも、自動防護・回復・攻撃後の隙で成立させる。全予告を中断する攻略条件にはしない。広い技を妨害できた喜びと、止め損ねても立て直す余地の両方を作る。

## 表の読み方

範囲は1024×576の戦闘空間での開始案。帯の「幅」は全幅。扇・帯・複数円の描画とダメージ判定は同じ形状データから生成する。予告には色だけでなく外周・斜線・点による順序を付ける。抵抗力R・容量Cは技ごとの基礎値。★は地域の大技。

## 妨害の役割と進行

低抵抗の弾・術式は忍者の連射を活かし、高抵抗の踏みつけ・斧・魔腕はパラディンと戦士の重い技、呪術師の抵抗低下で削る。職業が違っても回復・防護で受ける経路を残す。表の高抵抗値だけを地域に合わせて増やし続けず、範囲・手順・人数・演出で難化させる。

地域内1では短帯か小円1つ、2〜4で低抵抗と高抵抗の違い、5で多人数の雑魚戦、6〜9で複数地点と危険行動の選択、10で大ボスを扱う。雑魚の危険予告は同時2体まで、初回開始を1.5秒以上ずらす。地域1・5は同時1体までとして、入口・素材集めの容易さを維持する。複数通常ボスは別ウェーブに置く。

## 実装時の受け入れ条件

- Lv.＝通算ステージ、加入済み6人、アクティブを解放順に最大、枝・希少ジェム・薬・パッシブなし。当該主道・前ステージ主道をそれぞれ30配置seedで30/30勝利。巫女の実装済み回復・召喚・バリアも計算する。
- 大ボスはレベル固定・装備主道5段階遅れで勝利3/30以下。単発の実測上限51%、通常戦の中央値45〜90秒、大ボス45〜150秒を現行方針の目安にする。全員生存率、支援停止、床・状態・連撃を合わせた短時間被害も記録する。
- 初期・中断3回後・中断6回後の削り量とAI選択を測る。長期戦で妨害が失敗する状態を作り、自動防護で立て直せることを確認する。全危険技の中断成功を勝利条件にしない。
- 各危険技を「準備中断」「発動直前中断」「発動後の命中」「中断失敗」で確認。予約の全破棄、後続の残留、再使用待ち、状態・床・召喚の清掃を検査する。
- 円・扇・帯・段階波の内外で表示と当たり判定を照合する。同じ味方へ初撃50%を複数適用しない。端の切り取り、複数円の重なり、移動中の帯再入場、1人生存時の状態付与も測る。
- 新地域の妨害登録は `ACTIONS` だけでは完了しない。新AIの予約の開始・破棄・commit判定、味方の防護選択、固定育成基準 `interference-reference.js` の71〜100追加、状態解除・免疫・ツールチップまで揃える。現行の脅威判定 `contains` は円と帯なので、扇・円環・時間差の帯を明示的に追加し、描画と共通化する。未知の形状を帯として処理しない。今回の企画段階では本編へ登録しない。

育成・ドロップ・装備費用・周回・経験値の式は [balance-policy.md](../policies/balance-policy.md) を維持する。スキル・ジェムの効果欄は効果名と数値だけ。危険行動のツールチップは予備動作、抵抗力、容量、残量、中断回数のパラメータで表示する。
