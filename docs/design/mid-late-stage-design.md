## 地域と敵の一覧

各地域は10ステージ。雑魚A・B・Cの3系統、それぞれの通常ボスA+・B+・C+、最後に独立した大ボスD。C+は必ず成人女性型モンスター。上位種は体格だけでなく輪郭・装飾・攻撃の構えを変える。

| 地域 | 想定Lv. | A → A+ | B → B+ | C → C+（女性型） | 大ボスD |
| --- | --- | --- | --- | --- | --- |
| 砂漠：金砂の墓域 | 51〜60 | サンドスコーピオン → オブシディアンスコーピオン | 包帯兵 → 黄金のファラオ | 砂蛇 → ラミア | 砂喰いベヒモス |
| 高原：嵐渡りの高原 | 61〜70 | ホーンジャッカル → ストームジャッカル | 岩角ヤギ → アイアンホーン | 風の小精霊 → ハーピークイーン | マンティコア |
| 氷河：蒼氷の聖域 | 71〜80 | フロストウルフ → フェンリル | 氷殻ゴーレム → クリスタルゴーレム | 雪の精 → 雪女 | 氷牙マンモス |
| 火山：紅蓮の竜脈 | 81〜90 | ラヴァサラマンダー → マグマサラマンダー | 黒曜兵 → 黒曜の処刑者 | 幼火竜 → ドラゴンガール | ドラゴン |
| 魔王城：宵闇の玉座 | 91〜100 | 魔鎧兵 → 黒騎士 | インプ → アークデーモン | 夢魔 → リリス | 魔神 |

砂漠で継続被害と敵の移動、高原で隊列の乱れ、氷河で重い広域氷撃と支援の中断、火山で巨大な直線と地面、魔王城でこれらの組み合わせを扱う。氷河以降は危険技の予備動作を妨害で止める機会を設計し、中断失敗時は自動防護・回復と攻撃後の隙で立て直す。属性名は演出のテーマであり、新しい属性防御や装備相性表を追加する前提にはしない。

## 共通の戦闘ルール

- 敵HP・攻撃力はステージ固定。プレイヤーに追従しない。6人と巫女の召喚・回復・バリアを含めて調整する。
- 放置で勝てることを基本にする。クリック回避、特定の希少ジェム、枝、薬、未解放の技を必須にしない。準備した育成と自動支援、敵の攻撃後の隙で対処する。
- 2026-10-12の妨害実装を優先する。危険技の予備動作は雑魚2秒以上、ボス・大ボス3.8秒以上。発射・着弾位置は予備動作開始時に固定する。氷河以降の技別秒数・抵抗力・容量・予約破棄・休息は [危険行動企画](late-stage-danger-actions.md) を正本とする。
- 妨害成功で個体の基礎抵抗力×(1＋0.25×中断回数)、容量×(1＋0.15×中断回数)。回数は技とHPフェーズを跨いで維持する。中断時は未発動の連撃・床・状態・召喚を一括破棄し、休息へ進む。全危険技の中断を必須にしない。
- 予告は足元の輪・直線・扇形と、本体の構えを併用する。通常攻撃の光より予告輪を優先して描画する。色に加えて模様・輪郭を変える。
- 長い連撃は途中に間を設ける。大ボスの同じ味方への連撃は合計被害も測定し、短時間での事故死を防ぐ。
- 同一状態はスタックしない。強い効果を優先し、継続被害の更新は次のtickを早めない。完全停止・睡眠などの行動不能は1人あたり連続2秒以内、解除後3秒は行動不能への免疫を得る。最大2人まで同時付与し、生存者が2人なら最大1人、1人なら行動不能を付与しない。
- 支援が行動不能になった間は、別の敵が新しい行動不能を重ねない。複数の通常ボスが同時に出る編成を基本にせず、各ボスを別ウェーブにする。
- 潜行・飛行は攻撃不能になる時間を限定する。飛行中も近距離攻撃が届く扱いとし、遠距離職だけを必須にしない。潜行は最大1.2秒、直後に1.5秒以上の隙を設ける。
- 召喚はボス1体につき同時2体・1戦2回まで。援軍撃破は通常どおり報酬抽選するが、必要素材・費用の期待値は基本編成だけで計算する。大ボスの攻略を援軍の無限稼ぎにしない。
- 状態は死亡・ウェーブ終了・戦闘終了で解除。大ボスの地面ギミックは次ウェーブに残さない。

### 状態異常の開始値（調整案）

継続被害は敵攻撃力に対する倍率で計算し、既存の防御・軽減・バリアを通して評価する。最大HP比例の固定被害は使わない。下表はAI実装前の開始値であり、実測済みの数値ではない。

| 状態 | 効果・上限 | 主な地域 | 見た目 |
| --- | --- | --- | --- |
| 毒 | 1秒ごと威力×0.12、4秒、スタックなし | 砂漠・高原 | 緑の雫と脈動 |
| 砂縛り | 移動速度−35%、3秒。攻撃・支援は可能 | 砂漠 | 足元の砂の渦 |
| 出血 | 1秒ごと威力×0.10、4秒、スタックなし | 高原 | 赤い裂傷印 |
| 冷気 | 移動速度−30%、3秒。単体では行動速度を下げない | 氷河 | 青い霜の縁 |
| 凍結 | 最大1.5秒の行動停止、解除後3秒免疫 | 氷河 | 氷の輪郭とひび |
| 火傷 | 1秒ごと威力×0.15、4秒、スタックなし | 火山 | 橙の火種 |
| 破甲 | 防御−20%、4秒。重複なし | 火山・魔王城 | 割れた盾 |
| 呪い | 受ける回復量−25%、4秒。バリア・攻撃力には影響しない | 魔王城 | 紫の欠けた輪 |
| 沈黙 | 特殊技の新規開始だけ不可、最大1.5秒。通常攻撃・進行中の技・既存召喚は継続 | 魔王城 | 封じた口の印 |
| 睡眠 | 最大1.5秒、直接攻撃の被弾で解除。敵対化はしない | 魔王城 | 閉眼と三日月 |

浄化は既存パラディンのピュリフィケーションとサンクチュアリを利用する方向。現状の自動発動判定は主に毒・拘束なので、**新状態の解除対象・免疫対象・AIの優先度・UIパラメータを同時に拡張する実装が必要**。巫女に未実装の浄化があるものとして難易度を計算しない。浄化なしでも状態が短時間で自然解除され、適正装備で勝つことを確認する。

## 砂漠：金砂の墓域

琥珀色の砂丘、埋もれた墓殿、青緑の古代宝石。地面は淡い黄土、敵の輪郭は焦茶と黒、魔法は青緑で分離する。背景の砂嵐は奥だけを流し、戦闘面の視界を隠さない。

| 敵 | 攻撃・特殊行動 | デザインの要点 |
| --- | --- | --- |
| サンドスコーピオン A | 近距離物理。鋏→毒針。毒針は2回に1回、尾が緑に光る予告0.6秒 | 琥珀の甲殻、黒い鋏、小さな緑の毒針 |
| オブシディアンスコーピオン A+ | 扇形の鋏→尾の三連突き→毒液弾2個→休息1.5秒。三連突きの合計を通常強打1回相当から調整 | 黒曜の甲殻、肥大した両鋏、金の節、太い尾 |
| 包帯兵 B | 近距離物理。曲刀と包帯投げ。包帯は移動だけを短く妨げ、支援を止めない | 乾いた包帯、片方だけの曲刀、青緑の目 |
| 黄金のファラオ B+ | 杖の直線波→砂縛りの輪2個→包帯兵2体召喚→休息2秒。召喚上限は共通ルール | 金の仮面と大きな王冠、浮く裾、青緑の杖 |
| 砂蛇 C | 遠距離魔法の砂弾。近づくと短距離移動。潜行は最大0.8秒 | 淡い砂色の蛇、青緑の背びれ、丸い頭 |
| ラミア C+ | 砂弾の三方向射撃→蛇尾の円弧→砂縛り2地点→休息2秒。魅了・味方への攻撃は使わない | 成人女性の上半身、長い金色の蛇尾、青緑の衣装と宝冠。既存スキュラと違い単一の蛇尾 |
| 砂喰いベヒモス D | 角突進→地割れ3本→砂の咆哮→短い潜行→出現の衝撃→休息2.5秒。HP50%で地割れが3本から5本へ増えるが1本の威力は上げない | 大きな四足獣、岩のような背中、前向きの2本角、砂の鬣。ワームや竜と区別 |

ベヒモスの出現位置は土煙の輪で予告。砂の咆哮は視界妨害ではなく小威力の範囲攻撃＋砂縛り。潜行中に狙っていた味方の攻撃・MPは消費しないようAIで再選択する。

## 高原：嵐渡りの高原

高い草原、切り立つ岩、遠くの積乱雲。明るい空と深緑の地面に、敵の茶・白・青紫を置く。風は薄い帯と草の揺れで表現する。

| 敵 | 攻撃・特殊行動 | デザインの要点 |
| --- | --- | --- |
| ホーンジャッカル A | 近距離物理。噛みつき、低頻度の出血。味方後衛への瞬間移動はしない | 細身の茶色い獣、短い後ろ向きの角 |
| ストームジャッカル A+ | 弧を描く移動→直線突進→出血爪→休息1.8秒。雷の残像は出すが判定は本体だけ | 青白い鬣、大きな双角、細身で長い脚 |
| 岩角ヤギ B | 近距離物理。1秒の構え後に短い突進。ノックバック40pxから開始 | 灰褐色の毛、丸く巻いた石の角 |
| アイアンホーン B+ | 角の薙ぎ→長い直線突進→岩片3発→休息2秒。突進は予告した直線から曲がらない | 重い黒鉄の巻角、胸と肩の岩板、太い脚 |
| 風の小精霊 C | 遠距離魔法。小さな風刃。接近されると後退1回、後退後は2秒移動しない | 緑青の渦、葉の冠、顔が見える小さな精霊 |
| ハーピークイーン C+ | 三方向の羽根→風の円→急降下→休息2秒。押出しは最大70px、連続で画面端に押さない | 成人女性の顔と胴、白と青紫の翼腕、鳥の脚、冠。地上型ラミアと違う幅広い翼 |
| マンティコア D | 爪の二連撃→毒尾の扇射→翼の突風→飛び込み→休息2.5秒。HP50%で毒尾の射撃を1回増やし、射撃間に0.6秒を置く | 赤褐色の獅子の体、険しい人面、紫の蝙蝠翼、節のある毒尾 |

吹き飛ばし後の位置も味方の支援範囲を完全に切らないよう調整する。空中のマンティコアも全職が攻撃可能。毒と出血は別状態だが合計tick被害を測り、両方が付いた場合を基準に調整する。

## 氷河：蒼氷の聖域

深い青の氷壁、淡いオーロラ、白い雪面。戦闘面は暗めの青白、氷の敵は紺の輪郭、予告は紫の縁を入れた氷のひび。白いエフェクトだけで敵が消えないようにする。

| 敵 | 攻撃・特殊行動 | デザインの要点 |
| --- | --- | --- |
| フロストウルフ A | 噛みつき。危険技は短帯の霜牙跳び＋冷気、凍結なし | 白い毛、紺の背、青い牙 |
| フェンリル A+ | 氷爪。危険技は蒼牙跳躍と氷柱遠吠え、各予備動作後に発動し休息9秒。氷柱だけ凍結最大1秒 | 巨大な狼、濃紺の鬣、青いルーンと氷の牙 |
| 氷殻ゴーレム B | 拳。危険技は円範囲の氷拳砕き。前方装甲で被害15%減、無敵ではない | 雪を被った鈍い氷殻、太い腕、小さな顔 |
| クリスタルゴーレム B+ | 拳。危険技は晶拳大扇と結晶装甲。装甲は4秒・軽減30%・攻撃停止、付与前に中断可能 | 多面体の透明な氷、大きな胸の核、紫の内光 |
| 雪の精 C | 冷気弾。危険技は後衛寄りの冷気輪、行動不能なし | 雪の結晶を囲む小さな浮遊精霊、青い目 |
| 雪女 C+ | 冷気の扇。危険技は三華氷柱と薄氷の封輪。封輪は無被害・凍結1.5秒・最大2人、各休息9秒 | 成人女性、長い白髪、白と藍の着物、雪の冠、浮く裾。人型で蛇尾・翼を持たない |
| 氷牙マンモス D | 氷牙大薙ぎ→休息3秒→二段の氷震踏砕→休息3秒→後衛寄りの氷塊天落→休息3.5秒。HP50%以下はサイクル末尾に三段の白夜の氷冠→休息4秒。各技は独立した予備動作と妨害残量を持つ | 巨大な肩、太い4本脚、白銀の長毛と紺の陰影、長い鼻、2本の湾曲した蒼氷の牙、背の氷塊。重量と接地で威圧感を出す |

凍結は特定の攻撃だけに絞り、冷気を一定回数受けると自動で凍結する蓄積ルールは追加しない。凍結と大技の確定直撃を組み合わせず、凍結後は休息へ進む。大ボスの範囲・接地・鼻と牙の軌道・静止素材は [氷牙マンモス企画](glacier-stage-design.md)、地域の全敵の危険技は [後半3地域の危険行動企画](late-stage-danger-actions.md) を参照。

## 火山：紅蓮の竜脈

黒い火山岩、溶岩の裂け目、遠景の噴火と竜の巣。戦闘面は煤色を主にし、溶岩は周縁と奥に置く。常時赤い床で予告円を埋めない。

| 敵 | 攻撃・特殊行動 | デザインの要点 |
| --- | --- | --- |
| ラヴァサラマンダー A | 近距離物理＋短い火炎。火傷は火炎だけ。倒した際の爆発はなし | 黒と橙の四足蜥蜴、溶岩の背びれ |
| マグマサラマンダー A+ | 噛みつき。危険技は双溶岩弾と灼熱大扇、各休息9秒。溶岩弾の跡は最大2秒・2個 | 大きな四足蜥蜴、割れた黒い甲、太い橙の尾 |
| 黒曜兵 B | 近距離物理。重い斧。破甲は3回に1回、刃を白く光らせる | 黒曜石の鎧、単刃の斧、金色の隙間 |
| 黒曜の処刑者 B+ | 斧の通常攻撃。危険技は高抵抗の断罪大薙ぎと断層斬、各休息9秒。破甲直後の大技は間を1.2秒以上空ける | 大きな両刃斧、角張った肩、頭を覆う兜 |
| 幼火竜 C | 遠距離魔法の火球、近距離の爪。浮遊しても近接攻撃可能 | 小さな赤い有翼竜、橙の翼膜、小さな角 |
| ドラゴンガール C+ | 爪と翼。危険技は低抵抗の紅蓮三連球と直線の紅翼竜息、各休息9秒 | 成人女性、赤い角と翼、長い竜尾、黒と赤の鱗鎧、竜の脚。武器は持たず竜の肉体を使う |
| ドラゴン D | 翼震着地→休息3秒→双脈ブレス→休息3.5秒→噴火の三巣→休息4秒。各技に独立した予備動作。HP50%でブレスの逆側の直線を1本追加、間を1秒空ける | 四足の巨大な赤黒い有翼竜、長い首、2本の角、橙の翼膜、胸の溶岩光 |

床の危険地帯は親技の予備動作開始時に位置を表示し、親技の中断で落下物と床の予約を全て消す。存続2秒、同時3個・戦闘面積20%以内。1秒ごと威力×0.18から開始し、同じtickに重なった地面判定は最大1回。床と火傷も親技の後続被害予算へ含める。同じ地点を連続選択しない。手動回避を必須にせず、支援と自然な接敵移動で耐えられる範囲を検証する。

## 魔王城：宵闇の玉座

黒紫の石、赤い絨毯、金の門、紫の魔炎。遠景は玉座と大きな月窓、床は暗く平坦にして味方6人を読ませる。敵の闇魔法は紫、味方支援は白金。

| 敵 | 攻撃・特殊行動 | デザインの要点 |
| --- | --- | --- |
| 魔鎧兵 A | 近距離物理。盾と剣。短い正面軽減15%、側面・背面は通常 | 黒い鎧、赤い目、盾と直剣 |
| 黒騎士 A+ | 大剣の通常攻撃。危険技は高抵抗の王断の大剣と黒環薙ぎ、各休息9秒。反射・完全無敵は使わない | 長身の黒鎧、大剣、赤い外套、閉じた角兜 |

ジェムは絶対確率の排他的抽選で合計5.5%。後半でも確率を上げない。追加ジェムの種類・効果は今回の企画対象外で、素材画像にジェムを混ぜない。

武器・防具の主道10段は **なし／A／B／C／ABC／AB／AC／BC／ABC／地域結晶**。A/B/Cの費用は対称、主道にレアを使わない。同キャラの武器＋防具同段の合計は該当ステージ約3周以内、100ノード1本の全取得は地域10約300周を基準に調整する。各素材を必要なタイミングで取れることと、ゴールド側の費用も合わせて検証する。

基本編成だけで計算した素材の開始案は以下。確率からの平均であり、個々の周回の入手保証ではない。通常の素材変換・不足分の追加周回は既存どおり。

| 段 | 同キャラ武器＋防具の要求 | 1クリアの期待量 | 必要周回の期待値 |
| --- | --- | --- | ---: |
| 2〜4 | 対応コモン4個 | 対応7.6個 | 0.53 |
| 5 | ABC各2個 | ABC各3.6個 | 0.56 |
| 6〜8 | 対応2素材各4個 | 対応各4.9個 | 0.82 |
| 9 | ABC各4個 | ABC各3.4個 | 1.18 |
| 10 | 地域結晶4個 | 結晶1.9個 | 2.11 |

「必要周回」は要求数／期待量であり、複数素材が全部揃うまでの停止時間とは異なる。3周条件の最終判定では排他的でない各素材の抽選と在庫を含めて測定する。地域10のレアは平均0.3個／回で、1本の終端レア90個を約300周の基準にする。敵追加数だけを理由にABC費用を非対称にしない。

経験値は `{level, progress}`。クリア時だけレベル内進捗を付与し、表示は％。正の巨大な累乗・累積経験値を計算せず、獲得量が `3^(-20)` 以下なら0。死亡・ボス撃破の途中報酬に経験値を追加しない。

## 数値実装時の検証目標

全員のレベル＝通算ステージ、加入済み6人、アクティブを解放順に最大ランク、通常攻撃ランク1、枝・終端・ジェム・薬・パッシブ・専用強化なし。巫女の実装済み支援を含める。30配置seedで [wave-balance-adjustment.md](../history/wave-balance-adjustment.md) と同じ実戦計算を行う。

- 当該ステージまでの主道：30/30勝利。初回攻略の前ステージまでの主道：30/30勝利。
- 通常難所：単発実測上限51%、討伐中央値45〜90秒。全員生存率は参考測定。2026-10-12の予備動作・妨害実装後の基準を採用する。
- 大ボス：適正装備でも途中死者を許容。単発実測上限51%、連撃・状態・地面を合わせた短時間被害も記録。討伐中央値45〜150秒を現行の目安とする。
- キャラLv.を固定し主道だけ5段階遅らせた大ボス戦は勝利3/30以下、10段階遅れは1/30以下を目標にする。
- 浄化あり／なし、支援役が一時停止、毒＋出血、火傷＋地面、呪い中の回復を個別に測る。回復低下中にもバリアで立て直せることを確認する。
- 行動不能は付与時間・同時人数・免疫をログで測定。追加召喚数、潜行中のMP消費、予告と当たり判定の一致、最終素材期待値も検証する。中断の回数別削り量、全攻撃予約の破棄、発動後の命中、再使用待ちと防護AIは [危険行動企画の受け入れ条件](late-stage-danger-actions.md) を検証する。

目標は未検証。後半ほどHP・火力を上げるが、状態異常を増やした分を同時に単発威力にも上乗せしない。長時間の硬さだけで難化させず、支援と範囲攻撃で圧力を減らす構造を守る。
