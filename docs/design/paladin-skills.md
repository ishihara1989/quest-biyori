# パラディンの聖技

森1-10初回クリアで加入し、毒の沼地へ同時出撃する。加入時Lv10、旧セーブの森1-10クリア済みデータにも追加する。既存キャラの育成は維持し、経験値・装備コスト・ドロップは2026-10-09の `balance-policy.md` に従う。

通常攻撃1種、Lv5から5レベル刻みのアクティブ20種、各技の専用強化21種、共通パッシブ11種。各ノード5ランク、1SP。習得・減算・依存先返却・装備・ジェムは他キャラと共通の仕組みを使用する。効果表示は `PaladinSkills.parameters` の効果名・数値・パラメータだけにする。

## 戦闘

- 通常攻撃は180ms、聖槌はメイス掲げ520msから叩きつけ240msの接触位置で命中。攻撃速度と専用強化で動作時間を縮め、再使用時間は独立して管理する。
- 浄化は範囲内に毒・拘束がある時、防御は敵の予備動作がある時に優先する。聖域は負傷・状態異常、挑発は負傷した仲間、反撃は敵の接近を条件に選ぶ。
- 神聖ダメージはスケルトン・リッチに1.35倍。行動妨害力で予備動作中の抵抗容量を削り切ると、ヒュドラを含む大ボスも中断できる。中断成功ごとにその個体の抵抗力・容量が増える。ボス全般への通常の押し出し・拘束・打ち上げ・スタンは無効。
- 盾突進は接触した敵を攻撃方向へ押し出し、最後にスタン。各敵の押し出しは1回。光の壁・騎士団も攻撃方向に押す。
- 軽減は有効範囲内の最も強い1つを使用。反射・蓄積は本人、イージス・城壁・終式はパーティ全員、聖域・要塞は設置範囲を対象とする。城壁の致死保護は展開ごと各人1回、HP1で生存する。蓄積反撃には上限を設ける。
- 聖域は1秒ごと最大HP割合回復、新規の毒・拘束を防ぐ。防御源の死亡、ウェーブ終了、敗北時には結界を消す。

## 素材と確認

従来の6モーション21コマの構成は `paladin-motion-design.md`。Lv30のホーリースピアを断行槌へ置き換え、4コマの `break-strike` と4コマの `break-impact`、新アイコンを追加した。前進は左右の踏み出し各3コマ、全6コマ。生成元の透過PNGとプロンプトを各 `source/` に保持する。新しい妨害仕様と素材の再構築は [行動妨害の実装](../implementation/action-interference-implementation.md) を参照。

`paladin-skill-lab.html` は本編と同じシミュレーションと描画を使用する。全技・ランク・専用強化・左右反転・雑魚／ボス・コマ送り・タイムライン・エフェクト切替を確認できる。

```sh
npm run build:paladin
npm run test:paladin
npm run check:paladin-ui
npm test
```

再ビルドにImageGenを再実行する必要はない。生成済み原画をリポジトリ内の相対パスから切り出し、基準位置に合わせて最近傍で縮小・配置する。
