# 遺跡のステージ設計案

2026-10-11追記：本編への接続を実施。[実装・実戦検証・残る数値目標](../implementation/miko-ruins-implementation.md)を参照。以下は制作前の設計記録であり、提案の数値目標をすべて達成したという意味ではない。

2026-10-10 JST。企画の検討用。敵名、編成、攻撃、巫女の加入方法、支援内容、数値目標は提案段階で、本編には未適用。

## ユーザー指定の前提

- 海岸の次の地域は遺跡。
- 敵は状態異常などの複雑な仕掛けを使わず、高いステータスと多い数で攻める。
- 巫女のデビューステージ。巫女の支援がないと攻略が困難になる難易度を目指す。
- 大ボスは機械を思わせる大型の敵。
- この地域にも女性型ボスを1種用意する。
- 近距離物理・遠距離物理・近距離魔法・遠距離魔法を偏りなく配置する。

## 地域の骨格

既存地域と同じ10ステージ・各3ウェーブを提案する。地域5、通算41〜50、想定Lv.41〜50。海岸10クリアで遺跡1を解放する。

テーマは、崩れた神殿で今も動き続ける古代の防衛機構。石材、くすんだ青銅、金の紋様、青白い魔導炉を共通意匠にする。遠景に崩れた柱と大きな神殿、戦闘面に割れた石床、奥に眠っている巨兵を置く。

高耐久の前衛が戦闘時間を延ばし、その間に後衛の射撃が被害を積み重ねる。巫女の回復で前衛が持ちこたえ、味方の範囲攻撃で数を減らすと戦況が改善する流れを作る。単発の事故より、継続する圧力を難しさの中心にする。

## 通常敵4種

| 仮名 | 主な攻撃 | 外見 | 役割・攻撃案 |
| --- | --- | --- | --- |
| 石の衛兵 | 近距離・物理 | 四角い石鎧と大きな石剣 | 高HPの前衛。剣の振り下ろしと小さな薙ぎ払い。移動と攻撃はやや遅い |
| ルーンガーゴイル | 近距離・魔法 | 細身の獣像、畳んだ翼、光る爪 | 衛兵より軽快。魔力を帯びた爪と足元の小範囲魔力衝撃。状態異常は付けない |
| 古代の弩兵 | 遠距離・物理 | 青銅の細い機械脚と大きな弩 | 前衛の後ろから太い矢を発射。直線射撃と間を空けた2連射 |
| 浮遊魔導器 | 遠距離・魔法 | 結晶核を囲む石と金属の輪 | 光弾と小範囲の着弾攻撃。弩兵とは異なる高さ・形・弾色で見分ける |

石の衛兵も攻撃力は高めにし、単なる無害な壁にはしない。ルーンガーゴイルには前衛を短時間で押し切らない攻撃間隔を設ける。後衛2種のHPは前衛より低く、倒すと敵の総火力が目に見えて減るようにする。

物理・魔法は攻撃の種類を示す。キャラクター側の共通防御という既存方針を維持し、遺跡のために別々の防御育成を要求しない。混成ウェーブの初期編成は4種をおおむね均等にし、各ステージの見せ場に合わせて比率を変える。

## 通常ボス3種

### 重装ゴーレム：近距離物理の主役

石の衛兵を大きくした重装の守護像。両腕が太く、頭と肩の輪郭を通常敵と変える。

攻撃は拳の叩きつけ、広い腕の薙ぎ払い、間を空けた2連打。高HPと広い攻撃範囲で前衛を消耗させる。高い防御に加えて常時軽減まで重ねず、攻略時間は主にHPで調整する。

### 古代弩砲兵：遠距離物理の主役

大型の弩と青銅の脚を持つ歩行砲台。弩兵の上位種として、遠距離物理の存在感を作る。

攻撃は太い貫通矢、3方向の扇状射撃、時間差の3連射。予告方向と射線を固定し、発射後は向きを追従させない。足元まで近づいた相手には短い体当たりを使う。

### 女性型ボス：魔導人形セラフィナ

遺跡の祭壇を守る、成人女性の姿をした古代の魔導人形。全身が人型で、陶器のような白い肌、金の髪飾り、深い藍と白の祭礼衣装を持つ。肘・膝に控えめな機械関節、胸元に青白い魔導核、背後に大きな円環を置く。

これまでのアルラウネ・アラクネ・スキュラと異なる、全身人型のシルエットを見せる。待機中は静かで優雅、攻撃時は円環と腕が大きく動き、機械らしい正確な動きをする。

主役割は遠距離魔法。近づくと近距離魔法も使う。

| 攻撃案 | 種類 | 動作と作用 |
| --- | --- | --- |
| 魔光弾 | 遠距離魔法 | 腕を差し出し、最大3人へ順に光弾を発射。連射の合計で圧力をかける |
| 円環刃 | 近距離魔法 | 背後の輪を前方に回し、近くを円弧状に薙ぐ |
| 裁光 | 遠距離・範囲魔法 | 構えで3地点を予告し、時間差で光柱を落とす。予告時の位置に着弾する |

行動は魔光弾→円環刃→裁光→短い休息を基本にする。魅了などの状態異常は使わず、連射と範囲ダメージでパーティーを消耗させる。光柱の発動をずらし、同じ味方へ一瞬に全弾が重なる事故を抑える。

比較用の別案として、肉体を持つ「古代の女祭司」も考えられる。その場合も魔光弾・円環・光柱の攻撃構成は使える。現案では、大ボスとの意匠をつなげやすい魔導人形を推奨する。

## 大ボス：古代機兵タイタン

石の装甲と青銅の骨格を持つ大型の二足機械。太い腕、胸の魔導炉、背中の双砲で、通常ゴーレムより明確に機械らしく見せる。現代的なロボットより、神殿の一部が歩き出したような姿を目指す。

近距離・遠距離の物理と魔法をすべて使う、地域の総仕上げにする。

| 攻撃案 | 種類 | 動作と作用 |
| --- | --- | --- |
| 巨腕叩きつけ | 近距離物理 | 腕を高く上げ、広めの円へ叩きつける |
| 双砲連射 | 遠距離物理 | 背中の砲から左右交互に弾を発射する |
| 炉心照射 | 遠距離魔法 | 胸の炉が開き、予告した直線へ太い光線を放つ |
| 魔導震撃 | 近距離魔法 | 踏み込みで足元の円へ魔力衝撃を広げる。ダメージのみ |

基本は4攻撃→排熱休息→繰り返し。攻撃の予告、被弾、排熱を大きな動きで伝える。休息中も通常どおり攻撃が通り、その時間に巫女の回復で立て直せる。HPによる形態変更や別の専用ゲージは設けず、固定の攻撃サイクルから数値調整を始める。

大ボスのウェーブはタイタン1体から開始する。多数の敵による圧力は前半ウェーブで見せ、最後は大型機械の動きと味方の支援を見やすくする。

## 巫女のデビューと難易度

[既存の巫女構想](progression-design.md)は支援召喚を候補としており、具体的なスキルは未確定。遺跡では、式神による継続回復を中心にし、範囲軽減またはバリアを補助候補とする。攻撃召喚との切替など、巫女全体のスキル設計は別途検討する。

加入は海岸10クリア時を提案する。遺跡1へ入る前に、基本の回復支援を取得できるSPと、海岸メイン完了相当の初期戦力を用意する。加入直後の巫女だけを育て直す長い周回を要求しない。過去の装備ツリーを取得済みにするか、加入用の初期装備で同等にするかは未決定。

完全自動戦闘を前提に、回復はHP割合の低い味方を優先し、前衛にも安定して届くようにする。支援範囲からの散開や召喚の配置で難易度が大きくぶれる場合は、敵の倍率を上げる前に支援AIを見直す。

巫女が必要になる理由は、敵の総HPと継続火力の組み合わせで作る。支援ありでは回復量と被害が拮抗し、敵を減らすにつれて回復が追いつく。支援なしでは前衛のHPが削られ続け、後半ウェーブまで持ちこたえにくくする。敵に特定スキルでしか解除できない防御を付けて巫女を要求する方式は採らない。

### 検証目標案

[既存の攻略基準](../history/stage-balance-adjustment.md)を引き継ぎ、加入済みの味方・想定レベル・解放順に最大ランクのアクティブ・メイン装備のみで評価する。忍者と呪術師の加入時期は、この遺跡案では新たに決めない。

| 条件 | 目標案 |
| --- | --- |
| 巫女支援あり・適正メイン | 通常の難所で30配置すべて勝利、全員生存27/30以上、討伐中央値45〜90秒 |
| 巫女支援あり・前ステージまでのメイン | 初回攻略として30/30勝利。未クリアの遺跡メインを必要条件にしない |
| 巫女支援なし・適正メイン | 巫女本体の攻撃と人数を保ち、回復・軽減・バリアだけ無効化して比較。6〜10で勝利6/30以下を開始目標とする |
| 装備が10段階遅れ | 支援ありでも勝利1/30以下という既存目標を維持する |

上記は目標であり、実測結果ではない。支援の有無による比較は、巫女をパーティーから外して人数と火力まで変える比較と分ける。枝・希少ジェム・パッシブ・薬を必須条件にしない。

最大単発被害は既存の最大HP30%以下を守り、同時着弾の合計と短時間の集中被害も確認する。多数の弾や範囲攻撃の開始をずらし、回復が機能する前に前衛が倒れる編成を避ける。前衛の残HP、全員生存、被害、実回復量、支援を止めた際の結果を記録する。

敵HP・火力はステージごとの固定値にする。現在のプレイヤーの強化に追従させず、巫女のスキルが決まってから実際の戦闘で係数を調整する。

## 報酬・装備・演出

[2026-10-09のバランス方針](../policies/balance-policy.md)を継続する。経験値は通算41〜50に対応するレベル内正規化進捗を使い、累積経験値や正の巨大な累乗を計算しない。表示は％、獲得量が3^(-20)以下なら0。

素材名の候補は、石の衛兵・ガーゴイルの「古代石片」、弩兵・弩砲兵の「青銅歯車」、魔導器・セラフィナの「魔導片」、地域共通の「遺跡の結晶」、タイタンの「古代炉心」。重装ゴーレムのコモンは古代石片、タイタンのコモンは青銅歯車を候補とする。

素材確率、レアジェム5%、ユニークジェム0.5%は既存どおり。敵数増加を含む新しい基本編成の期待ドロップからコストを見積もり、武器・防具メインの同段階合計は約3周以下、各100ノードのツリー全取得は遺跡10約300周を目安にする。各ツリー全取得の共通容量＋1も維持する。レア素材をメインに要求しない。

演出は石片、青銅の火花、太い矢、魔導光を使い分ける。巫女の回復と防護は白金の光でまとめ、敵の青白い魔導光と区別する。支援発動時には式神から味方へ光が届き、HPの回復と結び付いて見えるようにする。

敵と背景は既存と同じドット絵テイスト。戦闘面は既存の接地範囲を維持し、崩れた柱などの重ねる要素は透過PNGにする。通常敵の輪郭と射線を残し、セラフィナの円環やタイタンの光線が画面を覆い続けないようにする。

素材制作へ進む際は、基準リファレンスと各コマの位置・軌道を定め、攻撃は動作のまとまりごとに3〜4コマ、歩行は左右3コマずつを基本にする。コマ送りと連続再生で、形・色・透過・見切れ・待機への接続を確認する。

## 次に確定する事項

1. 女性型ボスは魔導人形セラフィナのデザインでモーション制作済み。行動の数値・再使用間隔を確定する。
2. 巫女の基本支援を継続回復中心にするか、軽減・バリアにも大きな比重を置くか。
3. 通常敵4種・通常ボス3種・大ボス1種の素材を制作済み。各ステージの固定編成を確定する。
4. 巫女の加入時の装備・SP・支援AIと、支援を止めた比較試験の具体的な目標。

決定後に固定編成と数値を作り、実戦検証を行う。本書の案の保存のみでは、企画の採用や実装完了を意味しない。

## モーション制作（2026-10-10）

敵8種それぞれの待機・移動・被弾・撃破と、攻撃・特殊行動24本、対応エフェクト18種を制作した。合計56モーション、敵204コマ・エフェクト72コマの透過PNG、PNGシート、GIF、manifestを保存した。待機は4コマ、地上移動は左右3コマずつの計6コマ、飛行・浮遊移動は4コマ、被弾と撃破は各2コマ、攻撃・特殊行動は4コマ。被弾と撃破の原画は同じ4コマシートの前半・後半から切り出した。

基準画像は `public/assets/enemies/<id>/source/design-reference.png`、座標・軌道・配色制約は [ruins-specs.cjs](../../tools/assets/ruins-specs.cjs)、全文プロンプトと生成記録は [ruins-generation.json](../../development/records/ruins-generation.json) に保存した。全コマを基準画像から生成し、切り出し・接地登録・nearest-neighborによる拡大縮小でPNGシートとGIFを作成した。生成原画と修正版は両方保持している。

攻撃の発生タイミングは各manifestのeventsへ記録した。弩兵の二連射、弩砲兵の三連射、タイタンの左右砲撃は個別イベントに分け、セラフィナの光柱3地点は固定位置で140msずつずらす。炉心照射は発射コマ中の500msで収束する。エフェクト表示は確認画面用で、戦闘本編の遺跡ステージ・数値・AIへの適用は別工程。

全生成シートを目視確認し、透過・見切れ・PNGとGIFのコマ数と時間・飛行時の接地余白・生成原画とプロンプトの保存を検査した。ブラウザでも待機・移動・被弾・撃破と、攻撃に合成したエフェクトを確認した。
