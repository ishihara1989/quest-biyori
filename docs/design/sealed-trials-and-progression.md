# 封印・ソロ試練と転生中盤のバランス案

2026-10-22 JST。**個別の封印・ソロ試練、報酬、以下の調整基準は設計案・未採用。** 今回の本編実装は「輪廻の絆」「封印の試練」の2ノードまで。[実装記録](../implementation/sealed-trial-unlocks.md)。女神の本気へ到達する序盤のノード・敵能力・既存試練倍率は変更しない。

## 基準を「次の選択肢を開く周回数」で決める

2026-10-22追加指定：**価格8,000 PT以下のノードはすべて取得済みとして、中盤の詰まりを評価する。** 取り切るまでは周回ごとに購入先があるため、闘志・生命だけを取り出した構成を中盤の到達判定に使わない。価格しきい値は単体ノードごとで、取得費用の合計8,000 PTという意味ではない。現行では76ノード・累計134,660 PTが該当する。

次の循環を維持する。

1. 現在安定して勝てる試練の組合せで周回し、1周分で購入できる強化を取る。
2. 同じ強化帯で、別の封印条件またはソロ試練に挑戦できる。
3. 初クリア報酬で別系統を攻略しやすくする。前提試練自身の報酬を初クリアの必要条件にしない。
4. 増えたPTで次の強化帯に進み、既存の強靭などとの併用を増やす。

基準PTを、その時点の**実際に安定して勝てる組合せの1周報酬 B** とする。全試練を掛け合わせた理論値をBに使わない。Bは初クリア報酬適用後に更新する。同じ周の女神再撃破を加算収入にしない。

| 観点 | 今後の判定案 |
| --- | --- |
| 安定周回 | 固定条件30配置全勝。女神戦の中央値150秒以下、最長165秒以下を目標。180秒ぎりぎりの勝利は初攻略として区別 |
| 新しい挑戦 | 装備全取得・普通のジェムを容量の約半分まで装着して最終女神を倒せる。新試練の報酬自身を含めず30配置確認 |
| 次の選択肢 | その時点のBで1〜2周以内に買える有効な強化、または現能力で初クリアできる別系統が最低1つある |
| 同じ倍率での停滞 | 必要強化が3周分を超え、他の初クリア経路もない状態を要調整として検出 |
| PT増加 | 同じ投資帯の安定収入は、まず1段階あたり1.5〜3倍を目安とする。初回だけの高倍率は安定収入と分ける |
| 高倍率の組合せ | 2倍以上の強化段階を丸ごと飛ばして次々にクリアできる場合は、組合せ全体の投資・収入・周回時間を再点検 |
| 経済 | PT/周とPT/実時間の両方を測る。ゲート解放や収穫報酬による育成・周回時間の短縮も含める |

これは将来の検収案。今回の測定から150秒・165秒という線が一般に最適だと確定したわけではない。既存の戦闘被害・30配置・保存の確認方針は維持する。中盤以降の試練用基準を、既存通常地域の敵調整へ逆適用しない。

## 現行コードでの基準測定

以下の最初の表は、補助ノードを省略した前回の比較測定として保持する。新しい進行評価には、後掲の「8,000 PT以下を全取得した追加測定」を使う。

全6職Lv.100、通常10地域・女神装備全取得、通常ジェムはLv.10・品質1のレジェンダリー、職ごとに同じ優先規則で実際に装着可能な組合せを固定。専用容量を除く方向容量＋共通容量の約44〜49%を使う。エピック・ポーションなし。スキルはアクティブ→専用強化（ツリー順）→パッシブの順でSP内に収め、敵別の最適化はしない。装備取得後の戦闘スナップショットであり、装備取得までの所要時間は未測定。

適用済みの初クリア報酬は強靭2・猛攻・頑強・女神の本気・ゲート解放。購入ノードはメイン材料無償化までの前提・試練の扉・輪廻の絆・記載段階までの闘志と生命だけ。SP・容量・技能・対ボスの追加ノードはない。使用ジェムと全職のスキルランクを測定JSONに保存する。

約4,000 PTの組合せは **女神の本気×猛攻×頑強×ゲート解放**。初クリア恒常PT倍率を適用すると `100 × 10 × 1.5 × 1.5 × 1.2 × 1.5 = 4,050 PT`。強靭2まで追加できれば8,100 PTになるが、その戦闘も別途勝てることを確認する必要がある。

### 8,000 PT以下を全取得した追加測定

猛攻・頑強・強靭2・女神の本気・ゲート解放の恒常報酬を保持し、上記76ノードを取得した構成を使う。猛攻・頑強の攻撃・HP各1.5倍は前回にも含まれており、今回初めて追加した補正ではない。ユーザーの序盤ルートには詰まりがないという前提を維持し、序盤の敵能力は調整しない。

ジェム封印・スキル制限の**仮の初クリア報酬**を、前述の1能力欄基準で加える。レジェンダリーLv.10・品質1の各通常能力1欄、攻撃力・HP・防御力は3欄分。対応職の物理／魔法攻撃は1欄。固有能力は現行のレジェンダリー値で、エピックは付与しない。基礎加算を既存能力計算のパッシブ適用前へ入れ、容量倍率・総SP超過倍率は別枠で乗算する。個別試練の報酬の本編実装ではない。

装備主道限定は通常10地域の主道と、main扱いの女神装備の根を許可し、枝は使わない。女神の根は専用容量だけを付与するため、通常容量やSPを増やさない。装着ジェムは制限後の容量で選び直し、各部位の通常容量2,200に対して1,020（約46%）を使用。レジェンダリー・ユニーク・レアを組み合わせ、エピック・ポーションなし。

「技の記憶IV」「研鑽の環I」を含むため、主道限定でもLv.100由来の総SPは260。スキル制限報酬はHP・与ダメージ各2.6倍になる。容量報酬は2,200に対して各1.22倍、両報酬の別枠倍率は各3.172倍。これに全能力の基礎加算と、SP増加で取得できるスキルそのものの効果が加わる。前回の「SP100では超過報酬なし」は補助ノードを取らない比較条件での話であり、今回の進行前提には当てはめない。

通常の全装備へ戻した稼ぎでは、女神の本気＋強靭3が上限とは限らず、現行上限の強靭10も30配置全勝だった。猛攻・頑強・ゲート解放を併用し、初クリアの恒常PT倍率も含めると1周40,500 PTになる。これは**最終戦の計測時間であり、20秒で1周できるという意味ではない**。強靭の逐次解放・道中・育成時間も別途必要。

この前提なら、装備試練への詰まりより「安価ノードを取り切った後、現在の強靭上限まで一度に進める」点が次のバランス検討事項になる。単体14,000 PTのノードは40,500 PTの1周分で2個購入できるため、強靭2〜3の8,100〜12,150 PTだけを中盤の上限収入に置かない。序盤を難しくする調整は今回行わず、その先の試練・ノード費用・収入の増加幅を評価する。

追加ツールは `tools/balance/measure-seal-reward-route.cjs`。`--all-8000 --step=8` が装備試練、`--serious` で女神の本気、`--full-gear --strength=3` で制限なし装備の稼ぎ、`--full` で30配置。既存の同一構成の3配置を30配置へ拡張時に再利用する。通常装備の合法性・SP・容量・保存後の能力一致と、仮報酬を加えてもプレイヤーのセーブやジェム解釈処理を変更しないことを検証する。

出力は `output/trial-progression/rewards-main-8-all8000-single-str0-yes.json`（30配置）、`rewards-main-9-all8000-single-str0-yes.json`（3配置）、`rewards-main-8-all8000-serious-str0-yes.json`／`rewards-main-9-all8000-serious-str0-yes.json`（各3配置）、`rewards-full-8-all8000-serious-str10-yes.json`（30配置）。測定モデルの3テストと構造検査で入力・配置を確認する。ゲーム本体の数値・報酬は変更しない。

## ノード費用と詰まりの確認

今回採用する「輪廻の絆」4,000 PT＋「封印の試練」4,000 PTは、B=4,050なら合計2周で取得できる。前提が購入済みなら1つずつ買えるため、中間目標もできる。前提全体を含む最小の累計消費は12,880 PT（メイン材料無償化まで180、扉100、闘志5まで2,300、生命5まで2,300、絆4,000、封印4,000）。他系統への投資は別枠。

実装上の「闘志5・生命5」は各7.5倍の5番目ノード。古い保存互換用IDは `damage2`・`hp2` だが、2番目や5倍ノードを前提にしていない。

封印を買う前に闘志・生命を各4→5へ伸ばす費用は合計2,400 PTで、B=4,050の1周分に収まる。その後も各6は合計4,400 PTなのでBの約1.1周。各7は合計8,000 PTで約2周。よって解放直後の少数回の足踏みが直ちに詰みにはならない。一方、これだけで後続の全試練に必ず到達できるとは断言しない。

封印の個別条件はまだ遊べないので、今回はノードに「個別の試練は設計中」と明記する。

### 無彩の誓約

挑戦中は全職・全部位のジェム効果を無効にする。エピックもジェムなので対象。装着操作だけを禁止して、保存・自動装備・既に装着済みの能力が残る抜け道を作らない。ドロップ・所持・分解は可能とする案。放棄・次周では通常効果へ戻す。

「レジェンダリー1個分」は**同レベルの1能力欄の標準値**として定義する案。現行レジェンダリーは通常欄3つと固有欄1つの混成なので、ジェム全予算5.152を各能力へ丸ごと加える定義とは効果が大きく異なる。実装前にこの定義の確認が必要。

- 地域Lv.10・品質1・標準容量580の値を固定基準にする。通常欄の標準重みは `(5.152−1.6)÷3 = 1.184`。
- 通常能力はその1欄分、攻撃力・最大HP・防御力は3欄分を基礎値へ加算。職制限のある能力は対応職だけに適用。物理／魔法攻撃まで3欄にするかは未決定。
- MP自然回復・命中MP回復・範囲・再使用回復・妨害・バリア・被弾回復など、現行ジェムの能力を網羅。固有能力の発動間隔・上限を維持し、同じ能力のジェムと二重発動する別システムにはしない。
- 「ドロップ率」も全能力に含めるかを明記する。全能力という指定を文字どおり採る初期案では含めるが、PT経済と別に通常素材の収支を確認する。
- 武器・防具ごとに `方向容量＋補助容量＋共通容量` をCとし、与ダメージ／HPへそれぞれ `1 + C/10000` を別枠乗算。専用容量は除外、割引前、端数連続とする案。今回の基準のC=5,500なら1.55倍。攻撃・防御容量だけを数える解釈もあるため、ここは確定前に確認する。
- 一度クリアして得た恒常報酬は、同じ封印試練の再挑戦でも有効。初クリアの確認では当然この報酬を除く。

全能力の同時付与は「ジェム1個だけ」の強化よりはるかに広い。初期の見積もりだけでさらに報酬を上乗せしない。

### 半知の戒律

キャラLv.自体を50に止めず、**スキルノードの解放Lv.が51以上なら取得・効果とも無効**とする。通常攻撃・専用強化・パッシブにも同じ規則を使う。Lv.50の技は許可、Lv.52の専用強化は不可。

報酬は各職の `max(0, 総SP−100)` をEとし、与ダメージとHPへ `1+E/100` を別枠乗算。未使用SPではなく総獲得SPなので、振り直しで攻撃力が変動しない。女神装備や転生由来SPも含む案。現基準の総SP160なら各1.60倍。習得済みスキルの効果と別枠。以後のSPノードが攻防強化にもなるため、報酬単体とSP追加の組合せを測る。

倍率1.5はまず維持する。基準構成は併用時の残りHPが少なく、上記報酬を得た後は突破しやすくなる可能性があるが、まだ報酬込みの実戦は測っていない。

| I | 封印の試練 | 10倍 | 対応職の小支援を他職のソロ試練へ |
| II | 同職I＋強靭2の初クリア | 20倍 | 対応職の強支援を他の試練へ |
| III | 同職II＋女神の本気の初クリア | 100倍 | 対応職の武器・防具エピック効果を初期所持 |

同職I→II→IIIは順に解放する案。強靭2／女神の本気の指定を維持し、これらを「同時選択しなければならない条件」にはしない。ソロIの10倍は、女神の本気を併用しなければ既存の4,050 PT周回と同額。ソロIIで8,100 PT、IIIで40,500 PT。高い表示倍率でも、安定周回との差が必ず10倍になるわけではない。

一方、女神の本気を併用できると順に40,500・81,000・405,000 PTになる。各職間の難度差と、無彩・半知などとの併用は必ず別測定する。6職のソロIやIIを同時に選ぶことはできず、I×II×IIIの重複も禁止。段階は最高の1つだけを適用する。

### 支援の循環と最初の一職

**ソロ報酬を一つも持たなくても最初の一職に勝てる**ことが必要。6職全部が巫女の回復などを待つ循環を作らない。最初の入口候補は自己回復・バリアを持つパラディン。別候補として自前の召喚・回復を持つ巫女を検討し、最終的には実戦で2職以上に入口があることを確かめる。

Iの報酬は「他職のソロ」だけ、IIは他の選択中試練にも有効という解釈案。通常の試練なし周回へ出すかは未決定。IIを取った職はIを置き換え、同じ時刻に両方を重ねない。自身のソロでは自身の支援を出さない。他の5職の支援は共存する案。

ウェーブ開幕に1回、その後ウェーブ開始から10・20・30秒…で発動。ウェーブ切替で時計をリセットし、開始時と最初の更新での二重発動を防ぐ。召喚追加・ゲートの小分け召喚は新ウェーブに数えない。戦闘終了・放棄・ステージ変更で予約・対象・効果を清掃する。

数値の初期候補はIの回復最大HP5%、バリア最大HP5%・3秒、攻撃系100%程度。IIは回復15%、バリア15%・5秒、神楽など5秒以内を上限とする案。10秒間隔で永続バフ・無敵・凍結が連続する設定は避ける。画面外の支援者が持つ架空の装備ではなく、出撃中キャラの基準攻撃・HPから算出し、支援ごとの職補正・威力を固定する。既存スキルを名称だけ借りて最大ランクで無条件発動しない。実装時は採用済み画像を使う。

### ソロIIIの恒常エピック

対応職の武器／防具の2効果を、容量消費なしで初期所持する。全職クリアすれば全12効果が揃う。装着版と同じフラグへ統合し二重適用しない。対応エピックは以後のドロップ候補から除外する案。所持済み個体の扱い、作成・自動装備の候補から外すかも決める。

除外後にエピック抽選が当たった場合は、未取得候補の中から選ぶ方式を候補とする。エピック自体の基本確率は増やさず、全12種除外時はその抽選を不成立にする。他レア度のドロップやPTを勝手に増やさない。

「ジェム禁止中も恒常エピックは有効か」は未決定。恒常報酬なので有効にすると最終的に封印を攻略しやすくなる。無効にすると封印条件を後半まで厳格に保てる。この境界は後から報酬価値を変えないよう、実装前に決める。試練IIIと自身の報酬を使う初クリアの循環は作らない。

## 今後の実装・調整順

1. 半知の戒律と無彩の誓約の報酬定義を確定し、単独初クリア→報酬反映→女神の本気／強靭併用を測る。
2. 支援なしのソロIを6職測定。少なくとも2職に入口を作り、初クリア報酬で他職を開けるかを見る。今回のツールではソロを測っていない。現シミュレーターは戦士を常に生成するため、戦士以外のソロ出撃対応を先に実装する必要がある。
3. 主道限定を先行報酬ありの中盤以降として測定し、報酬・倍率・解放順を確定する。
4. ソロIIの全支援、IIIの初期エピック、封印との併用を順に追加する。
5. 最終女神を30配置。全周回を各設定で最低1回通し、道中の人数必須ギミック・MP枯渇・門・加入・保存・自動化を確認。女神に勝てることだけで全周回クリア扱いにしない。

ルート表は「購入済みノードの総費用／適用済み恒常報酬／今回だけ選択する条件／獲得PT／次の買い物までの周回数」を別列にする。枝分かれを許し、必須の唯一解を作らない。
