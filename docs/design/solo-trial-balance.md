# ソロ試練I〜III：攻略順・混沌の門・PT倍率

2026-10-22 JST。ソロ試練の実装前の設計測定。**後続指示でこの案を[本編へ実装済み](../implementation/sealed-and-solo-trials.md)。以下は設計段階の測定記録で、本編の検証結果は実装文書を参照。**

[封印・転生中盤の設計](sealed-trials-and-progression.md)の続き。**以下の戦闘条件はユーザー指定、支援数値・巫女AI・PT倍率は今回の実装候補値。本編の試練・AI・報酬にはまだ反映していない。**

## 今回確定した条件

- 8,000 PT以下の転生ノード76個をすべて取得済み。闘志・生命は各8（各20倍）。合計費用134,660 PT。
- 猛攻・頑強の恒常報酬で攻撃・HP各1.5倍。強靭2・女神の本気・ゲート解放の恒常報酬も適用済み。
- 先行するジェム封印・スキル制限の報酬を[前回の仮定義](sealed-trials-and-progression.md#8000-pt以下を全取得した追加測定)で適用。装備試練の未確定報酬は加えない。
- Iは1職だけ。IIは同職I＋強靭2の初クリアを前提に、**強靭2を必須で重ねる**。IIIは同職II＋女神の本気の初クリアを前提に、**女神の本気を必須で重ねる**。
- ソロは基本1回ずつ攻略する。稼ぎ用の女神より、同程度の負担に対するPT倍率を少し低くする。
- 次元の門は先のステージの装備を持ち込めるため、重点測定は混沌の門と最終女神。

## 構成と測定方法

全職Lv.100、取得できる装備を全取得。通常ジェムは容量の約半分を実際に装着可能なレジェンダリー・ユニーク・レアで埋める。品質1、地域Lv.10、エピック・ポーションなし。スキルはアクティブ→専用強化→パッシブの固定順でSP内に収める。敵や配置ごとに最適化しない。

混沌の門は通常地域10までの装備を使い、女神装備を持ち込まない。I・IIの最終転生女神では、通常の異次元の女神を先に倒して女神装備を稼げるため、女神装備を許可する。IIIは異次元の女神が両女神同時戦へ置き換わり、初クリア前に女神装備を稼げないため、女神装備なし。III自身の報酬であるエピック2効果を初クリアの入力へ含めない。

この時系列の差で、I・IIの最終戦は総SP320、IIIと混沌の門は総SP260になる。SP超過報酬もそれぞれ3.2倍／2.6倍。比較用の6人パーティーの女神の本気も、初回撃破前の通常装備だけを使う。

測定用アダプターは戦士以外も主キャラの位置へ移し、戦士の仮キャラを除いて**本当に1人だけ**で更新する。敵の照準・範囲・被弾・ウェーブ移行・召喚・MP・AI・バリア・分身は既存の戦闘計算を使う。支援者を味方の人数へ加えない。

戦士→魔法使い→パラディン→忍者→呪術師→巫女の順に全Iを取得し、同じ順で全II、全IIIを攻略する。Iでは先にクリアした職のIだけ、IIでは全I＋その時点までのII、IIIでは全IIを使用する。各職自身の支援は除外。IIIの過去クリア職のエピック効果はその職専用なので、別職の出撃キャラへ転用しない。

## 支援の測定値

I・IIともウェーブ開幕に1回、その後10秒ごと。II取得時は同職Iを置き換え、重ねない。門の小分け召喚は新ウェーブにしない。開幕時に攻撃対象がいなければ、その回の攻撃支援は空振りとなる。支援数値は出撃キャラの攻撃・最大HPを基準にし、出撃していない職の架空の装備や能力を使わない。

| 職 | Iの小支援 | IIの強支援 |
| --- | --- | --- |
| 戦士 | 近い4体へ攻撃力100% | 近い8体へ合計450%の連撃相当 |
| 魔法使い | 近い3体へ120% | 近い8体へ250%＋凍結1.5秒 |
| パラディン | 最大HP5%バリア・3秒 | 最大HP15%バリア・5秒 |
| 忍者 | 近い3体へ70% | 近い6体へ合計240%の投刃相当 |
| 呪術師 | 近い1体の攻撃力−10%・3秒 | 近い8体へ200%、攻撃・防御−20%・5秒 |
| 巫女 | 最大HP5%回復 | 最大HP15%回復＋MP5%回復＋霊威20%の神楽・5秒 |

攻撃支援は追加クリティカルやジェム追撃の発動元にしない。バリアは加算蓄積せず有効中の大きい値を採用。神楽は既存の強い神楽を上書きしない。回復は既存の回復阻害を反映する。各効果の時間は10秒未満であり、常時凍結・無制限バリアにはならない。

測定では連撃・投刃の合計威力を一度のダメージとして計算するため、実装時に複数ヒットへ分けても追加の追撃・MP回復などを発動させない必要がある。画像・モーション・描画は今回の対象ではない。

| 戦士 | 2.85秒 | 3.47秒 | 9.35秒 |
| 魔法使い | 5.02秒 | 9.40秒 | 20.37秒 |

### 巫女のソロ固有問題と修正条件

現行の `Miko.choose` は祭儀の選択条件に「味方3人以上」を含む。このためソロだと神楽・万霊祭儀を自動選択しない。現行AIの巫女IIIは、支援なしも他5職IIありも3/3時間切れ。HPは十分残っており、主因は火力・技の不使用である。

**実装条件に、ソロ出撃中は1人でも祭儀を選択できるAI修正を含める。** HP残量・MP・クールダウン・攻撃契約など他の選択条件は維持する。今回の測定ではアダプター内だけでこの選択を追加し、本編のAIファイルは変更していない。上の巫女I〜IIIの正式測定は、この修正案を使う。

巫女IIIは8,000 PT以下全取得・他5職IIの支援で30/30勝利、中央値177.57秒・最長177.60秒。1回の攻略としては成立するが余裕は少ない。**闘志9だけを14,000 PTで追加**すると30/30勝利、中央値119.17秒・最長119.37秒。生命9や2万PT以下のノード全取得までは要求しない。

難しい職を無理に横並びへ調整せず、「最後に巫女III、必要なら闘志9」を推奨する。ソロ支援の凍結・攻撃低下は敵の手数を減らすため、被弾時MP回復・クール回復との兼ね合いで、支援が増えれば必ず最短時間になるとは限らない。今回も巫女IIIは神楽AIのみ約171秒、全II支援あり約178秒だった。クリア成否は確認済みであり、支援を増やしただけで絶対に強くなるという推論は使わない。

## PT倍率の設定候補

同じ8,000 PT以下全取得・通常装備だけ・封印2報酬の6人パーティーで、女神の本気＋強靭を比較した。最終戦中央値は本気のみ4.3秒、強靭2で8.5秒、3で12.3秒、4で15.2秒、6で22.4秒、8で29.3秒、10で36.9秒。各3配置の比較用測定。PT倍率はそれぞれ10・20・30・40・60・80・100倍。

この範囲で最終戦の時間を負担の代理指標とし、下記の倍率を比較値より低く設定する。味方が減ることによるMP・範囲・ターゲット・生存への影響はソロ実戦へ含まれている。職差は維持し、早くクリアできる職のソロ周回が女神稼ぎより有利にならないようにする。序盤の戦士I・IIは同程度の比較帯に入るため、Iを6倍・IIを8倍として段階差を残す。

| 職 | I | II | III |
| --- | ---: | ---: | ---: |
| 戦士 | **6倍** | **8倍** | **20倍** |
| 魔法使い | **10倍** | **18倍** | **40倍** |
| パラディン | **20倍** | **40倍** | **80倍** |
| 忍者 | **10倍** | **20倍** | **80倍** |
| 呪術師 | **36倍** | **70倍** | **80倍** |
| 巫女 | **48倍** | **70倍** | **80倍** |

**この表はIIの強靭2・IIIの女神の本気を含む総倍率。** IIへもう一度2倍、IIIへもう一度10倍を掛けない。複数職ソロの同時選択は不可。

任意の試練を重ねる場合も、ソロの値を通常の試練倍率へそのまま乗算すると、同じ敵条件のIとIIIで報酬が逆転し、稼ぎ用女神を大きく超える。このため実装候補は **`総PT倍率 = max(表のソロ基準値, ソロ以外の通常試練倍率×0.8)`** とする。強靭は必須分と任意分を同系統の最高段階でまとめ、女神の本気も一度だけ数える。例：巫女III単独はmax(80,10×0.8)=80倍、通常試練が100倍になる併用では全職・全段階とも80倍、通常最大270倍との併用なら216倍。これに通常の恒常PT1.5倍を掛ける。

この非乗算ルールも提案段階。今回の30配置の取得順では任意併用を選んでいないため、表の倍率に一致する。任意の全組合せの戦闘難度・所要時間は今回の合格対象ではない。

高難度のIIIは80倍を上限にし、女神の本気＋強靭10の100倍を稼ぎ側の優位として残す。呪術師・巫女のIIIは比較用女神の上限より長いが、完成報酬のエピック2効果を主な目標とする。PTだけで負担を全補償する設定にはしない。

女神の本気の恒常PT1.5倍を適用すると、試練以外を重ねない初クリアPTは `150×表の倍率`。全Iで19,500 PT、全IIで33,900 PT、全IIIで57,000 PT、合計110,400 PT。全Iの分だけでも巫女III用の闘志9を購入できる。I・II・IIIはそれぞれ1回ずつ取る報酬を主目的とし、その後の継続稼ぎは女神へ戻れる。

表はゲーム本体へまだ登録していない。異なるスキル優先度・エピック入手済み・後の転生ノード購入などで周回時間は変わるため、最終戦の秒数だけから全周回のPT/時間が確定したとは扱わない。封印報酬の確定、支援の本編実装、女神装備の取得に必要な周回時間も含めた実プレイで最終確認する。

## 再現と検証範囲

- ツール：[measure-solo-progression.cjs](../../tools/balance/measure-solo-progression.cjs)。本編のソロ試練の代わりになる測定専用アダプター。
- `node tools/balance/measure-solo-progression.cjs --tier=1`：全職・混沌／最終戦の支援なし予備測定。
- `--tier=1,2,3 --stage=chaos-gate --released`：任意の一括召喚の予備測定。
- `node -e "require('./tools/balance/measure-solo-progression.cjs').route(1,30)"`：Iの取得順を30配置で確認。II・IIIも引数2・3で同様。
- `node -e "require('./tools/balance/measure-solo-progression.cjs').benchmark()"`：稼ぎ用女神の比較条件を測定。同じ入力・戦闘コードの結果があれば再利用。
- `--job=miko --tier=3 --stage=final --solo-ai --support=warrior:2,mage:2,paladin:2,ninja:2,shaman:2 --extra=damage-step-9 --full`：巫女IIIの余裕を持つ構成。
- `node -e "require('./tools/balance/measure-solo-progression.cjs').summarize()"`：既存の測定結果と倍率案を集約する。戦闘を再計算しない。

出力は `output/solo-progression/route-tier-1.json`〜`route-tier-3.json`、`summary.json`、`goddess-benchmark.json`、各配置・入力は `cases/`。同一入力・同一戦闘コードの既存3配置を30配置へ拡張する際は再利用する。

測定モデルのテストは [solo-measurement.test.cjs](../../tests/solo-measurement.test.cjs)。1人編成と各職AIの作動、必須試練、女神装備の時系列、自身のエピック報酬の除外、支援時刻・自職除外・戦闘外停止、ソロ神楽の選択、PTの二重計上と稼ぎ側の優位を確認する。既存の封印モデル3件も回帰確認する。

検証結果：ソロモデル5件＋既存封印モデル3件が合格。取得順の混沌／最終女神1,080戦、巫女IIIの闘志9追加30戦はすべて勝利。全正式配置の撃破数（混沌128体、通常女神1体、両女神2体）を保存済みの結果から照合した。構造・文書リンク検査も合格。

今回の合格対象は混沌の門と最終女神の戦闘モデル。全通常ステージの実周回、ソロ選択UI、初クリア記録、保存・再読込、支援画像・演出、初期エピックとドロップ除外は本編実装時の確認対象として残す。次元の門はユーザー指定で重点測定から除外した。
