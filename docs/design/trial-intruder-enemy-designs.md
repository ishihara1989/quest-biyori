# 試練の追加敵：全10地域のSFデザイン案

2026-10-24 JST。**見た目だけの初稿・未承認・本編未登録**。試練の追加敵を先にデザインし、見た目の確定後にモーション制作へ進むための候補。

## 対象と今回の範囲

「全10ステージの大ボス」を通常10地域の最終ステージ（通算10・20・…・100）の大ボス戦と解釈し、各戦闘に追加する敵を1体ずつ提案する。第10地域の追加敵を「外宇宙の女神」とする割り当ても今回の案であり、まだ実装仕様ではない。

ユーザー指定は全体をSF寄りにすること、ラスボスを外宇宙の女神とし、銀髪のショートボブ・ダークスキン・SFパーツ・全体にスレンダーなシルエットを備えること。これらを見た目の固定条件とする。1〜9の種類・仮称・共通配色は今回の提案。

登場編成の実装、能力、行動、モーション、エフェクト、報酬、解放条件、倍率、保存は今回の対象外。既存の異次元の女神・転生の女神とは別の追加敵として扱う。[試練拡張の背景](reincarnation-system-design.md)も参照。

## 共通の造形

外宇宙由来の機械生命体という方向で、白いセラミック外装、黒鉛色の構造、紫の楕円コアを共通にする。地域の特徴は主に形と差し色で示す。全身に細かな発光模様を増やさず、コアと輪郭を優先する。

既存大ボスと並ぶため、樹木と鹿、多頭竜とカエル、巨人と掘削機、触手とマンタのように輪郭を離す。後半の迫力は単なる大型化だけでなく、浮遊部品・材質・構造の密度で出す。

## 外宇宙の女神の固定条件と提案

- **髪**：顎付近で切り揃えた銀髪のショートボブ。短い輪郭を保ち、髪を長く伸ばして装飾量を増やさない。
- **肌**：暖色の濃い褐色。顔・肩・腕で肌色を読み取りやすくし、白い装甲と銀髪を対比させる。
- **体形**：細い肩幅、長い手脚、縦に通るスレンダーな全身像。大型の肩装甲や幅広いスカートで人体を埋めない。
- **衣装案**：黒〜濃紺の細身スーツ、白いセラミックの襟元・腰部・前腕・脛のパーツ、小さな金の接合部、胸元の紫コア。
- **神格の表現案**：頭と肩の背後に分割された3本の機械的な軌道リング。腰横に身体から離れた長い2枚のフィンを置き、細い本体と大きな余白の両方を見せる。
- **顔の方向案**：落ち着いた余裕のある表情と紫の目。凛とした外宇宙の存在感を軸にする。

初稿はこの方向を可視化したもの。リング径、フィンの長さ、肌の濃さ、顔立ち、装甲量は静止画で調整してから確定する。装飾の動き方・変形・攻撃形態はまだ決めない。

## 初稿の確認と次工程

全体の地域対応、9体の輪郭の差、外宇宙の女神の指定4条件、全身の見切れを静止画で目視確認した。候補画像には細かな陰影や外周の光があるため、後の本編用透過PNG制作ではドット密度・背景の分離・小サイズでの視認性を改めて整える。ゲーム用素材としての合格扱いにはしない。

次は種類や見た目をユーザーと確定し、必要な候補だけ静止画を修正する。**見た目の確定前にモーション制作へ進まない**。
