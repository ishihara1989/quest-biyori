# 戦士スキルとツリー

本編 `game.html` の育成メニュー、および `skill-lab.html` で確認できる。
データは `public/js/skills/warrior-skills.js`、取得・保存は `forest-progression.js`、
戦闘処理は `forest-simulation.js`、共通描画は `warrior-skill-renderer.js`。

- Lv1の連刃とLv5〜100の20アクティブ、計21技。
- 専用強化パッシブ21、一般パッシブ11、計53ノード。
- 戦士の全ノードは5段階。1段階ごとに1SP。Lv1で1SP、レベルアップごとに1SP、Lv100で合計100SP。
- 連刃が未取得でも通常攻撃は1体に命中する。取得Lv1〜5で同時対象1〜5体。通常攻撃はMP不要。
- アクティブ・一般パッシブは前提なし。専用強化だけ対象技のLv1を要求する。
- アクティブ習得はキャラクターLvのゲートであり、以前の技を取る必要はない。
- 専用強化は原則対象技の解放Lv+2で解放。連刃はLv3、最終技のみLv100。
- アクティブLvを上げると威力が1段階につき18%増加。月輪薙ぎは射程+25・角度+18度も増加。
- 専用強化1段階につき、その技の威力+10%・範囲+4%・再使用時間−3%。連刃は再使用の代わりに攻撃動作を短縮。
- 取得レベルでX座標を決め、技・専用強化・一般パッシブを縦に配置。同じレベルは同じX座標。
- ホイールはカーソル位置を中心に20〜180%の拡大縮小。空白ドラッグまたは矢印キーで移動。カメラは取得・選択の再描画でも維持。
- 未解放ノードも選択して詳細・前提・モーションを閲覧できる。振り直しは無料。

## 自動戦闘と確認ページ

習得した全アクティブは個別の再使用時間を持つ。複数が使用可能なら解放Lvが高い技から選ぶ。
MP不足の場合は使用可能な低コスト技、または通常攻撃を続ける。
上記の倍率・MP・再使用時間とパッシブ数値はバランス調整用の初期値。

動き・命中タイミング・対象判定は共通定義を両画面で使用。
既存の振り下ろし・奥→手前・手前→奥・ジャンプ・移動の透過スプライトを再利用し、
座標移動・跳躍・残像・生成エフェクトを組み合わせる。
双閃返し・八荒連閃は開始座標へ戻る。崩牙斬は主標的100%、周囲35%の衝撃。
昇牙連斬は雑魚の打ち上げ、旋嵐剣・剣嵐円舞・戦鬼旋界は巻き込み、着地技はノックバック。
ボスにはこれらの移動・拘束を適用せず、ダメージと戦士のモーションは通常どおり。
絶界十字断の3段目は中心150以内のみ。
Lv100は十連斬り抜け→跳躍→上空で約0.32秒静止→特大着地→遅れて痕跡炸裂。

確認ページは習得条件や本編のセーブに依存せず全技を再生可能。
Lv1〜5・専用強化Lv0〜5・雑魚5体／固定ボス・0.1〜2倍速・前後のコマ送り・時間指定・ループ・軌道表示・エフェクトOFFを備える。
戻しや時間指定は同じ固定乱数の戦闘を再構築し、ダメージと演出の時間を一致させる。

## 保存移行

戦士の取得Lvは `skillRanks` マップに保存し、取得IDの一覧も保持。
旧戦士ツリーのID一覧のみのデータは全額返却。経験値・装備・アイテム・ジェムは保持する。
新方式のデータは5段階・SP予算・習得Lv・専用強化の前提を検証して復元。
魔法使いの既存ツリーは従来の取得段階を保持。

## 素材・検証

`public/assets/skills/warrior/` に21アイコンと6エフェクトを配置。
各エフェクトは4コマ。生成前に各コマの軌道・接地位置・終了状態を指定した2×2単位で生成。
生成元とプロンプトを `source/` と `PROMPT.md` に保存。RGBAを維持し、コマ切り出し・整数配置・最近傍縮小で実装用PNGを作成。
各エフェクトに透過確認用 `review.png` と連続確認用 `preview.gif` を同梱。

`npm run test:warrior-skills` は全技の命中回数、独立取得、SP、保存移行、移動無効、元座標への復帰、MP、個別再使用、固定ステップの一致を検証する。
