# 始まりの森：育成の試作仕様

この文書は2026-10-08時点の試作記録です。2026-10-09以降のレベル・ドロップ・装備ツリー・ジェム・周回・保存仕様は [バランス方針](../policies/balance-policy.md) と現在のコードを正本とします。

実装日：2026-10-08（日本時間）。`progression-design.md` の合意済み構造を基にした、最初のエリアの実装。未決定だった数値・取得条件・容量の帰属は、以下の試作値を使用する。後続エリアの正式仕様ではない。

## 対象と加入

「序盤1ステージ分」は、既存の最初のエリア「始まりの森」の1-1〜1-10として実装した。戦士は最初から使用でき、魔法使いは**1-4「妖花の庭」の初回クリア時に加入**。次の出撃から2人が同時に自動戦闘する。他4人は加入前の表示のみ。

## 能力・レベル

基礎攻撃力・防御力は物理と魔法で共通。ジェムの特化倍率を適用して武器攻撃力・魔法攻撃力を計算し、戦士は武器攻撃力、魔法使いは魔法攻撃力を通常攻撃・攻撃スキルに使用する。HP、MP、MP自然回復、移動速度、攻撃速度、再使用速度、クリティカル率・倍率を表示。防御軽減は `80 / (80 + 防御力)`。攻撃速度は通常攻撃の周期と、通常攻撃・攻撃スキルの予備動作／硬直に作用し、スキル再使用時間は別計算。

敵の撃破経験値は `8 + 区画番号 × 2`、クリア経験値は `区画番号 × 20`。加入済みの全員が同じ経験値を得る。Lv.nまでの累計経験値は `(n − 1) × n × 40`、試作上限はLv.20。レベルでHP・MP・攻撃・防御が成長する。

戦士：HP420 / MP80 / 攻撃34 / 防御4 / MP回復3毎秒。魔法使い：HP300 / MP130 / 攻撃30 / 防御3 / MP回復4毎秒。

戦士の通常攻撃射程は180px（接地座標間、旧値120px）。命中時は射程に24pxの許容を加え、最大3体に命中する。接近完了判定に微小な誤差許容を設け、射程境界で通常攻撃を開始できなくなる問題を防ぐ。

## スキル

各キャラ8ノード（初期スキル1＋習得7）。初期SPは2、レベルアップごとにSP+1。最終ノードは2SP、他は1SP。振り直しは無料。習得した行動は自動使用し、パッシブは常時有効。スキルの個別装備枠は今回追加しない。

| キャラ | 初期行動 | 分岐 |
| --- | --- | --- |
| 戦士 | 旋風斬：攻撃×2.65、MP18、再使用6.5秒 | 剣の心得、疾風の離脱、旋風の軌跡、返し刃、呼吸を整える、不屈、戦意解放 |
| 魔法使い | 風刃：攻撃×2.4、MP16、再使用5秒 | 魔術の心得、集風、風刃の連鎖、風の拒絶、静かな詠唱、風の衣、翠風の共鳴 |

MPが足りない時も通常攻撃を続ける。戦士の離脱は突進・地面攻撃予告に反応して実際に移動し、返し刃は離脱完了後の通常攻撃を強化する。魔法使いは風で軽い敵を集めたり押し出す。ボスの位置は風で動かさない。魔法使いは攻撃中に体を傾けて杖先に光を溜め、340ms後に風の魔法弾を発射する。弾は敵を追い、300ms後の着弾で1回だけダメージと風のエフェクトを発生させる。詠唱・飛行時間はいずれも攻撃速度で短縮する。通常攻撃はMP不要、風刃はMP16を消費し、連鎖習得時は着弾位置の150px以内の別の敵へ最大2体追加命中する。専用スプライトは未制作のため、既存画像に描画上の動きと杖の発光を重ねる。

## 武器・防具の強化

戦士の大剣・革鎧、魔法使いの杖・ローブに、それぞれ**独立した20ノードのツリー**を実装。主道10＋各主道からの枝道10。主道は対応区画のクリアと前の主道取得が条件。枝道は対応主道の取得が条件で、全枝道を永続取得できる。

武器の主道は攻撃力、防具の主道はHP・防御を伸ばす。枝道は攻撃速度・MP回復・容量・装着コスト軽減を伸ばす。区画4・10の枝道は高コストのユニークノード。素材は既存の雫・結晶・牙・花びら・古樹の欠片を使用。詳細な効果・費用は `public/js/core/forest-progression.js` が正本。

| 取得数（各ツリー単位） | 武器 | 防具 |
| --- | --- | --- |
| 5 | 攻撃力+5 | 防御力+2 |
| 10 | 攻撃容量+1 | 防御容量+1 |
| 15 | 得意方向の装着コスト−1、最低1 | 得意方向の装着コスト−1、最低1 |
| 20 | この武器の共通容量+1 | この防具の共通容量+1 |

1-10のクリアと主道10取得で、その装備の次世代解放条件を達成。次のエリア／第2世代のノードは今回の対象外。主道完走と20ノード全取得は別々に表示する。

## ジェム・レア度・リザルト

容量は**装備ごと**に持つ。方向は武器攻撃・魔法攻撃・攻撃・防御・補助、さらに共通容量で不足を補う。初期武器は攻撃3・防御0、戦士は武器攻撃3・魔法攻撃1、魔法使いは武器攻撃1・魔法攻撃3。初期防具は攻撃0・防御3・武器攻撃0・魔法攻撃0。補助は戦士2・魔法使い3、共通はいずれも1。全方向の不足を合算し、共通容量を超える装着を拒否。武器の「攻撃の器」は攻撃容量とそのキャラの得意な攻撃種別容量を各+1する。割引は武器の攻撃／得意種別、防具の防御に適用し、複合ジェムの各方向も最低1を消費する。

能力・装備画面では「武器のジェム」「防具のジェム」を別々の欄に同時表示する。容量・装着状態・装着／解除操作は各装備に独立し、装備強化画面で選択中の武器・防具には依存しない。狭い画面では2つの欄を縦に並べる。

| ジェム | レア度 | 基本容量 | 効果 |
| --- | --- | --- | --- |
| 烈撃 | レア | 攻撃2 | スキル威力+15%、再使用時間+10% |
| 守護 | レア | 防御2 | 防御+5 |
| 息吹 | レア | 補助2 | MP自然回復+1毎秒 |
| 剣撃 | レア | 武器攻撃2 | 武器攻撃+20% |
| 魔導 | レア | 魔法攻撃2 | 魔法攻撃+20% |
| 疾駆 | レア | 攻撃2 | 攻撃速度+12% |
| 生命 | レア | 防御2 | 最大HP+80 |
| 詠唱 | レア | 補助2 | 再使用速度+15% |
| 双極 | ユニーク | 武器攻撃2＋魔法攻撃2 | 武器攻撃+30%、魔法攻撃+30%（同容量の剣撃＋魔導より各50%強力） |
| 翠護 | ユニーク | 防御2＋補助2 | 防御+7、MP自然回復+1.5毎秒（同容量の守護＋息吹を上回る） |

ジェムドロップ率の試作値は通常敵7%、地域ボス24%、トレント40%。ジェムが落ちた場合のユニーク率は地域ボス8%、トレント30%、通常敵0%。各レア度内は均等抽選。装着／解除は無料。同種を複数装着でき、各個の容量と効果を加算する。パーティ全体で所持数を超える同時装着は不可。再読み込み後も装着数を保持する。

アイテム一覧はドロップ品とジェムだけを表示。装備はキャラの強化ツリーに属し、所持品・ドロップ・加入報酬には含めない。アクセサリーは出さない。レア度はコモン白 `#ffffff`、アンコモン水色 `#7ddcff`、レア紫 `#b78aff`、ユニークマゼンダ `#ff4fd8`。雫・牙・花びら・回復薬はコモン。森の結晶はボススライム・ボスイノシシ・アルラウネ限定のアンコモン。古樹の欠片はトレント限定のレア。

道中のルート欄・獲得ポップアップは廃止。獲得品の保存は撃破時に行い、リザルト表示では再加算しない。リザルトには今回の全ドロップ・初回回復薬・道中＋クリアの総ゴールド・経験値を表示。敗北でも道中獲得分を表示。宝箱は0/350/650/1000msから4コマを順に表示、1500msから低レア度順に公開。各品の間隔はコモン250ms、アンコモン360ms、レア470ms、ユニーク580ms、レア度の間は300ms。最終演出後5秒でAUTO再出撃。メニュー中・非表示タブ・一時停止中は進行しない。スキップは全品公開時点へ進める。動きを減らす設定では開いた宝箱と全獲得品を即時表示。

## UI・保存・検証

「能力・装備」「スキルツリー」「装備強化」を画像中心の育成画面に統合。詳細はホバー／キーボードフォーカスのツールチップで表示し、タッチではノードを選んで効果・費用・条件を確認できる。取得ボタンを画面下に固定し、武器・防具は横スクロール。低い画面・スマートフォン幅にも対応。

既存のlocalStorageキー・version 1を維持。旧セーブのゴールド・素材・ジェム・クリア状況・育成を引き継ぎ、1-4攻略済みなら魔法使いを復元する。旧所持品の装備・装飾品は一覧用データから除外。育成変更は進行中の戦闘にも反映し、HP・MPの比率を保持して付け外しによる回復を防ぐ。非表示タブ・メニュー中は戦闘停止、オフライン報酬は既存のまま未実装。

画像は組み込みimage_genで16種類のアトラスを生成。原画・切り出しPNG・全文プロンプトを `public/assets/ui/progression/` に保存。`node tools/assets/build-progression-ui.cjs` で再構築。

宝箱4コマと追加ジェム・結晶9種も組み込みimage_genで生成。原画・コマ・シート・manifest・全文プロンプトを `public/assets/ui/loot/` に保存。追加アイコンは `items/` と `progression/` に切り出す。`node tools/assets/build-loot-ui.cjs` で再構築。リザルトの順序・時刻は `public/js/core/forest-loot.js`、表示は `forest-loot-ui.js`。

検査：`node --test tools/*.test.cjs`。加入、購入条件・素材消費、独立ツリー、SP、複合容量、セーブ移行、MP、攻撃速度、特化ダメージ、2人出撃、範囲強化、ドロップ抽選、報酬順序、透過素材を検証。`node tools/verify/verify-loot-ui.cjs` は実ステージクリア、4コマ、全レア度の公開、AUTO、スキップ、再挑戦、PC／スマートフォン、敗北、動きを減らす設定を独立ブラウザーで検証する。
