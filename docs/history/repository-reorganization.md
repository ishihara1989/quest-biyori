# 2026-10-13 リポジトリ整理

継続する配置基準は [repository-structure.md](../policies/repository-structure.md)、文書の入口は [docs/README.md](../README.md)。

## 変更内容

- `public/assets/` から原画・参考画像・生成記録・配置レシピ・比較図・検収・プレビューを `development/assets/` へ分離。本編用はスプライト・フレーム・背景・UI画像・実行時JSONとプロフィールアニメーションに整理。
- 本編が使っていた砂漠・高原の素材アイコン10点は `public/assets/ui/items/` へ、プロフィールアニメーション6点は各職の `portrait.gif` として登録。元の画像・アニメーションと同じ内容を使う。
- 巫女のカタログは本編の描画情報と、生成・検収を含む開発用カタログに分離。
- 本編実装を `data/`・`combat/`・`skills/`・`render/`・`ui/`・`core/` に分類。検証19画面と専用JS/CSSは `development/labs/` に分離。
- テストを `tests/`、素材ツール・バランス解析・画面検証を `tools/` の用途別ディレクトリへ移動。生成ジョブとプロンプト入力は `development/records/`、旧 `tmp/` の保存済み検証資料は `development/artifacts/legacy/` へ移動。
- 文書を方針・設計・実装・制作・履歴に分類し、一覧と未分類の置き場所を追加。以前のREADMEは開発履歴として保持。
- npmコマンド・モジュール参照・文書リンク・生成元リンクを更新。通常起動は検証ページの旧URLを新URLへ転送し、`start:game` は本編だけを配信。
