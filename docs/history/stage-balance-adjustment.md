# 敵編成・難易度の調整

2026-10-11追記：洞窟以降はウェーブ上限と大ボス基準を更新し、再調整した。最新の設定・判定は [wave-balance-adjustment.md](wave-balance-adjustment.md) を参照。以下の数値は更新前の実装・検証記録。

2026-10-10 JST。ユーザーの追加指示により、森3の序盤緩和を先行し、森・沼地・洞窟・海岸の各地域の2・3・4・6・7・8・9・10、計32ステージを調整した。各地域の1・5は想定上容易なステージとして、編成・HP・火力をそのまま保存する。

## 本編への適用

- 森3はイノシシ12体→8体。3体、3体、ボス＋2体の3ウェーブにし、敵火力を抑える。適正メインの討伐中央値は54.5秒、前ステージまでのメインでは約57秒。両条件30/30勝利。
- 他の31ステージは雑魚とボスを別のウェーブに分ける。ボス1体なら雑魚を最初の2ウェーブへ、ボス複数なら雑魚→中ボス→最後のボスと進める。最後のボスを雑魚の集中攻撃から切り離す。
- 敵HPと火力をステージごとに固定する。仲間や解放済みアクティブ、範囲攻撃の実際の火力を含めて、適正強化では長期戦に勝利し、装備が10段階遅れると難しくなるよう調整する。召喚された敵にも同じ倍率を適用する。
- 森3以外では敵の種類別総数とクリアゴールドを保存する。ドロップ確率、基本編成1クリア当たりの期待素材・ゴールド、装備費用を維持する。戦闘時間が延びる分、1分当たりの獲得量は変わる。追加召喚による獲得量も戦闘時間に依存する。

設定は [forest-data.js](../../public/js/data/forest-data.js) の `STAGE_TUNING`。`hp` / `damage` は既存のステージ内倍率 `1 + (地域内番号−1)×0.1` と掛け合わせる絶対倍率で、旧 `enemyHp` / `enemyDamage` を置き換える。敵の基礎値とプレイヤーの成長・装備・スキルは変更しない。実プレイヤーの現在強化へ追従する倍率ではない。

## 基準と判定

全員を通算ステージ番号と同じレベルにし、挑戦開始時に加入済みの仲間のみ参加する。アクティブを解放順に各最大ランクまで取得。通常攻撃は標準ランク1、枝・終端・ジェム・薬・パッシブ・専用強化は使用しない。

| 条件 | 装備 | 合格条件（各30配置） |
| --- | --- | --- |
| 適正 | 当該ステージまでの全地域の武器・防具メイン | 30/30勝利、討伐中央値45〜90秒、全員生存27/30以上 |
| 初回攻略 | 前ステージまでの同メイン | 30/30勝利 |
| 10段階遅れ | 10ステージ前までの同メイン | 勝利1/30以下。通算10以上で判定 |

適正の最大単発被害は対象キャラ最大HPの30%以下も確認する。勝利時の前衛残HP中央値25%を探索の目安にするが、合格条件の固定範囲にはしない。敵の攻撃が戦士・パラディンに集中するため、パーティー合計残HPだけで苦戦度を判定すると、前衛が倒れても合計値が高く残る。合計HP、前衛の低い方の残HP、全員生存数をそれぞれ記録する。

本編の戦闘シミュレーションで配置seed 0〜29を固定し、100msずつ最大180秒まで進める。召喚・回復・無敵・MP消費・移動・技の競合を含み、時間切れは勝利に数えない。有限配置の回帰検査であり、すべての乱数に対する保証ではない。

```sh
npm run audit:stage-balance
npm run test:stage-balance
```

[検証表](../../output/balance/stage-tuning-verification.md) と [全戦闘のJSON](../../output/balance/stage-tuning-verification.json) は再生成可能。検査が未達ならコマンドは終了コード1を返す。回帰テストは同じ戦闘基準に加えて、調整対象外の8ステージと素材予算の保持を確認する。

## 適用後の結果

| 条件 | 検証数 | 勝利 |
| --- | ---: | ---: |
| 適正メイン | 32ステージ×30配置 | 960/960 |
| 初回攻略 | 32ステージ×30配置 | 960/960 |
| 10段階遅れ | 通算10以上の対象25ステージ×30配置 | 1/750 |

適正のステージ別討伐中央値は46.4〜77.4秒。全員生存は951/960戦、最も低いステージでも28/30戦。最大単発被害率は5.9%。10段階遅れの内訳は748敗北・1勝利・1時間切れで、唯一の勝利は沼地4のseed 13。全ステージで上記の判定に合格した。

パッケージに登録した全236テストが通過。森の育成・周回画面、沼地の編成・召喚・進行、洞窟／海岸の戦闘・地域切替・モバイル表示をブラウザーで検証し、画面エラーもなかった。回帰テストが実際に動かした2670戦から検証表を出力し、掲載倍率と本編の設定が一致することも確認した。

## 共通式への移行

[balance-formulas.md](../design/balance-formulas.md) の20%成長、1ノード1〜3%の予算、旧地域全取得＋ジェムで20先を飛ばせない上限、スキルのリスク補正、比率による防御式は提案段階。この変更は現行の装備・スキル・ダメージ式を前提にした敵の調整なので、これらを適用した時は同じ検査で倍率を再計算する。
