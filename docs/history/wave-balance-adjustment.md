# ウェーブ上限・巫女加入後の難易度調整

2026-10-11 JSTのユーザー指示を適用。育成・ドロップ・装備費用・周回は [balance-policy.md](../policies/balance-policy.md) の2026-10-09方針を維持する。

2026-10-12に行動妨害と予告攻撃の被害を変更した。以下は変更前の記録。現在の予備動作・累積抵抗・能力補正・検証条件は [行動妨害の実装](../implementation/action-interference-implementation.md) を参照する。

## 適用範囲

- 森・沼地は全20ステージの編成、HP、火力、報酬を維持する。両地域の大ボスも変更しない。
- 洞窟・海岸は最大4ウェーブ、古代遺跡は最大5ウェーブ。最大数に固定せず、敵の同時攻撃数、範囲攻撃の効率、MPと支援の持続を含めて編成を選ぶ。
- 各地域の1・5は従来の容易な3ウェーブを維持する。
- 洞窟以降の通常難所24ステージはHP・火力・編成を再調整する。敵の種類別総数とクリア報酬を維持し、基本編成の期待素材量・ゴールド・装備費用を変えない。追加召喚分と時間当たりの獲得量は戦闘時間に依存する。
- 敵の倍率はステージ固定。実際のプレイヤーのレベルや装備を読んで追従させない。巫女の回復・バリア・攻撃と他キャラの性能は変更しない。

設定は [forest-data.js](../../public/js/data/forest-data.js) の `STAGE_TUNING` と [ruins-data.js](../../public/js/data/ruins-data.js) の `TUNING`。`waveCount` はそのステージのウェーブ数。雑魚とボスを順に分け、最後のボスは単独にする。`hp` / `damage` は従来と同じ絶対倍率。`majorBossHp` / `majorBossDamage` を指定した場合は大ボスのみに追加で掛ける。

ステージ選択のウェーブ数、戦闘HUDの分母、進行マークも実際の編成数から表示する。

## 判定

全員のキャラレベルは通算ステージ番号に固定し、挑戦開始前に加入済みの仲間だけを使う。アクティブは解放順に最大ランク、通常攻撃ランク1。枝・終端・ジェム・薬・パッシブ・専用強化は使用しない。

「基準レベルから5レベル下の装備強化状態」は、キャラレベルとスキルを基準に維持し、武器・防具の主道を5ステージ前までにした状態として判定する。

| 条件 | 判定（配置seed 0〜29） |
| --- | --- |
| 適正装備 | 当該ステージまでの主道、30/30勝利、討伐中央値45〜90秒 |
| 初回攻略装備 | 前ステージまでの主道、30/30勝利 |
| 通常難所の生存 | 適正装備で全員生存27/30以上、最大単発被害30%以下 |
| 洞窟・海岸・遺跡の大ボス | 装備5段階遅れの勝利3/30以下、適正装備の最大単発被害35%以下 |
| 森・沼と洞窟以降の大ボスの装備10段階遅れ | 勝利1/30以下 |
| 洞窟以降の通常難所の装備10段階遅れ | 参考測定として勝率を記録する |

大ボスは適正装備でも戦闘途中の死者を許容する総力戦に更新する。全員生存率も記録するが、勝率・前衛残HP・討伐時間と合わせて判断する。通常難所と森・沼の生存基準は維持する。

2026-10-10の「通常難所も装備10段階遅れで勝利1/30以下」という目標には未達が残る。今回の洞窟以降の通常難所はこの測定を合否条件から外し、適正・初回の全勝と適正の全員生存を優先する。古い装備の完全な通行止めは今回指定された大ボスで厳格に判定する。検証表は通常難所の10段階遅れの勝率も省略せず掲載する。

本編と同じ固定ステップの戦闘を100msずつ最大180秒まで実行する。召喚、無敵、状態異常、MP、回復、バリア、移動、技の競合を含む。時間切れは勝利に数えない。30配置は回帰検査であり、全乱数に対する勝利保証ではない。

バランス回帰テストは実際に実行した戦闘から [検証表](../../output/balance/stage-tuning-verification.md) と [全戦闘JSON](../../output/balance/stage-tuning-verification.json) を生成する。森・沼と容易な1・5の保存、全ステージの種類別総数・報酬、4・5ウェーブを最後まで進めた場合のクリア1回と敵能力倍率も検査する。UI検査は独立した保存領域で行い、PC・390px幅の画面を `output/balance/wave-ui/` に保存する。

## 大ボスの実測

| 大ボス | ウェーブ | 適正装備 勝利 | 初回攻略 勝利 | 装備5段階遅れ 勝利 | 適正討伐中央値 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 洞窟10・ケイブトロール | 4 | 30/30 | 30/30 | 0/30 | 67.8秒 |
| 海岸10・クラーケン | 4 | 30/30 | 30/30 | 0/30 | 63.0秒 |
| 遺跡10・古代機兵タイタン | 5 | 30/30 | 30/30 | 3/30 | 53.2秒 |

タイタンの装備5段階遅れで勝利した3配置はいずれも生存者1人、前衛残HP0%。討伐中央値84.1秒。5段階遅れと10段階遅れの時間切れを勝利に混ぜていない。適正装備でも洞窟・海岸の全員生存は0/30、遺跡は10/30で、前衛の損耗を伴う総力戦になる。

生成時のタイタンはHP218,120・攻撃力4,807、クラーケンはHP141,360・攻撃力825。タイタンのHPは海岸大ボスの約1.54倍、攻撃力は約5.83倍。実際の被害は技の倍率、防御、無敵、巫女のバリアを含めて検証している。遺跡7は最終確認で火力倍率16→15に抑え、適正・初回の全勝と通常難所の生存基準を維持する。

## 最終確認

`npm test` は311/311通過。バランス検査は40ステージ・3,480戦、適正1,200/1,200勝利・初回1,200/1,200勝利。討伐中央値45.8〜84.8秒、通常難所の全員生存は最低27/30。遺跡7は28/30に改善した。全検証行の倍率と本編設定の一致を確認した。

通常難所の装備10段階遅れという旧目標は14ステージで未達。この結果も検証表・JSONへ掲載している。全体検査の合格は上記の更新後の判定に対するものであり、旧目標まで達成したという意味ではない。

`npm run check:wave-balance-ui` は4・4・5ウェーブの分母、進行マーク、ステージ詳細、最終ウェーブ後の結果表示、PC/390px幅、ページ・画像エラー0件を確認。`git diff --check` も通過した。[最終のテストログ](../../output/balance/npm-test.log)、[集計JSON](../../output/balance/wave-balance-summary.json)。
