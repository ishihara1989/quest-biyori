# 行動妨害の実装

2026-10-12 JST。[設計案](../design/action-interference-design.md)を本編・スキル検証画面へ適用した。回避経路の改善は含めない。後続の[ジェム再設計](gem-system-implementation.md)で固定「破勢のジェム」を更新し、ユニーク以上のランダム能力へ行動妨害力と妨害抵抗貫通を追加した。以下の旧ジェム単体の数値は検討経緯として残す。

## 妨害と累積抵抗

命中ごとに `max(0, 妨害力 − 妨害抵抗力)` を、現在の予備動作の残量から引く。味方全員で残量を共有する。0になった時点で、未発動の攻撃・召喚・潜行プランを破棄する。通常のスタンとは別の判定で、大ボスにも適用する。

```text
ヒットの妨害力 = 基礎値 × (1 + 0.05 × (ランク − 1)) × (1 + 装備・ジェムの増加率)
抵抗力 = 基礎抵抗力 × (1 + 0.25 × 成功中断回数) × (1 − 抵抗低下率)
容量 = 基礎容量 × (1 + 0.15 × 成功中断回数)
```

中断するたびに、その個体の次の予備動作の抵抗力・容量が増える。上限や時間減衰は設けない。次の行動で残量は満容量へ戻る。中断失敗では回数を増やさない。新しい敵個体では0回から始める。

抵抗低下は最も強い有効効果を1つ採用し、上限35%。呪術師の脆弱の呪いは20〜30%、魂穿ちは30〜35%・4秒、魂封じの陣は25〜35%・最終命中から2.1秒。ミスでは付与せず、命中した同じ攻撃の削りから適用する。

通常攻撃・継続ダメージ・分身・派生反射には妨害力を付けない。同じ一撃で本体と部位へ当てても1回だけ削り、別ヒットは別々に加算する。無敵・ミス・予備動作終了後の命中は削れない。準備中の行動を通常の行動停止や押し出しで無期限に遅らせることも防ぐ。

## 予備動作と失敗時の被害

- 雑魚の対象技は最低2秒、ボスは最低3.8秒。森の大猪・アルラウネ・トレントと、沼の一般ボス（キングトード・泥巨人・リッチ）は5秒。防護スキルや回復役が揃う前の攻略で、初期の妨害技が間に合う時間を作る。
- パラディン加入後のボスの予告攻撃は、最初の一撃が適正レベル・前ステージまでのメイン装備のHPの50%相当。一般ボスの連撃の残りは合計20%相当に分配する。大ボスは後続へ合計60%相当を分配し、後続の一撃は40%までに抑える。
- 加入前の森のボスは最初30%・後続合計12%、雑魚は最初10%・後続合計4%。数の多い敵や妨害担当が未加入の攻略に、全予告を止めることを要求しない。
- この値は固定の育成基準を使う。実際の最大HPを上げても敵の威力は増えない。基準防御力で上記の被害になり、実際の防御力・軽減・バリア・敵への攻撃弱化を適用する。
- 通常攻撃は従来の威力を使う。予告攻撃を避けた場合は被害なし。潜行からの部位出現にも、予告地点への初撃を付けた。

予告の開始から再行動までの最低間隔は、雑魚が予備動作＋5秒、一般ボスが予備動作＋9秒、森のボスが予備動作＋20秒。大ボスはヒュドラ＋9秒、クラーケン＋1秒、古代巨人＋2.5秒、その他＋3秒。実際の動作がそれより長い場合は動作終了を待つ。中断しても再使用待ちを巻き戻さない。

大ボスの出現直後は従来の初期待機に8.5秒、古代巨人は12.5秒を加算する。前ウェーブからの防御・MP回復の準備時間を作る。森・沼で同時出現する一般ボスは、初回行動を6.5秒ずつずらす。編成と能力倍率は保持する。

古代巨人のビームは半幅95、砲撃は半径160とし、砲撃の2発は後衛から狙う。ベヒモスの潜行も後衛を狙い、着地地点を準備開始時に固定する。前衛だけの防御で長期戦を無傷にできないようにし、実際の範囲と予告を一致させる。

Lv30の旧ホーリースピアを、素早い単体技「断行槌」に置き換えた。神聖属性、1 Hit、威力×3、範囲220、MP20、再使用8秒、基本命中240ms、動作660ms。既存のスキルID `spear` と専用強化IDを保持し、習得・強化済みセーブを引き継ぐ。

パラディン・戦士・忍者の武器は、洞窟以降の各地域のメイン8・9段目に妨害力＋12%ずつ、ユニーク枝に＋4%・6%・10%を追加した。森・沼のメイン、費用、ノード数は維持する。メインにも伸びを持たせ、希少品を初回攻略の必要条件にしない。ユニーク「破勢のジェム」は妨害力＋25%、MP自然回復＋0.6/秒、容量4（攻撃2・補助2）。既存のユニーク抽選枠に追加し、レア／ユニークの絶対ドロップ確率を変えない。

妨害対象のスキル選択に、抵抗減算と命中までの時間を反映した。パラディンは単発で止められる技と、時間・MPが足りる2技の連携を優先する。同時に複数の予備動作がある場合は、高抵抗で仲間への被害が大きいものへ重い一撃を回す。防御は予備動作・弾の飛行時間・連撃の長さを見込み、通常攻撃や不十分な妨害技で防御が遅れないようにする。

大ボスとの戦闘では防御に必要なMPを温存し、妨害の連携や倒し切れる攻撃は優先する。倒し切れるかの判定には敵の防御力、妨害の予測には命中までの抵抗低下の期限も含める。重い技は次の予備動作が終わるまでに再使用できる場合に通常の攻撃にも使う。イージスガードはMP24・再使用10秒・軽減65%。

## 予告表示と演出

森・沼・洞窟・海岸・遺跡・砂漠の共通表示として、円または帯で予告範囲を表示する。照準は予備動作開始時に固定し、飛び道具の着弾地点もそれに合わせる。複数地点への攻撃は全地点を示す。

敵の上に残量バー・盾アイコン・中断回数を表示する。低抵抗は紫、重い攻撃は橙系で表示し、マウスオーバーで抵抗力・容量・残量・中断回数・予備動作秒数を確認できる。削り・抵抗・中断に別々の視覚反応を付ける。スキルとジェムの効果欄は効果名と数値だけを表示する。

断行槌は内蔵ImageGenで4コマのキャラクターモーションと4コマの金色の盾破砕エフェクトを生成した。元画像・座標計画・プロンプトを各 `source/` に保存し、透過PNGを最近傍で切り出した。接地位置、武器の見切れ、コマ送り・連続再生を確認した。

- モーション: `public/assets/paladin/motions/break-strike/`
- エフェクト: `public/assets/skills/paladin/effects/break-impact/`
- モーション原画・プロンプト: `public/assets/paladin/motions/break-strike/source/`
- エフェクト原画・プロンプト: `public/assets/skills/paladin/effects/break-impact/source/`
- 再構築: `node tools/assets/build-interference-assets.cjs`
