# 装備強化の自動取得・解放通知（2026-10-12）

- 森10クリアで、オプションの装備強化自動取得を解放。新規・既存セーブとも初期OFF。
- ノード種別（メイン／サブ／ユニーク）、キャラの順に優先度を判定。各一覧の上下ボタンで並べ替え、チェックで対象から除外できる。未加入キャラの設定は加入後に適用。
- 武器・防具、全地域を対象にする。素材・ゴールド・クリア条件・前提ノードは手動購入と共通。取得できない候補は飛ばし、次に取得可能な候補を選ぶ。優先候補のための素材予約は行わない。同条件では低いステージ・浅いノード・武器の順。
- ON切替時、クリア時、素材変換時と通常画面の1秒ごとに最大24ノードを取得。メニュー表示中は定期取得を止め、設定の編集・手動購入を妨げない。設定はセーブ・リセットに対応。
- 各地域1クリアで装備強化ページを解放。それまでは地域ページに解放条件を表示。
- 初回クリアで実際に解放された素材変換レシピ、装備強化ページ、自動取得オプション、ジェム工房、次の地域を通知する。素材の所持数で通知の有無は変わらない。
- 結果表示は加入（4.6秒）→解放（3.2秒）→宝箱。加入演出のサイズ・粒子数・表示時間を最大に維持。解放を結果画面にも残し、自動周回は報酬表示後に始める。演出短縮設定とキーボードのフォーカス移動に対応。

検証：`npm run test:auto-gear`、`npm run check:auto-gear-ui`。既存の育成・戦闘・素材変換・報酬テストも実行。
