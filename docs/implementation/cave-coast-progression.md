## 固有攻撃

各敵の通常攻撃と固有攻撃を順番に選び、固定60Hzの戦闘時計で作用点を処理する。構え・命中・復帰の途中で攻撃時計をリセットしない。予告の円、線、扇形は着弾範囲を表示する。

| 敵 | モーションと作用 |
| --- | --- |
| コウモリ | 噛みつき、扇状の超音波 |
| 大コウモリ | 噛みつき、超音波、吸血、急降下突進。吸血は実際に減ったHPの65%を回復 |
| ワーム | 噛みつき |
| ラージワーム | 噛みつき、尻尾を埋めて標的付近から出す |
| 蜘蛛 | 近接攻撃、クモ糸弾 |
| アラクネ | 手の爪による近接攻撃、クモ糸弾、飛爪。成人女性の上半身はアルラウネを参考に量感を増やした原画を基準に統一 |
| ケイブトロール | 棍棒振り下ろし、岩石投げ、地面をえぐる土塊飛ばし、踏み込み地震、3連続振り下ろし。攻撃後1.6秒、連打後3秒の休息 |
| ヤドカリ | ハサミ攻撃 |
| オオヤドカリ | ハサミ攻撃、殻にこもる、殻の回転突進。殻にこもっている間の被ダメージ30% |
| リザードマン | 槍の突き |
| ボスリザードマン | 槍の突き、薙ぎ払い、尻尾の範囲攻撃 |
| タコ | 触手、墨弾 |
| スキュラ | 成人女性の上半身と8本の触手。触手叩きつけ、泡弾 |
| クラーケン | 触手叩きつけ、墨弾、触手を埋めて標的付近から出す、水流の扇状ブレス |

飛び出た尻尾・触手は独立した攻撃対象として敵一覧へ追加する。小さな金色の接地リングで攻撃対象を示す。受けた攻撃はクリティカルや防御を二重計算せず本体へ1回転送する。本体撃破または7秒経過で消え、追加の経験値・素材・ゴールドを出さない。生存中は1.4秒ごとに近接攻撃する。

| 状態異常 | 時間 | 効果 |
| --- | --- | --- |
| クモ糸 | 3.5秒 | 移動・通常攻撃時計・技の動作速度55% |
| 墨の目潰し | 3秒 | 攻撃の命中率50% |
| 泡の拘束 | 2.2秒 | 動作を中断し、移動・攻撃を停止 |

対応する透過画像を対象に重ねて状態を表示する。被弾・撃破モーションも全14種に実装。戦闘中のスキルによる吹き飛ばし・拘束・打ち上げは敵の攻撃を中断する。

## 育成・報酬

[2026-10-09のバランス方針](../policies/balance-policy.md)を維持する。各キャラクターの武器・防具は、各地域メイン10・枝80・終端10の計100ノード。前地域のメイン10が次地域の入口条件。100ノード全取得は各地域10の期待ドロップ約300周、武器・防具のメインの合計費用は対応ステージ約3周以下。後続地域の全取得でも共通ジェム容量を1ずつ増やす。

コモン素材は雑魚30%・ボス100%、地域結晶はボス30%・大ボス100%、レア素材は大ボス30%。ジェムはボスのみレア5%・ユニーク0.5%。洞窟は牙・外殻・糸・洞窟の結晶・トロールの巨岩、海岸は殻・鱗・墨袋・海岸の結晶・クラーケンの真珠を使う。

経験値は `{level, progress}` のレベル内正規化進捗。累積経験値を計算しない。地域10では直前レベル→想定レベルに1クリア、次のレベルには3、9、27…クリア。獲得量が3^(-20)以下なら0、画面は％表示。
