# 混沌の門

2026-10-15 実装済み。魔王城10（通常ID 100）クリアで解放するやりこみ用の特殊ステージ。IDは `chaos-gate`。通常100ステージの進行順から独立し、特殊ステージ画面で次元の門と選び分ける。

## 解放・戦闘・接続

- 魔王城10の初回クリア時に専用の赤・金の解放演出と門の画像を表示する。再クリアでは繰り返さない。
- 次元の門と同じ開門→召喚→閉門→全滅待ち→再開門／破砕の状態遷移を共用する。門は無敵・攻撃対象外・ドロップなし。
- 雑魚は地域6〜10の3系統を各7体、35体ずつ3回で105体。ボスは各地域1体ずつを3回で15体。大ボスはベヒモス、マンティコア、マンモス、ドラゴン、魔神の5体。門3体を含めて128体。
- 黄金のファラオとアークデーモンの追加召喚は特殊ステージ内で抑止し、固定の125体を維持する。通常地域では元の挙動を保つ。
- 敵の能力は雑魚＝魔鎧兵、ボス＝黒騎士、大ボス＝魔神の基本HP・攻撃・防御へ正規化し、元の行動・速度・射程・素材・ゴールドを維持する。門専用倍率はHP 1500、攻撃2000、大ボス補正はHP／攻撃1、防御4900。
- 同じステージ周回では混沌の門を維持する。2026-10-15の[異次元の女神の追加](extradimensional-goddess.md)後、次ステージへ進む設定ではクリア後に界外の御座へ進む。敗北は魔王城10へ戻り、同じステージ周回に切り替える。OFFでは結果画面で止まる。解放・選択・クリア・装備・所持品を既存セーブへ保存する。
- 経験値は通常ID 100相当の正規化進捗を使い、Lv.100ではMAXを維持する。初回の回復薬・専用アイテム・加入報酬なし。

## 報酬

- 素材は倒した敵の地域6〜10から通常確率。トレハンの確定分＋端数抽選を維持する。
- ジェムは全てLv.10。ボス・大ボスのレア10%、ユニーク1%、レジェンダリー0.1%の排他的抽選。通常の2倍で、トレハン倍率を追加で掛ける。雑魚・門からは落ちない。
- 2026-10-17の増員後は撃破12,275G＋クリア12,000G＝**24,275G/周**。双方にトレハン倍率を掛け、端数を繰り越す。
- 地域6〜10のツリー各1本、合計500ノードの定価は4,175,500G。素材変換で余剰結晶を不足素材へ回すと約190周で素材が揃う。この時点の4,612,250Gは定価を約10.5%上回り、素材を揃える周回でゴールドも消費できる。6職・武器／防具で費用は共通。取得数割引は既存仕様を維持する。
- 通常の魔王城10のクリア報酬2,000Gを使うと同じ190周で1,463,250G不足するため、特殊ステージ専用の増額とする。

## 画像・演出

新規の背景 `public/assets/stages/chaos-gate/background.png` と透過門 `gate.png` を採用。組み込みimage_genで生成した原画・全文プロンプト・登録記録は `development/assets/stages/chaos-gate/` に保存する。赤い混沌空間、浮遊する黒曜石の足場、金の稲妻、黒曜石の閉じた両開き門という指示で制作。プロンプト全文は `sources/prompts.json`。

背景は1024×576、門は512×512。門の透過余白を保持し、最近傍縮小と32pxの透明余白追加で登録する。画像生成によるモーション分割はなく、開閉・召喚・ひび割れ・破砕は既存のCanvas描画を共用する。次元の門の紫・青、混沌の門の赤・金を切り替える。資料館にも3種類の門と全状態・演出を登録する。
