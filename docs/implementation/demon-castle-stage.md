# 魔王城：宵闇の玉座の本編実装

2026-10-15 JST。地域10・通算91〜100を本編へ追加。火山90のクリアで91を解放し、進行設定では100まで自動進行する。100では同じステージを周回する。敗北では1つ前へ戻って同一周回へ切り替え、OFFでは結果画面で停止する。

## 地域と素材

魔鎧兵・インプ・夢魔、黒騎士・アークデーモン・リリス、魔神の7種。3〜5ウェーブの10ステージとし、通常ボスは別ウェーブに置く。91と95は入口・素材集め用の短い戦闘。100の基本編成はコモンABCの期待値3.2・3.1・3.1個、地域結晶1.9個、レア0.3個。召喚インプも通常の報酬抽選を行うが、基本素材予算には含めない。

[6体とFXの検収済み素材](../production/demon-castle-motions-status.md)と[二腕・無面・浮遊の魔神](../production/demon-god-redesign.md)を採用。48本体モーション＋17FX、237コマを本編用PNG・アトラスへ登録した。原画・検収GIFは開発側に保持し、本編からロードしない。画像のRGBAは全コマで元の検収PNGと一致する。

魔神の危険技4種のみ、検収済み準備ポーズの保持を実際の予備動作へ延長。発動・復帰の順と画素を維持する。敵の全モーション・背景・5素材アイコン・地域テーマ・鍛冶・ジェムLv.10・素材変換・資料館に接続した。

各職の武器・防具は地域ごとに100ノード。魔王城の根を火山主道10へ接続。主道の素材順、ABC各433個・レア90個・約300周の予算を維持し、主道の同段階の武器＋防具を各ステージ約3周以内で取得できる。

## 危険行動と状態

13種の危険技を既存の共通妨害へ登録。雑魚2.6〜2.8秒、ボス4.4〜5秒、魔神4.6〜5.6秒の予備動作。照準と円・扇・帯を開始時に固定し、同じ図形で判定と予告を描く。危険行動の中断では未発動の後続・召喚・状態異常を破棄し、発射済みの弾は残る。

- 呪い：回復量−25%、4秒。上書きで延長し、重複減算しない。
- 睡眠：1.5秒まで。動作を一時停止し、直接被害で解除。継続被害では解除しない。
- 沈黙：1.5秒まで。特殊技の新規開始を禁止し、通常攻撃・進行中の技・既存の精霊は継続。
- 睡眠・沈黙は同時1人まで、1人生存時は付与しない。解除後3秒の免疫、浄化・聖域・既存の状態免疫に対応。
- 悪魔の援軍：5秒で2門、5.5秒でインプ。同時2体・1戦2回まで。

火傷・破甲は火山の既存処理を再利用する。各行動の初撃・後続・火傷は共通の固定育成基準と行動予算で算出し、味方の現在最大HPへ追従しない。リリスの闇花は1人2発まで、終焉の最後の輪は基準HP10%以下。

魔神はHP70%・35%で次の行動開始時にフェーズを切り替える。断界・三界魔柱、終盤の封声・交差二帯＋薄い輪を使い、その間に拳撃を挟む。HPを回復せず、中断回数も保持する。

## レベル上限

全職のレベル上限を100とする。99→100に到達すると余剰進捗を0へ戻し、以後のクリアでは経験値・SPを増やさない。上限ではEXPをMAXと表示する。保存形式は既存の `{level, progress}` を維持し、レベル100以上の保存値を100・進捗0へ補正する。巨大な追いつき報酬でも正の巨大な累乗を計算しない。
