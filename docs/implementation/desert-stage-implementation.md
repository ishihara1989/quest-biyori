## 戦闘と段階的な演出

| 敵 | 攻撃・演出 |
| --- | --- |
| サンドスコーピオン | 鋏の一撃、尾突きと緑の毒液 |
| 包帯兵 | 曲刀の斬撃、包帯から放つ砂縛り |
| 砂蛇 | 砂弾、後退しながらの射撃 |
| オブシディアンスコーピオン | 広い鋏の薙ぎ払い、3連の毒針、2発の毒弾、休息 |
| 黄金のファラオ | 青緑と金の魔法波、2地点の砂縛り、包帯兵召喚、休息 |
| ラミア | 3連射、尾の薙ぎ払い、2地点の砂縛り、休息 |
| 砂喰いベヒモス | 構えから突進、前脚の叩きつけと地割れ、砂の咆哮、浅い潜行、長い休息 |

雑魚は小さな着弾、通常ボスは連撃・広い衝撃・魔法波、大ボスは岩と砂の大きな衝撃・画面振動・地割れへ段階を上げる。地割れはHP半分以下で3方向から5方向へ増える。攻撃エフェクトとキャラクターの上に予告を描画し、対象位置・攻撃範囲を確認できる。

通常ボスの予告は1.0〜1.2秒、大ボスは1.2〜1.5秒。構え開始時に位置・方向を固定し、味方を追い続けない。連撃は発射・命中時刻を分ける。地割れの線が重なっても同じ味方への被害は1回。突進は240ms、浅い潜行は800msで移動し、潜行後に1.5秒以上の復帰時間を持つ。背中は見えたまま全職の攻撃対象になる。

毒は敵攻撃力×0.12を1秒ごと、4秒。重複せず更新時に次tickを早めない。砂縛りは移動−35%を3秒、攻撃・支援は継続。浄化で解除し、聖域内では新しい状態を付与しない。死亡・ウェーブ終了・戦闘終了時に状態・弾・予告を解除する。蛇の後退も移動拘束に従う。

ファラオの召喚は同時2体・1戦2回まで。通常ボスは独立ウェーブに分け、砂漠全体で最大5ウェーブ。6-1と6-5は容易な3ウェーブとして残した。

## 育成と進行

[2026-10-09の方針と後続更新](../policies/balance-policy.md) を維持。経験値はレベル内の正規化進捗、素材とジェムの確率も共通ルールを使う。

素材は鋏・包帯・蛇鱗・砂漠の結晶・ベヒモスの角。最初のステージからコモン3系統を出し、装備主道の要求順を「なし、A、B、C、ABC、AB、AC、BC、ABC、D」に保つ。召喚分を費用の期待値に含めない。6人の武器・防具は各100ノード、ABC各433個・レア90個。武器と防具の同段階の主道は期待3周以内、全取得はツリー1本あたり約300周。

遺跡主道10から砂漠主道1へ接続。砂漠の基本能力上昇は沼地ツリーの2.6倍、主道のみ段階ごとに `1 + 0.2 × (段階−1)` を追加で掛け、後半の育成効果を上げた。費用・枝・容量の共通ルールは維持する。装備の表示名・所持ノード・容量・変換・ステージ60までの保存を拡張した。砂漠装備のアイコンは既存の遺跡用装備絵を共用する。

自動進行は遺跡10→砂漠1。砂漠10クリア後は同ステージ周回。敗北時は一つ前へ戻り同ステージ周回に切り替わる。
