# 次元の裂け目 / 次元の門

2026-10-12 実装。バランスの共通方針は `balance-policy.md` を維持する。

## 特殊ステージ

- 遺跡10（通常ID 50）クリアで解放。既存の機能解放演出に、紫と青の裂け目・門の画像・解放カードを追加。
- ステージ選択の地域タブの最後に「特殊ステージ」を独立して表示。UIでは個別名「次元の門」を使用し、地域・ステージ番号を表示しない。
- 通常 `STAGES` / `ENEMIES` と `SPECIAL_STAGES` / ゲートを分け、戦闘・選択・保存には `ALL_STAGES` / `ALL_ENEMIES` を使用。特殊IDは文字列。後続の通常地域を追加しても通常ルートの並び順・自動進行に入り込まない。
- 自動進行でも特殊ステージからは同じステージを周回。敗北時は解放元の遺跡10へ戻り、同じステージ周回に切り替える。OFFなら結果画面で停止。

## 召喚

| ウェーブ | 門 | 召喚 | 合計 |
| --- | --- | --- | ---: |
| 1 | 次元の門 | 5地域の同系統を各2体、10体ずつ3回 | 雑魚30体 |
| 2 | 大きな次元の門 | 5地域から各1ボス、5体ずつ3回 | ボス15体 |
| 3 | 巨大な次元の門 | トレント / ヒュドラ / ケイブトロール / クラーケン / タイタン | 大ボス5体 |

雑魚はスライム・蛙・コウモリ・ヤドカリ・石系統、獣・泥・ワーム・リザード・弩兵系統、植物・骨・蜘蛛・タコ・魔導器系統の順。遺跡の石系統は衛兵1体＋ガーゴイル1体とし、30枠内で雑魚全16種類が登場する。ボスは全15種類を1体ずつ。

門は攻撃対象から除外され、ダメージ無効。召喚中に出現済みの敵を倒しても、その回の残りはすべて出現する。門が閉じている間は召喚した敵の全滅を待つ。最後の回を全滅させるとひび割れ・破砕の後に門も倒れる。門3体を含む撃破総数は53体。門からドロップは出ない。ボススライムの分裂・リッチの追加召喚はこの特殊ステージでは行わず、指定の召喚数を維持する。ワーム・クラーケンの攻撃用部位は既存挙動を維持し、撃破数や報酬に加算しない。

## 能力・報酬

- 雑魚は石の衛兵、ボスは重装ゴーレム、大ボスはタイタンの基本HP・攻撃・防御に正規化し、遺跡10の倍率を適用。トレントも大ボスとして扱う。各種の行動・射程・移動・攻撃周期は維持。
- Lv.50、アクティブ順次取得、全6キャラ、ジェム・回復薬なしで両端を検証。メイン装備のみは3配置すべて敗北。森〜遺跡の武器・防具各500ノード（全ユニークを含む）の取得は3配置すべて全員生存クリア。中間の細かい難易度調整は行わない。
- 素材は倒した敵の元地域から通常確率で抽選。森〜遺跡の共通・結晶・レア素材を入手可能。
- ジェムLv.5。ボス / 大ボスのレア10%、ユニーク1%の排他的抽選。トレハン倍率をさらに掛ける。雑魚や門からはジェムを落とさない。Lv.5にレジェンダリーは追加しない。
- 2026-10-13：クリアゴールドは遺跡10の3倍（3,000G）。撃破分3,220Gと合わせて1周6,220G。両方にパーティー合計のトレハン倍率を掛ける。経験値は遺跡10相当。初回専用アイテム・回復薬・加入報酬なし。正規化したレベル内経験値を使い、特殊IDを指数計算に渡さない。

### 装備強化の報酬収支（2026-10-13）

森〜遺跡の各地域ツリー1本ずつ、合計500ノードを基準に比較する。費用は全キャラ・武器／防具で共通。素材変換を使わない全取得の約300周方針と、通常地域の報酬・装備費用は維持する。

| 項目 | 周回数・量 |
| --- | ---: |
| 500ノードのゴールド費用 | 1,252,650G |
| 素材変換なしの必要素材の期待周回数 | 300周 |
| 余剰結晶をコモン／レアに変換した素材予算 | 210周 |
| 旧ゴールド総額（4,220G/周）の必要周回数 | 約297周 |
| 新ゴールド総額（6,220G/周）の必要周回数 | 約201周 |

素材変換なしでは旧ゴールドもほぼ釣り合う。一方、余った結晶で不足素材を補うと、210周分の素材で500ノードを購入可能なのに旧ゴールドは366,450G不足する。クリア報酬を1,000→3,000Gへ増やし、1周総額は約47%増加。210周分の新ゴールドなら500ノード購入後に53,550G残る。素材・ジェム確率・撃破ゴールドは維持する。トレハンは素材とゴールドを同倍率で増やすため、この比率も維持される（端数・抽選の揺れを除く）。

210周は各素材の期待獲得量を切り捨てた整数予算から、実際の工房レシピ（結晶1→コモン3、結晶5→レア1）で全費用を用意できる値。ランダム抽選での確定到達回数ではない。1地域ツリーだけを強化する場合と異なり、5地域分を並行して消費する前提。複数キャラ・武器／防具では費用と素材必要量が本数に比例する。

再計算は `node tools/balance/audit-rift-rewards.cjs`。実際の素材変換・装備購入APIで、旧報酬では途中でゴールド不足、新報酬では全500ノード購入可能なことを `npm run test:rift` で検証する。

## モーションの座標・時間設計

基準画像は `public/assets/stages/dimensional-rift/gate.png`。全状態・全サイズで同じ画像・配色を使用し、再生成によるコマ間の差を避ける。ゲートの基準位置 `(825,452)`、スプライト画像の中心X 50%、接地Y 94%、可視高さ比89%。高さ210 / 242 / 274で拡大。

| 状態 | 時間 | 動き |
| --- | ---: | --- |
| 閉鎖待機 | 全滅まで | 門固定、周囲のオーラとピクセル粒子だけ周期移動 |
| 開く | 900ms | 左半分をX方向へ `-高さ×0.12`、右半分を `+高さ×0.12`。中央に渦を露出 |
| 召喚 | 160ms間隔 | 出現地点X `550+(番号%5)×76`。10体のYは `356+floor(番号/5)×104+(番号%2)×22`、5体のYは `379+(番号%2)×100`。どちらも平均Y 419で上下に分散 |
| 出現 | 450ms / 850ms | 本体は24px下から定位置へ、透明度15→100%。周囲の裂け目・粒子は850msで消える |
| 閉じる | 650ms | 開いた左右を元位置へ戻す。次の開きは閉じた同じ座標から開始 |
| 崩壊 | 1400ms | 初めの280msで亀裂、続いて8×8の画像片を中心から放射・回転・落下して透明化 |

召喚効果は雑魚＝青緑の細い裂け目、ボス＝紫の交差する二重輪、大ボス＝金の稲妻・太い衝撃輪。背景は異次元の浮遊石島・星雲・黒曜石の足場。通常背景のレイヤーに混ぜず切り替える。低モーション設定は粒子移動や大きな画面揺れを抑え、開閉・出現・崩壊の状態変化を表示する。
