# エピックジェム・女神の契約

2026-10-15実装。[企画](../design/epic-gems-and-goddess-equipment.md)の12種の主案を採用し、追加指示のトレハン成長・レベルなし・女神報酬・SP合計を適用した。

## 固定エピック12種

エピックには地域Lv、品質、小型品、ランダム副能力を持たせない。各職の武器用・防具用を1種ずつ、計12種。職と箇所の両方で装着を制限する。定義は `public/js/data/epic-gems.js`。

| 職 | 武器 | 防具 |
| --- | --- | --- |
| 戦士 | 天壊万刃：追加Hit2回・各100%、動作−40%、MP−50% | 不滅戦鬼：被弾闘気10段、各与ダメ＋20%・速度＋10%、HP吸収10% |
| 魔法使い | 万象連星：追加魔法2回・各100%、範囲＋50%、MP−50% | 星界魔炉：最大MP＋200%、最大MP5%/秒回復、魔法発動でHP20%バリア・上限100% |
| パラディン | 神罰聖槌：守護発動で全敵×10、反射＋300%、神聖＋100% | 不落天城：守護持続＋200%、設置守護全域、被弾クール回復2秒/1秒 |
| 忍者 | 百影投刃：投擲×3、分身・複写威力100% | 無尽影衣：異種分身共存、各＋4体、持続＋200%、MP−70% |
| 呪術師 | 無窮呪獄：呪印25、深呪3種、呪印消費0、脈動間隔−50% | 黄泉還流：呪い持続＋200%、印ごと軽減2%・上限80%、呪い吸収10%、脈動MP2%/0.5秒 |
| 巫女 | 常世神楽：持続＋200%、再使用−50%、霊威＋100%、5秒協撃、全員MP3%/秒 | 万霊総社：攻撃5・補助3・回復3契約、憑依4種、持続＋200%、MP−70%、ウェーブ開始時全種無料招来 |

巫女の独立型は11契約17個体、憑依は4種。同種の無限追加は行わず、憑依の同種1契約は維持する。神楽は再発動で更新し、旧開催の終撃を1回だけ処理する。更新しても定期協撃時計を先送りしない。死亡・終了時の清掃では終撃を発生させない。

魔法の追加発動は本体と独立した発動時計・命中判定を持ち、追加MP・再使用・バリア付与を要求しない。追加攻撃・複写・神楽から自身を再帰発動しない。忍者の同じ分身技の再使用はその集団を更新する。装着解除時は過剰な召喚枠・分身・深呪などを通常上限へ戻す。

## 女神強化と容量

異次元の女神のクリアで、装備強化に専用アイコン付き「女神」ページを解放する。各職・武器／防具それぞれ、根1＋4枝×10＝41ノード。

| ノード | 1ノード | 1箇所の完成値 |
| --- | --- | --- |
| 根 | 職専用容量2000 | 2000 |
| 武器攻撃／防具防御 | ＋100×10 | ＋1000 |
| 補助 | ＋100×10 | ＋1000 |
| SP | ＋3×10 | ＋30 |
| 共通 | ＋50×10 | ＋500 |

追加回答により、SPは武器30＋防具30、キャラ合計60。Lv.100の基礎SPを合わせて160。追加SPを取得・減算・振り直し・保存復元の予算へ反映する。通常地域の取得数ボーナスは女神ツリーへ重ねない。既存の自動強化ではユニーク枠として扱う。

エピックは専用容量2000＋武器なら攻撃1500／防具なら防御1500。専用容量の表示名は職名に合わせて「戦士容量」「魔法使い容量」「パラディン容量」「忍者容量」「呪術師容量」「巫女容量」とする。専用容量は箇所ごとに独立し、共通容量で代替できず、割引も付かない。攻撃／防御には従来の装備割引が適用され、最大40%時の実消費は900。各箇所に1個ずつ装着できる。

## 報酬・制作

女神素材はユニーク「星界の残滓」。女神が満足して帰還した後の抽象的な光・星・空間の残響を表し、身体や装備の破片にはしない。

- 女神のジェム抽選は、エピック1%・レジェンダリー10%・それ未満0%。基本確率では排他的抽選1回。2026-10-16修正：トレハン後は各レア度100%ごとに1個確定＋端数抽選とし、合計100%の上限を撤廃。＋1000%ならエピック11%、レジェンダリー110%（1個確定＋10%）。エピック成功時は12種を均等抽選、レジェンダリーは地域Lv.10。
- 星界の残滓は独立に30%。ジェムと同時獲得できる。フェーズ移行・幻影からは落ちず、帰還を開始する決着処理で報酬を1回だけ付与する。
- 両方にトレハン倍率を1回だけ適用する。ジェム・素材とも100%ごとの確定個数＋端数抽選。旧「通常ジェム10倍」は使わない。
- 制作は職・武器／防具を指定し、エピック破片200＋残滓30。解体はエピック破片100。レジェンダリー破片10→エピック破片1への上位変換を追加する。制作・変換は女神クリア後。
- 女神強化の根は残滓1、各枝の深さ1〜10は残滓1〜10。1ツリー221。ゴールドは要求しない。
- 既存の保護・装着中解体禁止・自動解体設定を維持する。「レジェンダリー以下」の設定でエピックを解体しない。エピックにレベル表示や地域Lv強化を出さない。

## 通常ジェムの変更

- 命中MP回復は攻撃容量へ変更。既存の個体ID・効果・品質は保持する。容量が合わなくなった装着のみ読込時に所持欄へ戻す。
- レジェンダリーに防御容量の「被弾MP回復」「被弾クール回復」を追加。品質1.00・固有枠配分後のLv.5基準はMP4%・クール1秒、Lv.10はMP6%・クール1.5秒。実際のレジェンダリー生成はLv.6以降。
- 被弾系は生存した直接被弾が対象。バリアへの被弾も含む。DoT・反射・回避・無敵は対象外。同じ敵動作で1回、本人共通の最短発動間隔1秒。クールは本人の各アクティブ残り時間を0を下限に減らす。
- ユニーク以上の固定効果は `0.5＋0.1×地域Lv` 倍。Lv.5を従来値、Lv.10を1.5倍とする。基礎ステータスなど既に地域参照値で伸びる効果には二重に掛けない。
- ユニークのトレハンはLv.1で12%、Lv.5で20%、Lv.10で30%。2026-10-17以降、レジェンダリーは通常能力の配分比1.184÷1.15（約1.0296倍）で増やす。Lv.6は22.65%、Lv.10は30.887%（表示30.9%）。品質には依存しない。
- 固定効果のみの個体も地域Lvアップグレード対象にする。エピックはレベルがないため対象外。

## 素材と検証

内蔵image_genを各画像に1回ずつ使い、エピック12・新レジェンダリー2・破片1・残滓1・女神ページ1の計17点を制作した。全プロンプトと原画は [生成記録](../../development/assets/ui/epic-gems/generation.json)、一覧は [画像検収](../../development/assets/ui/epic-gems/review.png)。本編は `public/assets/ui/gems/` の透過128px PNGだけを読み込む。再登録は `npm run build:epic-gems`。

素材は全17点について透過・外接矩形・余白・小サイズでの判別を確認する静止アイコン。既存の戦闘アニメ素材の形は変更しない。女神で再利用する旧エフェクトの枠形式差による描画エラーは共通描画側で補完した。

重点テストは `npm run test:epic-gems`、本編操作は `npm run check:epic-gems-ui`。12種の固定性・容量・職／箇所・保存・SP・制作収支・ドロップ境界・被弾・各職の効果・解除、通常幅／390px・女神ページの一括取得・制作・再読込・全12種同時戦闘を対象にする。女神の通常ジェム構成は `npm run audit:goddess` の既存30配置を再測定し、エピックによる強化を相殺する敵調整は行わない。

確認結果：

- 関連回帰474件、失敗0。全テストファイルから通常地域の敵調整用 `stage-balance.test.cjs` だけを外し、`node --test --test-concurrency=4` で実行。通常地域の敵数値・メイン装備基準は変更しておらず、その全装備条件30配置の再調整計算は今回の対象外とした。
- 重点17件合格。追加魔法の実発動・MP消費1回・再帰防止、神罰・分身投擲・解除時の通常上限復帰を含む。
- 本編ブラウザー検証合格。1440px／390px、8画面記録、実行・読込エラー0。11契約17個体・憑依4種・分身31体・神楽を同時に確認。
- 女神の既存基準を各30配置で合格。ジェムなし0/30（時間切れ、全配置6人生存）、各職ユニーク2個で30/30（約150.3〜154.2秒、全配置6人生存）。敵数値の変更なし。
- 全エピック装着の試運転1回は約20.9秒・6人生存で女神クリア。終了後の召喚・憑依・分身・追加魔法はすべて0。
- `npm run check:structure`・`git diff --check` 合格。素材・確認結果は `development/assets/ui/epic-gems/` と `output/epic-gems/` に保存。
