# 忍者・呪術師・巫女のパッシブ

2026-10-11追加。戦士・魔法使い・パラディンのスキルツリーに合わせ、3人それぞれに共通パッシブ11種と専用強化21種を実装した。

- パッシブ・専用強化は各5ランク、1ランクにつき1SP。
- 共通パッシブは前提なし。専用強化は対象技Lv.1が前提で、対象技の解放レベル＋2（上限100）で解放する。
- 通常攻撃は従来どおり無料のLv.1。通常攻撃の専用強化にはSPを使う。
- 3列（技・専用強化・共通）の配置、取得・減算・全返却・保存は既存の育成UIと共通。
- 技をLv.0へ減算すると専用強化も全返却。共通パッシブと他のキャラのSPは維持する。
- 効果欄・ツールチップは効果名と数値・パラメータだけを表示する。既存アイコンを使用する。

## 専用強化

- 忍者「忍術強化」：威力＋10%、射程・半径・幅＋4%、動作時間−3%/ランク。分身・複写はそれぞれの威力を強化する。持続する技は効果時間＋4%/ランク。拘束・目眩ましの時間、分身上限6、複写回数、共通待ち8秒は維持する。陣の総威力を波数へ分配する仕様も維持する。
- 呪術師「呪式強化」：威力＋10%、射程・半径・連鎖距離・杭間隔＋4%、動作時間−3%/ランク。直接攻撃・呪印・深呪・陣・反応追撃・呪印消費の加算・終撃に反映する。複写済み呪印の威力・失効時刻、呪印上限5、呪印寿命10秒、デバフ上限、脈動・追撃の制限は維持する。
- 巫女「霊式強化」：攻撃技の威力、回復技の回復量、防御技のバリア量、命令の倍率をそれぞれ＋10%/ランク。射程・半径・幅・連鎖距離＋4%、動作時間−3%/ランク。持続する技は効果時間＋4%/ランク。召喚数・契約上限・憑依制限・召喚の行動周期・HP割合上限・霊威の非加算は維持する。
- 動作短縮は180msを下限にする。再使用時間は専用強化によって短縮しない。共通パッシブ「再使用速度」は既存のhaste計算に反映する。
- 巫女の回復・バリア共通パッシブは各効果量に適用し、専用強化とは乗算する。最大ランク同士では効果量×1.8。HP割合上限は増やさない。

[balance-policy.md](../policies/balance-policy.md)の攻略基準を維持し、パッシブを初回攻略の必須条件にしない。加入時のレベル・SP・初期アクティブ、経験値、装備費用、ドロップ、敵の調整は変更しない。

## 検証

- `npm run test:passives`：全6職の割合補正と全3人のノード・解放・SP・保存・依存先返却、共通能力、専用強化の分離、通常弾・分身・呪印・回復・バリアの実戦反映を確認。
- `npm run check:passives-ui`：ローカル開発サーバーに接続し、全6職の3列の表示・アイコン・習得・効果ツールチップ・依存先返却・再読込・小さい画面を確認。忍者と呪術師の技プレビューで専用強化Lv.0〜5を切り替えられる。
- `npm test`：既存の戦闘・育成・素材テストと新規テストをまとめて実行。
