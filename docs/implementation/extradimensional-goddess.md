# 異次元の女神／界外の御座

2026-10-15 実装済み。混沌の門クリアで解放する最終の特殊ステージ。IDは `extradimensional-goddess`。初回は既存の装備全取得とジェムで挑む。クリア後は[女神の契約・エピック](epic-gems.md)を解放する。

## 解放と進行

- 混沌の門の初回クリアで、日蝕、金青の天環、女神の姿を使う6.4秒の専用解放演出を表示。動きを減らす設定では2.6秒。スキップ・キーボードフォーカス・報酬表示後の進行を維持する。
- 次へ進む設定では混沌の門から御座へ自動進行。同じステージ周回では混沌の門を維持する。御座は最終なので両設定とも御座を周回する。
- 御座で敗北・時間切れになると混沌の門へ戻り、同じステージ周回へ切り替える。OFFなら結果画面で停止する。
- 既存セーブの混沌の門クリア記録からも解放する。選択、両特殊ステージのクリア、装備、ジェム、所持品は既存保存形式で保持する。

## 戦闘

制限時間180秒。残り時間と共有HPの割合を表示する。HPは25億、防御4,900。別個体への交換や移行時の無敵・回復はない。50%で約2.4秒の移行を行い、中断回数を引き継ぐ。

前半は御座から小さな星弾と指パッチン。10地域を袋で一巡し、各地域の女性型／大ボスを選ぶ。同地域の連続と同じ区分の3連続を防ぐ。歴代20体は描画用の幻影で、AI、HP、敵数、ターゲット、追加召喚、報酬を持たない。予告した代表技だけを女神の行動として処理し、最終判定後250msで回収する。星鏡は妨害不可。毒・火傷・呪い・砂縛りは最大3秒、拘束・凍結は最大1秒。支援2職の同時拘束を避け、人数上限と解除後免疫を維持する。

後半は重複しない最大3人を選ぶ追尾流星、界面断裂、天環の裁定、零界収束。流星は固定した対象IDの現在位置を追い、各1 Hit。死亡した対象から別の味方へ乗り換えない。危険技は予備動作開始時の範囲・向きを固定し、通常の行動妨害へ接続する。中断で予約を破棄し、抵抗力と容量が上昇する。星鏡と流星の予測も自動防護へ渡す。後半から新しい状態異常は付与しない。

被害は装備全取得時の職ごとの固定HP・防御基準から算出し、現在最大HPへの割合攻撃にはしない。防御、弱化、防護、バリア、無敵を通す。危険技は初撃33%、追撃17%を開始予算とし、1人2 Hitまで。前半は連撃・継続被害込みで1呼び出し20%以内に抑える。

HP0では満足して微笑み、会釈して手を振り、異次元へ帰る。第1フェーズからの決着にも座位を起点にする。攻撃予約・流星・幻影・印を破棄し、報酬は1回だけ。本体は1450ms、扉と影は1800msまでに消え、2200ms後に勝利を確定する。時間内にHP0なら帰還中の制限時間到達で敗北にしない。

## 難度の採用値

ユーザー指定は「ジェムなし装備全取得では制限時間を少し越え、ジェムを足すと突破」。全6職Lv.100、全地域の武器・防具各1,000ノード、アクティブを解放順に取得、薬なし。希少ジェムを持たない通常地域向けのメイン装備基準は、この最終特殊戦には適用しない。

| 構成 | 30配置の結果 | 時間・残HP | 生存 |
| --- | --- | --- | --- |
| ジェムなし | 0/30、すべて時間切れ | 180秒、残HP3.2〜5.6% | 全配置6人 |
| 各職の武器にユニーク2個 | 30/30勝利 | 約150.3〜154.2秒 | 全配置6人 |

ジェムの検証構成は、Lv.10・品質1.0・攻撃力＋再使用回復速度の合法ユニークを各職2個、合計12個。防具ジェムとレジェンダリーは不要。この構成は検証用で、加入・報酬や保存データへ自動配布しない。最大単発被害はジェムなし約12%、あり約9.6%。固定シード1〜30。同じ実測から判定と `output/goddess/balance.json` を作成する。

## 報酬と素材

撃破18,000G＋クリア30,000G。双方に既存のトレハン倍率と端数繰り越しを適用する。2026-10-15の追加指示により、ジェムはレジェンダリーLv.10を10%、レベルのないエピックを1%の排他的抽選1回へ変更。2026-10-16にジェムの合計100%上限を撤廃し、各レア度100%ごとの確定個数＋端数抽選に修正。下位ジェムは落とさない。独立してユニーク素材「星界の残滓」30%。両方にトレハンを1回適用する。初回回復薬はない。クリアで女神装備・エピック制作を解放する。[採用値・素材・強化](epic-gems.md)。経験値は通常100相当、Lv.100ではMAX。

## 採用素材と調整

制作データは [runtime-v3](../../development/assets/extradimensional-goddess/runtime-v3/README.md)。修正済みの通常射撃、術式、大技、帰還、玉座・天環を本編へ登録し、指パッチン3コマを内蔵image_genで追加した。基準画像と初稿・修正版の原画を保持する。

本編は16クリップ54コマ。固定の区間縮尺、アルファ外接矩形からの表示原点、接地位置を登録する。個別の描き直し・色変更・形状補正はしない。セル越境や姿勢不良が残る初稿の待機、移行、流星、休息、星鏡、収束柱は採用しない。待機の呼吸、位相移行、休息、星鏡・収束は採用ポーズとCanvasで組み立てる。歴代ボスも全コマの範囲から固定の表示縮尺と原点を計算し、鏡内へ収める。

本編ロードは `public/assets/` 内で完結する。資料館へ女神の登録素材を追加。最終育成の味方スキルに埋もれないよう、女神本体を演出の手前に描く。

## 検証

混沌の門クリアまでは女神を秘匿する。ステージ一覧・戦闘ルートは混沌の門クリアで表示する。資料館は女神との遭遇後、残滓は入手後、エピックの破片・凡例・工房・解体設定はエピックジェムの初入手後に表示する。女神の装備強化タブは女神クリア後に表示する。非表示の項目は件数にも含めない。女神強化・エピック制作には女神クリアが必要。

- `node --test tests/content-discovery.test.cjs` と `npm run check:goddess-discovery-ui`：解放前の秘匿、混沌の門クリア直後の表示、女神クリア後の利用・保存再読込、通常幅と390px幅。

- `npm run test:goddess`：解放、進行、既存／新規保存、2フェーズ、20幻影、状態上限、流星、固定範囲、中断、帰還、時間切れ、1回報酬、透過・全コマ。
- 接続と共用箇所の回帰：女神を含む159テスト合格。混沌の門・次元の門、魔王城、成長・保存・ジェム、行動妨害、パラディン・巫女、資料館を確認。
- `npm run audit:goddess`：両構成各30配置で上記基準合格。途中の固定3配置は `-- --quick`。
- `npm run check:goddess-ui`：本編通常幅と390px幅、専用解放・次へ進む、最終周回と敗北先、OFF、保存再読込、全20幻影、予告と発動、追尾、中断、両フェーズからの帰還、動きを減らす設定。16クリップ54コマを通常速度と0.25倍で連続再生し、全コマへ到達。読込・実行エラーなし。
- 素材の全コマ一覧・GIFは制作側 `review/`。本編のキャプチャ・結果は `output/goddess/`。素材に変更がない演出修正後は `-- --scenes-only` で成功済みの素材再生結果を再利用する。
- `npm run check:structure` と `git diff --check`。
