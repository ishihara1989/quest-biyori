# ジェム再設計の実装

2026-10-12 JST。[検討案](../design/gem-system-design.md)を基に、ユーザー追加指示の容量・トレハン・主系統指定・妨害能力を適用した。初回実装はレジェンダリーまで。2026-10-15に[エピック・女神強化・通常効果成長](epic-gems.md)を追加した。以降の元記録の固定効果・トレハン・命中MP回復容量・破片変換上限は同追加仕様で更新する。

## 状態異常抵抗（2026-10-16追加・採用済み）

- 「浄護のジェム」／能力ID `resistance` をユニーク・レジェンダリーの主系統・副能力へ追加。全職対応、防御容量を消費する。エピックは従来の専用固定品を維持する。
- 軽減対象は状態異常の**付与確率**。Lv.1で12%、以後1Lvごとに2ポイント増え、Lv.5で20%、Lv.10で30%。品質・効果予算・レア度では変化しない。成功した状態異常の時間・継続ダメージは従来値。
- 複数個は装着者ごとに残存確率を乗算する。30%を2個なら `0.7 × 0.7 = 0.49`、合成抵抗率51%。武器・防具の両枠と主系統・副能力をまとめて計算し、次の戦闘開始時に反映する。
- 対象は毒・拘束・蜘蛛糸・暗闇・泡拘束・砂縛り・出血・冷気・凍結・火傷・破甲・呪い・睡眠・沈黙、および女神の対応する状態異常。物理的な押し出しは対象外。初回付与と更新ごとに判定し、抵抗した更新では既存の異常を延長・強化しない。直接被弾は別判定。
- 抵抗成功で緑の光を表示。ジェムの効果表示は「状態異常抵抗 +30%」などの効果名と数値だけとし、能力画面には乗算後の合成抵抗率を表示する。抵抗0では追加の乱数を消費しない。
- ドロップ・合成・Lv強化・解体除外・保存復元に既存の仕組みを使用。旧個体の能力・品質・IDを保持する。
- 画像は内蔵image_genで生成した緑の宝石と金の盾の透過ドット絵。原画と全文プロンプトは `development/assets/ui/gems/`、本編画像は `public/assets/ui/gems/status-resistance.png`。再登録は `node tools/assets/build-status-resistance-gem.cjs`。
- `tests/status-resistance.test.cjs` でレア排除、全Lv・品質・レア度、確率境界・複数装着、更新抵抗、地域ごとの実付与、保存・再読込、透過と余白を検査する。ジェム・育成・報酬・各地域の関連回帰テスト、構造検査、隔離ブラウザの合成・装着・再読込・通常幅／狭幅の検証を使用する。

## セーブと個体

- セーブ全体の版・保存キーは維持し、`gemVersion: 1`でジェムだけを移行する。旧版ジェム・装着・ジェム破片を初期化し、キャラの経験値、スキル、装備強化、地域素材、ゴールド、クリア状況を保持する。
- 各個体にID・レア度・主系統・地域Lv・品質・小型倍率・能力IDと予算・保護状態を保存する。ロードで再抽選しない。不正な個体は除外する。
- 森Lv.1、沼Lv.2、洞窟Lv.3、海岸Lv.4、遺跡Lv.5、砂漠Lv.6。地域内では共通Lv。
- レアは1能力、ユニークは2能力、レジェンダリーは4能力。レジェンダリーは固有效果を1個保証する。
- 品質は0.95〜1.05の共通係数。レアには容量50・100の小型品を含め、効果と解体量も比例させる。合成は標準サイズ。
- 物理と魔法の特化を同時生成しない。攻撃容量と防御容量も同一個体に同時生成しない（物理・魔法・範囲・妨害・攻撃系固有效果と防御系能力の組み合わせを含む）。攻撃＋補助、防御＋補助は許可する。ドロップと合成に同じ抽選制限を使う。全能力を使えるキャラが1人以上残るものだけを生成・装着する。装着数だけでなく方向別容量・共通容量を検査する。
- 容量統合時は`gemVersion: 1`を維持し、所持ジェムを削除・再抽選しない。既存の攻撃＋防御の個体は効果を保持し、新しい抽選では生成しない。

## 能力と容量

基礎能力は、その地域の戦士・地域終端レベル・メイン装備のみの固定参照値から生成する。攻撃／物理／魔法は参照攻撃力の8%、HPは8%、防御は`(80+参照防御)×8%`、MP自然回復は参照MPの0.7%/秒をレア1単位の初期値とした。装着者の現在能力には追従しない。

ユニークは2.3単位／容量340、レジェンダリーは5.152単位／容量580。レジェンダリー固有效果へ1.6単位、残りの3能力へ各1.184単位を配分する。効果予算から方向別容量を配り、端数は最大剰余方式で合計容量を維持する。

ユニーク以上の効果は再使用回復速度・スキル範囲・トレジャーハント・行動妨害力・妨害抵抗貫通。これらは地域Lvで増やさない。妨害抵抗貫通は最大40%、合算再使用回復速度は最大200%。妨害貫通は実際の中断判定とAIの選択評価へ同じ倍率で反映する。

**容量500は武器・防具それぞれの初期合計（共通50込み）。** 武器攻撃容量・魔法攻撃容量は攻撃容量へ統合し、物理／魔法攻撃力の効果と職業制限は維持する。全職の武器は攻撃350、補助100、共通50。防具は防御300、補助150、共通50。地域ツリー1本を完成すると方向合計200・共通50が追加される。30ノードで武器は攻撃100（防具は防御100）、40ノードで補助50、80ノードで武器は攻撃50（防具は防御50）、100ノードで共通50を取得する。70ノードの割引は10%ずつ乗算し、最大40%にする。容量以外のノード効果・素材費用は維持する。

## レジェンダリーの固有效果

| 能力 | 実装 |
| --- | --- |
| 残響追撃 | 直接命中の実ダメージの一部を追撃。元動作につき1回・最短1秒 |
| 命中MP回復 | 直接命中で最大MPの一部を回復。最短1秒 |
| 被弾バリア | 生存した直接被弾の後、最大HPの一部のバリア。再発動5秒、持続4秒、合計HP30%上限 |
| 瀕死追撃 | 命中後HP30%以下の敵へ追加ダメージ。元動作につき1回・最短1秒 |

追撃は派生扱いとし、会心・妨害・他のジェム・呪い追撃・分身複写を再抽選しない。補正済みの実ダメージを使い、防御・属性・召喚支援倍率を再適用しない。追撃による撃破もドロップ・ゴールドを1回だけ付与する。解除後は能力を0へ戻し、被弾バリアも消す。召喚・DoT・反射などの派生命中にジェムの発動権は付けない。

## ドロップと工房

- レア5%、ユニーク0.5%を維持。砂漠のボス／大ボスからレジェンダリー0.05%を追加する排他的抽選。
- トレハンは個体ごとに必ず+20%。予算・品質・地域Lv・レア度で20%を変えない。装着した個体の数だけパーティー全体で加算し、全素材（コモン・地域結晶・レア）とジェムの基本確率へ1回掛ける。1個ならレアジェム5→6%、2個なら5→7%。2026-10-13追加指示：素材は100%上限を廃止し、100%ごとに1個確定、端数で追加1個を抽選する（250%なら2個確定＋50%で1個）。基本100%の素材にも倍率を掛ける。2026-10-13追加指示：敵撃破・ステージクリアの獲得ゴールドにも同じ倍率を掛ける。1ゴールド未満の端数は保存して次回獲得へ繰り越す。初回クリアのアイテム報酬と経験値には掛けない。2026-10-16修正：ジェムもレア度別に100%ごとに1個確定＋端数の追加抽選とし、合計100%での倍率制限を廃止する。基本確率での排他的抽選は維持する。通常・特殊ステージ共通の `rollGems` は0個以上の配列を返し、全個体をクリア時に保存・自動解体する。
- 遺跡5-10クリアで工房・解体・アップグレード・破片変換を解放する。
- 合成ではレア度・到達地域Lv・主系統を選択する。選択した主能力は保証し、副能力・品質は抽選。費用は主系統から事前に確定し、抽選結果で変えない。
- 解体は同レア破片`floor(10×Lv×小型倍率)`。装着中・保護中は解体できない。解体確認をキャンセルした場合は変更しない。
- 合成は同レア標準品10個分の価値。基礎複合ユニークは自レア60%／1段下40%、ユニーク固有系と通常レジェンダリーは80%／20%、レジェンダリー固有系が主系統なら自レア100%。下位成分は10対1の価値で換算する。地域レア素材はレア10個、ユニーク以上30個。
- アップグレードは各段階の目標Lv標準品3個分の破片を合計し、Lv依存予算比・小型倍率で補正する。目標地域クリスタル40個×上げる段階数。性能がLv非依存の個体には出さない。費用は解体量の増加より必ず多くする。
- 破片10→上位1。変換で余った破片は保持し、レジェンダリーから先への変換は追加しない。
- リザルトでも個体を別々に表示する。レア度、地域Lv、実際の能力と容量を確認できる。

## まとめて解体・自動解体（2026-10-12追加）

- ジェム画面の「まとめて解体」タブで、Lv以下・レア度以下を個別指定する。両方指定した場合は「すべて一致」（AND）／「いずれか一致」（OR）を選択する。「指定なし」はその条件を使わず、両方とも指定なしなら対象0個。
- 対象個体の画像・個数・レア度別の獲得破片を事前表示し、確認後に解体する。個体をクリックすると装備画面で確認・保護できる。保護中・装着中は常に除外する。
- 2026-10-13追加：「まとめて解体」にも自動解体と同じ「残す効果」を表示する。複数選択でき、主効果・副効果のいずれかに選択した効果を持つ個体は、AND／OR条件に関係なく除外する。対象一覧・個数・獲得破片と実際の解体に同じ判定を使う。一括用の選択は画面内で保持し、自動解体の保存設定とは独立する。
- 一括処理は全レア度の破片残高を検査してからまとめて付与・削除する。残高が安全な整数の範囲を超える場合は全体を中止し、個体も残す。
- オプションの「ジェム自動解体」は初期OFF。同じLv・レア度・AND／OR条件に加え、攻撃・防御・補助容量と、各効果による除外を設定できる。選択した容量または効果を1つでも持つ個体は残す。主効果・副効果の両方を確認する。旧武器攻撃・魔法攻撃容量の除外指定は、ロード時に攻撃容量の除外へ統合する。
- 自動解体は新しくドロップした個体にだけ適用する。設定変更・ロードでは所持個体を解体せず、合成にも適用しない。解体したドロップは破片としてリザルトに加算し、同じジェムを獲得品として重複表示しない。
- 既存の解放条件（遺跡5-10クリア）・解体量・ドロップ確率を維持する。設定は`autoGemDismantle`として保存し、旧セーブはOFFで補完。不正な閾値・条件は自動解体をOFFへ戻し、除外設定の不正ID・重複IDは除去する。
- 関連自動テスト42件と、既存ジェムUIの回帰検証、新規UIの実操作検証を通過。新規UI検証は`npm run check:gem-dismantle-ui`。AND／OR・キャンセル・保護／装着・破片量・設定保存／再読み込み・未解放状態・副効果の除外・実際の自動解体ドロップ・1440px／390pxの表示を確認。画像記録は`output/gem-dismantle/`。
