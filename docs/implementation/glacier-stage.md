# 蒼氷の聖域の実装

2026-10-13。地域8、通算71〜80。高原70のクリアで解放。既存セーブの育成・素材・装備を維持して追加する。

## 敵・行動・素材

フロストウルフ、氷殻ゴーレム、雪の精、フェンリル、クリスタルゴーレム、雪女、氷牙マンモスの7種。全種に待機・移動・被弾・撃破と個別の通常攻撃を登録し、危険技13種には独立した本体モーションを用意する。四足の狼2種とマンモスは6コマ・720msのtrot、ゴーレムは6コマの歩行、雪精と雪女は浮遊。撃破の終端は保持してから消える。

円・帯・扇・円環の同じ形状データを予告と命中判定に使う。照準・地点・順番は予備動作開始時に固定する。氷柱、氷塊、段階波は1人1回まで。氷塊の中心間隔は260px以上で、配置できない場合は本数を減らす。予告中断で本体の予約・装甲・後続判定を破棄し、発動済みの通常冷気弾は消さない。

凍結は最大2人、2人生存時は1人、1人生存時はなし。雪女の封輪は回復・防護役を同時に選ばない。解除後は3秒免疫。冷気は移動速度−30%・3秒。結晶装甲は被ダメージ−30%・4秒、発動中の攻撃停止と9秒の休息。浄化と戦闘終了時の清掃にも接続する。

マンモスは通常攻撃2回→薙ぎ→踏砕→氷塊の順。各危険技の後に3〜3.5秒休む。HP50%以下への移行は現在のサイクルが終わってから行い、次サイクルの末尾に白夜の氷冠を追加する。登場後には8.5秒以上の待機を置く。

コモン3種、氷河の結晶、マンモスの氷牙の5素材と全職の武器・防具100ノードを追加。経験値、トレハン、ジェム・素材の確率、ABC各433個・レア90個・約300周のツリー予算は [バランス方針](../policies/balance-policy.md) を維持する。

## 制作と確認

原画・固定リファレンス・生成プロンプト・座標目標は [氷河の制作領域](../../development/assets/glacier-motions/PROMPTS.md)。組み込み image_genで57枚の透過原画を制作し、最近傍サンプリング・切り出し・位置合わせで174枚の敵フレームと44枚のエフェクトフレームを梱包する。生成座標と実測は区別し、座標への一致を生成完了だけで断定しない。

本編素材は `public/assets/enemies/`、`effects/glacier-*`、`stages/glacial-sanctuary/`、`ui/items/`。確認画面は [glacier-assets.html](../../development/labs/glacier-assets.html)。各コマ、速度、左右反転、基準絵を確認できる。

再現コマンド：`npm run build:glacier`、`npm run test:glacier`、`npm run audit:glacier`、`npm run check:structure`、`npm test`。実戦の測定は `output/glacier-implementation/balance.json`、ブラウザ検証は同ディレクトリの `browser-qa.json` に保存する。

## バランス検証結果

全10ステージで当該主道・前ステージ主道とも各30配置で30/30勝利。氷河80の中央値は当該主道131.8秒、前ステージ主道145.7秒。装備主道5段階遅れは1/30勝利。前ステージ主道の最大単発被害は50.482%。入口71と素材集め75は約6秒、その他の通常戦は約45〜60秒。

原画の外縁へ触れたマンモスの5モーションは、元の不採用原画を保持して余白を増やしたV2へ差し替えた。修正の全文指定は [修正生成記録](../../development/assets/glacier-motions/REVISION-PROMPTS.md)。

四足3種の移動は、対角脚の交代・分割境界の検収後に18枚の単コマへ切り替えた。[歩行の修正生成記録](../../development/assets/glacier-motions/SINGLE-TROT-PROMPTS.md) に基準絵、脚の位置ガイド、全文指定、採用原画を保存する。1・2・6でLH+RF、3・4・5でLF+RHが遊脚。単コマ全体を最近傍で等比拡縮し、体の上端で登録する。脚の切り貼りは行わない。

検収項目と計算目標・実測の区別は [制作・検収記録](../production/glacier-motion-review.md) を参照。採用原画69枚で外縁への接触0。歩行は¼×・1×の全6コマ再生を確認済み。

浄化なしの前ステージ主道編成でも氷河80を30/30配置でクリア。ブラウザでは専用20行動の本体・エフェクト、共通188コマと左右反転、鍛冶100ノード、地域8タブ、390px幅、素材ギャラリー7種+11種を検証する。
