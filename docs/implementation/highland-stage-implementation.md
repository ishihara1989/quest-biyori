# 嵐渡りの高原 — 本編実装

2026-10-13 JST。砂漠10クリアで地域7・通算61〜70を解放する。高原10は次地域の実装まで同じステージを周回し、敗北時は前のステージへ戻って同じステージ周回に切り替える。既存セーブを維持し、育成はレベル内の正規化進捗を使う。

## 敵と戦闘

7種・48モーション・独立エフェクト10種を登録した。高原背景と7種のサムネイル、地域素材5種も接続する。

| 敵 | 行動 |
| --- | --- |
| ホーンジャッカル | 近距離の噛みつき。3回に1回出血 |
| 岩角ヤギ | 予告線に沿う短突進、押し戻し40px。封印中は移動せず近接攻撃 |
| 風の小精霊 | 風刃。接近された時に一度だけ後退し、その後2秒は移動しない |
| ストームジャッカル | 弧を描く接近→直線突進→出血爪→休息1.8秒。残像に当たり判定なし |
| アイアンホーン | 角の薙ぎ→固定直線の長突進→岩片3発→休息2秒 |
| ハーピークイーン | 3方向の羽根→風の円→急降下→休息2秒。飛行中も全職から攻撃可能 |
| マンティコア | 二連爪→毒の扇射→翼の突風→飛び込み→休息2.5秒。HP50%以下で毒の追加射撃を一度だけ行う。間隔0.6秒 |

危険行動は既存の予備動作・抵抗力・容量・妨害システムを使う。予告時の位置を固定し、突進や弾を途中で対象へ追尾させない。攻撃の発動時刻に合わせて表示コマを進める。通常攻撃・投射の暗闇判定、封印、後退中の足止めも既存の制御に接続した。

毒は威力×0.12、出血は×0.10、1秒間隔・4秒・非スタック。更新で次のダメージ時刻を早めない。高原由来の1回の継続ダメージは毒6%HP、出血5%HPを軽減前の上限にし、合計を抑える。聖域は状態異常と押し戻しを防ぐ。風の押し戻しは最大70px、同じ対象への再押し戻しは3秒空け、戦闘範囲内に収める。波の切り替え・敗北・勝利で行動、投射物、状態異常を片付ける。

## 素材・育成・バランス

角獣の牙、岩角の欠片、風精の羽、高原の結晶、マンティコアの毒尾を使用する。全6職の武器・防具は地域ごとに100ノード。主道の素材順と費用、ABC各433個・レア90個、基本編成から全取得約300周を維持する。主道の武器・防具を合わせても各段階3周以内の予算。高原の主道は砂漠の主道10から接続し、武器8・9段目の行動妨害力+12%も継続する。Lv.7のジェム、工房・素材変換・装備容量にも地域素材を接続する。

30配置、6人、想定レベル、解放順の最大ランクアクティブ、主道のみで検証。枝・ジェム・薬は使わない。全10ステージで適正装備30/30、前ステージ装備30/30。高原10の装備5段階遅れは0/30。高原10の勝利時間中央値は適正121.5秒、初回137.3秒、初回の最大単発被害は50.0%HP。1・5は回復用の短い周回、通常難所は約46〜77秒。全配置の記録は `output/highland-implementation/balance.json`。

## 四足素材と検収

マンティコアはユーザー採用のV2の足先の運動を保持し、①の右後脚の太腿から足への接続だけ修正した。初回修正は第五の足を追加したため不採用。旧V1と修正前のV2原画を残す。

他4種にも脚別の歩幅・持ち上げ量・関節・斜め投影を計算したガイドを作った。3コマ単位の生成では接地が正しく交代しなかったため1コマ単位に分割し、脚の所属・接続・接地とコマ間の運動を確認した。ホーンジャッカルの奥前脚の伸びすぎ、ストームジャッカルの接地逆転と尾先の見切れを局所修正した。胴体・目の位置と共通縮小率で登録し、フレームごとの足裏位置合わせはしない。

計算した座標は目標であり、出力の実測値と混同しない。原画と目標の差は残るため、脚の接地・解剖・自然さを別々にレビューする。今後の制作・検収は [四足歩行の標準手順](../policies/quadruped-trot-production.md) とAGENTS.mdに従う。各敵の `public/assets/highland-motions/trot/<enemy>/` にガイド・原画・プロンプト・選択レシピ・検収記録を保存する。旧歩行のSHA-256付きバックアップは `public/assets/highland-motions/backups/`。

本編の素材は `public/assets/enemies/` と `public/assets/effects/highland-*/`。生成・監修用の原画は `public/assets/highland-motions/` に保持する。`npm run build:highland` は選択レシピを再利用し、旧歩行へ戻さない。

最終検査は高原11テスト、関連回帰68テスト、全214コマの素材検査、確認画面52項目とマンティコアガイド10項目を通過。本編では19行動に加え、四足5種の左右反転・80姿勢・6→1の再生・待機／被弾／攻撃への切り替えを検査した。選択原画30枚の四辺も個別に確認し、原画の見切れを梱包後の余白で見逃さない。装備・地域の画面は幅390pxでも横にはみ出さず、読み込み／実行エラーなし。

## 検証コマンド

- `npm run test:highland`：進行・セーブ・素材予算・行動・状態異常・フレームレート独立性・登録素材。
- `npm run audit:highland`：適正／初回各30配置、大ボスの装備5段階遅れ、最大単発被害。
- `npm run check:highland-ui`：地域・装備・全19行動・画面サイズ390px・読み込みと実行エラー。
- `node tools/balance/audit-highland-motions.cjs`：PNG・GIF・透過・見切れ・再生・原画へのリンク。
- `node tools/verify/verify-highland-motion-ui.cjs`：48モーションと10エフェクトのコマ送り・再生・切り替え。
- `node tools/assets/highland-review-record.cjs`：四足4種の選択記録と旧歩行のSHA-256照合。
