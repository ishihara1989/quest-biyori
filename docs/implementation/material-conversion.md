# 素材変換

2026-10-11実装。「アイテム」→「素材変換」で、始まりの森・毒の沼地・洞窟・海岸のステージ別タブを切り替える。各タブに5系統の変換をまとめ、コモン素材への変換では獲得する1種をアイコンで選ぶ。

| レシピ | 消費 | 獲得 |
| --- | --- | --- |
| コモン → 結晶 | A・B・C 各2個 | D 1個 |
| 結晶 → コモン | D 1個 | A・B・Cの選択した1種 3個 |
| 結晶 → 大ボス | D 5個 | E 1個 |
| 大ボス → 結晶 | E 1個 | D 3個 |
| 大ボス → コモン | E 1個 | A・B・Cの選択した1種 9個 |

A・B・Cは地域のコモン素材、Dは地域結晶、Eは地域の大ボス素材。地域をまたぐ変換はできない。ゴールド費用はない。

2026-10-15修正：全9地域で、各地域の最終ステージ（1-10〜9-10）をクリアすると、その地域の全9レシピをまとめて解放する。1〜9ステージ目では解放しない。素材の所持・ドロップ入手は解放条件にしない。既存セーブもクリア状況から同じ条件で判定する。

2026-10-15表示修正：未解放のレシピと地域タブは表示しない。解放済みでも、入力素材・出力素材のいずれかが未入手ならそのレシピを非表示にする。入手後に素材を使い切っても表示を維持する。変換の実行条件と素材消費量は従来どおり。

「変換」で1回、「最大」で所持素材が足りる回数を一括変換。所持数上限を超えない回数に制限する。未解放・不足・不正な回数の要求は素材を消費しない。変換結果は即座に保存し、既存の所持数・クリア状況から復元する。

検証：`npm run test:conversion`。ローカルサーバー起動後に `npm run check:conversion-ui` で実画面の解放・変換・保存・地域/タブ切替・モバイル表示を確認する。
