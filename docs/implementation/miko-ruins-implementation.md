## 加入・育成・保存

海岸10（通算40）初回クリアで巫女がLv.40・レベル内進捗0から加入する。過去4地域の武器・防具の主道40個ずつと、Lv.40までの8アクティブをランク5で取得済み。40SPを使用済みとし、そのクリアの経験値を巫女へ重ねて与えない。加入演出、6人のパーティー表示、スキル取得・返却、装備、ステータス、自動進行に対応した。

海岸クリア済みの旧セーブに巫女がない場合も加入状態を補完する。新規セーブと加入後に育成したデータは通常の保存・読込を行う。

古代遺跡は通算41〜50。各キャラクターの武器・防具に第5地域の100ノードを追加し、海岸主道の完了で解放する。2026-10-11の素材コスト方針を維持し、100個の費用はコモン各433個、結晶106個、レア90個。武器・防具の各段階の主道合計は期待ドロップ約3周以内。経験値は既存のレベル内正規化進捗を継続する。

## 巫女の戦闘

通常攻撃と全20アクティブを実装。独立召喚は攻撃2契約・回復1契約・補助1契約。同じ種の再召喚は更新し、個体数を増殖させない。召喚個体に敵のターゲットになるHPや衝突判定を付けない。

回復は低HPの味方を優先し、最大HP・スキルごとの回復上限を守る。バリアは残量と新規量の最大値で更新し、加算しない。鼓舞は梟・神楽の最大値を一度だけ適用する。憑依は通常1体1種・同種1体で、双霊憑依中だけ1体2種。巫女・宿主の死亡、ウェーブ終了、敗北時に該当する召喚や予約攻撃を解除する。

召喚の寿命・行動周期・再使用時間は本体の動作速度と分離。烏2体の発動は180msずらし、命令後も通常の行動時計をリセットしない。連続命令でも同じ個体の発動間隔を300ms以上に保つ。剣霊の追撃は通常攻撃1動作につき1回で、追撃から再発動しない。

総霊神楽と万霊神楽は再使用時間を共有する。協力攻撃は生存者が通常攻撃の60%を1回ずつ、200msの遅延後に順に発動する。万霊神楽の追加契約は空き枠だけを一時的に埋め、神楽終了時に解除する。既存召喚の寿命は延長しない。

制作済みの巨大守護霊・鳥居・衣・召喚・回復線・バリアを描画し、支援アイコンには効果名・数値・残り時間のツールチップを用意した。通常の6人戦闘と神楽、スマホ幅390pxをブラウザーで確認した。

## 遺跡の戦闘・報酬

敵8種の待機・移動・被弾・撃破と固有行動、18種のエフェクト、遠景と近景の背景を登録した。矢・砲撃・魔導弾・光柱・炉心照射は発射位置と狙いを固定して予告し、連続着弾をずらす。ゴーレムの連撃、セラフィナの再充填、タイタンの放熱も実装した。新しい状態異常は追加していない。

5-5は4種×4体×3ウェーブ、計48体。5-10は雑魚混成、通常ボス3体、タイタンの3ウェーブ。古代石片・青銅歯車・魔導片・遺跡の結晶・古代炉心の報酬、ジェム、素材変換、鍛冶、保存に対応する。通常素材30%、ボスの通常素材100%、結晶30%、大ボス結晶100%、レア30%、ボスのレアジェム5%・ユニーク0.5%は既存どおり。

- `npm run test:miko`：加入・旧セーブ・SP返却、全20技、契約枠・更新・寿命、回復・バリア、憑依、神楽、死亡・ウェーブ時の解除。
- `npm run test:ruins`：10ステージ・敵8種、報酬と変換、全員の100ノード・費用・解放、敵の固有行動と固定照準、素材の存在。
- `npm run check:ruins-ui`：ゲーム本体で加入・6人・育成・報酬画像・全20技・召喚、神楽・万霊神楽・九尾、幅390px。ページエラー・画像読み込み失敗0件。独立したブラウザー保存領域を使用する。
- `npm run audit:ruins`：各30配置、適正主道・初回主道・支援OFF・装備10段階遅れを比較する。結果は `output/ruins-implementation/balance.json` と `balance.md`、画面は同ディレクトリのPNGへ保存する。

今回の全体検査は300件中284件通過・16件未達。巫女・遺跡の追加検査と素材検査は通過した。全体検査後に加えた「宿主死亡で双霊の衣を解除」「神楽の仮契約を通常の再召喚で更新」の回帰検査1件も個別実行で通過した。16件の内容は末尾に記録する。ログは `output/ruins-implementation/npm-test.log`。

実戦の初回攻略・適正主道は全10ステージで30/30勝利。適正主道の全員生存は各27/30以上、通常難所の討伐中央値は約46〜54秒。1・5は容易な約9〜13秒。初回の最大単発被害は最大HPの約16%以下。
