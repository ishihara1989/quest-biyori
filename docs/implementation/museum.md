# 資料館

2026-10-14実装。本編メニューとフッターの「資料館」、スキル詳細の「▷ 資料館」から開く。

## 展示と解放条件

- 味方の基本モーション：加入済み。既存の加入判定 `ForestProgression.unlocked` を利用する。
- 味方の通常攻撃・スキルエフェクト：加入済み、かつそのスキルの `unlockLevel` に到達。習得ポイントの使用、強化ランク、前提スキルの購入は要求しない。
- 敵のモーション・エフェクト：実際の戦闘で遭遇した敵だけを表示する。開始時の敵、後続ウェーブ、召喚された敵を記録し、敗北しても遭遇記録を保持する。
- 未加入の味方、未遭遇の敵、レベル未達のスキルは、名前・画像・項目・解放条件を一覧に出さない。地域の選択肢と件数も表示対象だけから作る。

2026-10-15更新。`encounteredEnemies` に遭遇した敵を保存する。記録のない旧保存データは、クリア済みステージのウェーブから遭遇済みの敵を復元する。資料館の操作は育成・所持品・進行を変更しない。

本編のスキルツリーも現在レベルまでのノード・接続・レベル目盛りだけを表示する。アイテム欄は入手した素材・消耗品だけを表示し、使用後の0個表示は維持する。ジェムの破片・工房のレア度・破片変換・解体設定は、`discoveredGemRarities` に記録した入手済みレア度だけを表示する。旧セーブは現在所持するジェムからレア度の履歴を復元する。破片だけではジェム入手済みと判定しない。破片変換は変換元・変換先の両方が既知の場合だけ表示する。素材変換は解放済み、かつ全材料と出力が既知のレシピだけを表示する。未到達地域・ステージ、未加入キャラの自動装備設定、未解放の装備ページも非表示にする。

## 操作

2026-10-16更新。上部メニューのツールチップも「資料館」に統一。敵の素材一覧に `kind` がある場合はその分類を使い、未指定は従来どおりモーションとする。女神の本体7項目をモーション、帰還の扉・玉座・天環・着弾・指先の光・追尾流星・流星の星冠・界面断裂・天環の波の9項目をエフェクトとして展示する。素材の登録処理にも分類を保持する。

危険技予告以外に残る図形描画は [エフェクト画像化の残件一覧](procedural-effects-inventory.md) を参照。

味方／敵、敵の地域、展示対象、モーション／エフェクトを順に選ぶ。スキルは技ごとに一覧表示し、同じ技の複数素材はプルダウンで切り替える。巫女の召喚獣・守護霊・憑依・歩行も対象。

再生・一時停止、最初から再生、前後のコマ送り、コマ一覧の直接選択、0.25／0.5／1／2倍速、表示倍率、暗色／明色／市松背景、ループ切替を備える。コマ送りは可変の表示時間と `frameSequence` に従い、端で循環する。ループOFFでは最終コマで停止する。動きを減らす設定では一時停止から始める。

開いている間は既存メニューと同様に戦闘が停止する。閉じる／他メニューへ切り替える際に資料館の再生を停止し、読み込み中に閉じても遅れて画面を上書きしない。

## 登録と検証

- `tools/assets/build-museum.cjs`：本編の職・スキル・ステージ定義と採用済みマニフェストから `public/assets/museum/index.json` を作る。新規素材・職・敵・初登場ステージを変更したら `npm run build:museum` で再登録する。
- `public/js/core/museum-library.js`：解放条件とコマ位置の計算。
- `public/js/ui/museum-ui.js`・`public/css/museum.css`：資料館の画面と再生。選択した素材だけを遅延読み込みする。
- 手裏剣の回転、次元の門の動作・出現・崩壊は本編の画像／描画処理を使ってコマ送りできる時間軸で表示する。

本編用の画像とマニフェストのみを参照し、開発用GIF・原画・検証画面には依存しない。

検証コマンド：

```sh
npm run build:museum
npm run test:museum
npm run check:museum-ui
node tools/verify/verify-museum-ui.cjs --browsing-only
npm run check:content-discovery-ui
npm run check:structure
```

自動テストは登録の更新漏れ・画像参照、全職の加入と必要レベルの境界、全敵の遭遇と旧セーブのクリア履歴からの復元、保存再読込、表示時間の異なるコマの前後移動を確認する。ブラウザ検証は本編のみを配信する隔離サーバーと独立した保存領域を使い、全職・全地域の代表展示、再生操作、スキル画面からの移動、閉じる処理、戦闘の停止・再開、通常幅／狭い幅を確認する。スクリーンショットは `output/museum-ui/` に出力する。

`--browsing-only` は表示・分類・操作・保存不変性・閉じる処理・通常幅／狭い幅・動きを減らす設定を確認し、戦闘開始後の停止／再開だけを除く。2026-10-16の分類修正時、通常の全項目検証は既存の戦闘停止／再開で失敗した。`forest-game.js` の戦闘更新条件にメニュー表示中の停止条件がなく、資料館を開いても戦闘時間が進む。この残件は表示・分類の修正範囲には含めない。
