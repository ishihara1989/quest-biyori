# 忍者の実装記録

2026-10-10。仕様：[ninja-skill-design.md](../design/ninja-skill-design.md)。今回の依頼に合わせ、バランスは少数の実戦サンプルで確認し、敵の数値は変更していない。

## 加入・育成

- 沼10（通算20）の初回クリア報酬で加入。次の戦闘から4人目として同時出撃。
- Lv20・進捗0%・20SP、通常手裏剣R1。アクティブは未取得で、Lv5〜20の4技を各R5にできる。
- 武器・防具はそれぞれ森・沼のメイン20ノードを初期所持。枝と終端は未取得。
- 沼10クリア済みの既存セーブにも加入。育成済みの忍者はレベル・スキル・装備・ジェムを維持。
- 経験値、装備の費用、ドロップ確率、無料振り直しは共通ルールを継続。

## 戦闘

通常手裏剣と全20アクティブを [ninja-skills.js](../../public/js/skills/ninja-skills.js)、[ninja-combat.js](../../public/js/combat/ninja-combat.js) に実装し、本編と確認ページが同じ [forest-simulation.js](../../public/js/combat/forest-simulation.js) を使う。

- 弾は地面座標で掃引判定。通常弾は照準先の死亡後も直進し、最初の接触敵へ1回命中。風魔は往復各1回、部位と本体は同一の所有者へ重複しない。
- 動作と通常周期に攻撃速度を適用し、動作は最短0.18秒。MP・個別再使用・設置周期・寿命・状態時間は独立した時計。
- 分身は上限6、終了後に共通待ち8秒。通常分身は開始時の能力を継承し、奥義分身は共通の発射時計を使用。
- 影写しは指定の投擲1動作につき1回消費、35%・150ms遅延。元のクリティカルを維持し、状態異常・分身・別の複写を再生成しない。
- 目眩まし・移動低下・移動停止・技封じ・行動停止を実装。[enemy-control.js](../../public/js/combat/enemy-control.js) で攻撃を分類し、拘束・凍結・スタンも共通の制限上限2秒と終了後の耐性2.5秒を使用。
- ボスの強制限免疫、目眩ましの軽減、飛行フラグによる撒菱除外、MP不足、対象の死亡・潜行、本体死亡、ウェーブ終了を処理。

## 素材

既存の待機・移動・跳躍・通常投擲・印を再利用。追加のキャラクター画像とVFXは built-in image_gen で生成し、生成画像の切り出し・透過保持・位置登録・nearest-neighbor縮小でパッケージ化した。

| 追加モーション | コマ数 |
| --- | ---: |
| throw-combo（連続投擲） | 6、3＋3の分割生成 |
| throw-tool（道具投擲） | 3 |
| cast-release（印の解放） | 3 |
| air-throw（空中投擲） | 3 |
| lay-trap（地面散布） | 3 |
| low-dash（低い抜け動作） | 6、3＋3の分割生成 |

計24コマ。登録は320×256、接地ピボット(160,239)。原画・生成プロンプト・個別PNG・シート・マニフェスト・確認GIFを各モーションに保存。3コマの境界が原画の等分線を越えた素材は、実際の透過区間で切って全身を保持した。

初回の追加VFXは風魔、閃光、出現煙、消滅煙、撒菱、影釘、札、糸、電撃針、朧煙幕、結界、終撃の12種・42コマ。後半の演出強化でさらに6種・24コマを追加し、計18種・66コマになった。[演出強化と生成素材](../production/ninja-fx-enhancement.md) を参照。21個のスキルアイコンは生成素材から切り出し、状態アイコン5個は既存の小型UIアイコン方式を拡張。広い煙は薄く、弾・敵・本体を識別できる濃さで描画。

再生成・再登録の入力は [ninja-generation.json](../../development/records/ninja-generation.json)、[ninja-effect-generation.json](../../development/records/ninja-effect-generation.json)、[ninja-fx-upgrade-generation.json](../../development/records/ninja-fx-upgrade-generation.json)。すべてリポジトリ内の保存済み原画を参照し、個人の生成ディレクトリには依存しない。

## 確認

- `npm run test:ninja`：全技・全ランク・左右・速度1/10、ダメージ予算、分身・複写、部位、飛行、制限、MP不足、中断・死亡・ウェーブ後処理、加入とセーブ移行。
- `node tools/assets/check-motion-assets.cjs ninja`：忍者全13モーション・55コマの透過、余白、接地、シート、GIF枚数・時間。
- `npm run check:ninja-ui`：[確認ページ](../../development/labs/ninja-skill-lab.html) の全技、R1/R5、反転、高速、低速連続再生、コマ送り、地上／飛行／部位、6分身、エフェクトOFF、MP0、移動停止、モバイル、本編のツリー・返却・鍛造・戦闘・沼10加入演出。JSエラー、画像の読込失敗なし。
- 育成・既存3職・森／沼／洞窟／海岸の関連回帰テストも通過。

`npm run audit:ninja` の簡易実戦：洞窟1・5・10を各3seed、前ステージまでのメインと当該ステージのメインで測定。枝・ジェム・パッシブ・専用強化・薬なし。

| 通算stage | 前段階メイン | 当該メイン | 前段階での戦闘時間 |
| --- | --- | --- | --- |
| 21・洞窟1 | 3/3勝利、忍者は加入Lv20 | 3/3勝利 | 5.8〜7.8秒 |
| 25・洞窟5 | 3/3勝利 | 3/3勝利 | 5.2〜7.4秒 |
| 30・洞窟10 | 3/3勝利 | 3/3勝利 | 45.6〜49.3秒 |

洞窟10ではMPが最少で約7まで減るサンプルがあり、通常攻撃へ戻って継続できた。一方、Lv30・メイン20でも3/3勝利した。古い装備での敗北条件と、洞窟序盤の短い戦闘時間は、追加キャラ・ステージが揃った後の固定バランス再調整候補。今回の追加で敵HP・火力を動的に増やす処理は入れていない。

詳細と画面キャプチャは `output/ninja-skills/`（Git管理外）。
