# パッシブの成長能力を割合補正へ変更

2026-10-17実装。装備の固定加算が増える後半でも育成効果が残るよう、全6職の攻撃力・最大HP・防御・最大MP・MP回復パッシブを割合補正に変更した。

## 採用値

各値は1ランクあたり。各5ランク・1SP、解放レベル・スキルID・取得済みランクは維持する。

| 対象 | 戦士 | 魔法使い | パラディン | 忍者・呪術師・巫女 |
| --- | ---: | ---: | ---: | ---: |
| Lv.1の攻撃力 | +5% | +5% | +5% | +5% |
| Lv.7の最大HP | +6% | +5% | +6% | +5% |
| Lv.7の防御 | +5% | +5% | +8% | +5% |
| Lv.12のMP回復 | +10% | +10% | +10% | +10% |
| Lv.32の最大HP | — | — | +6% | — |
| Lv.52の最大MP | +5% | +5% | +5% | +5% |
| Lv.52のMP回復 | +5% | +5% | +5% | +5% |

攻撃力・最大MPは最大ランクで+25%。MP回復の2スキルは最大ランク同士で+75%。パラディンの最大HPは2スキル合計で+60%。職差は防具パッシブのHP・防御に残した。移動速度・範囲・連鎖距離や既存の割合効果は従来値を維持する。

## 計算と保存

- 成長能力は `damagePercent` / `maxHpPercent` / `defensePercent` / `maxMpPercent` / `mpRegenPercent` で集計。同じ能力への割合は合算する。
- HP・MP・防御は、基礎値＋レベル成長＋装備・ジェムの固定加算へ `1＋割合合計` を掛ける。
- 攻撃力は汎用攻撃力と物理・魔法専用の固定加算まで含めて割合補正し、その後に既存の武器／魔法攻撃倍率を掛ける。通常攻撃とアクティブの両方へ反映する。
- 魔法使いのエピック防具は最大MPの割合補正後にMPを3倍にし、その最大MPの5%を回復へ加算してから、MP回復の割合補正を掛ける。
- セーブは既存のスキルID・ランクを保存したまま、新しい効果で再計算する。SP返却・全振り直しを維持し、実行中の戦闘への反映時期は次の戦闘開始時とする。
- 効果欄とツールチップは「攻撃力 +5% / Lv」のように効果名と数値だけを表示する。

## 確認

- 関連テスト130件が合格。新規の割合テストでは全6職の低レベル・後半装備、ランク1〜5、専用ジェムの加算、割合の合算、エピックMP回復の計算順序、保存・減算・全返却・戦闘開始への反映を確認。
- `npm run test:passives` で既存パッシブと新規割合テストを実行する。
- `FOREST_TEST_URL=http://127.0.0.1:4193/` を指定した `npm run check:passives-ui` が合格。全6職のアイコン・取得・割合ツールチップ・依存先返却・再読込・1440px/900px幅を確認。
- ローカルmainの開始コミット `7eed6e39` と、全100ステージの適正／前ステージ装備および洞窟以降の大ボス5段階遅れ、混沌の門2条件・女神2条件の1,061キャラ構成を比較。新規割合集計キーが0であることに加え、全戦闘能力・スキルパラメータが一致した。初回攻略基準が使うパッシブ未取得構成は変わらないため、同条件の戦闘再計算は行わない。
- 比較出力は `output/passive-percent-stats/reference-equivalence.json`、ブラウザ画像は `output/expansion-passives/`。
