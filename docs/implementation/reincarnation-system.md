# 実績・転生の女神・転生システム

2026-10-20 JST。本編実装済み。試練システムは今回の対象外とし、関連5ノードは **Coming soon・購入不可**。本書を現行仕様とし、[企画書](../design/reincarnation-system-design.md)と[ツリーモック](../design/reincarnation-tree-mock.md)は設計経緯として残す。

## 解放と秘匿

1. 全6職の武器・防具に、職・部位の合うエピック12種を合法に同時装着する。
2. その構成で開始した異次元の女神戦に勝つと、「女神の配送センター」を永続発見する。途中の装着変更・所持品だけでは判定しない。
3. 転生の女神に勝利すると、転生・スキル自動取得・ジェム自動装備を同時解禁する。自動化は初期OFF。

発見と転生解禁には、それぞれ画像素材を重ねた7.6秒の専用演出を用意。報酬へ進む操作で短縮できる。動きを減らす環境では2.6秒の静止中心の表示にする。発見前の新ボス、撃破前の転生メニュー、エピック発見前の隠し条件は、ステージ・実績・通知に表示しない。実績の総数・達成率から隠し項目の件数を示さない。

## 女神の戦闘

制作済みの基本4素材17コマと兵器・FX20素材60コマを `public/assets/enemies/reincarnation-goddess/` に採用。通常攻撃はパルス散弾機関砲→陽電子レール砲→追尾ミサイル→重力ブーメラン→衛星スタンプ砲、次にトラック。HP半分以降は行動後の間隔が短くなる。

- 扇・直線・最大3対象の小円・往復する弧・大円・突進帯で危険範囲を区別。
- レール砲は最後の0.7秒に照準固定。ミサイルは着弾0.25秒前、衛星は0.7秒で地点固定。
- 円盤は行き・帰り各1回。最初の接触だけ移動速度−20%を1.2秒。
- レール砲とトラックに既存の妨害・抵抗成長を適用。トラック中断後は涙目・爆発と2.3秒の隙。回収爆発に味方への被害はない。
- トラックは独立した敵・HP・報酬を持たず、本体の二重表示をしない。衝突は対象ごとに1回まで。
- HP0で勝利を確定し、予約攻撃を消す。右上の門へ帰還して2.4秒で消える。演出中に180秒を超えても敗北へ変えない。

採用HPは200億、制限180秒。Lv.100・通常装備と女神装備完成・対応エピック12種・従来の全アクティブ配分・通常ジェムなし・薬なし・転生強化なしの固定30配置で **30勝、中央値168.950秒、最長170.383秒**。最大単発・同一行動の合計被害はいずれも最大HPの約20.16%。全配置で6人が生存し、全6種類の攻撃が出現。最適ジェムや追加SPの最適化まで180秒へ揃える調整はしない。

## 転生の精算と保存

毎周の転生の女神撃破を条件とし、転生確定で100 PTを付与。同じ周での再撃破はPTを増やさない。周IDと撃破資格を別に保存し、次周へ古い資格を持ち越さない。画面にはPT、リセット対象、保持対象、現在の主要倍率を表示する。

確定前に次セーブ全体を別オブジェクトで作り、単一のlocalStorage更新が成功してから再読込する。保存失敗・取消では現在のセーブを変更しない。確定ボタンの連打と再読込で同じ周を二重精算しない。

| リセット | 保持 |
| --- | --- |
| 全職Lv.1・経験値0、スキル、装備取得、所持金と端数 | 転生回数・総獲得PT・取得済み転生ノード |
| 全素材・薬・ジェム・破片。装着中・保護中も含む | 実績・発見・エピック収集・装備完成の生涯記録 |
| 今周のクリア・通過・加入。戦士と森1から開始 | 機能・レシピ・装備ページ・特殊ボスの発見 |
| 進行中の戦闘・未受取報酬・予約 | 自動強化・解体・スキル・ジェムの設定、速度・周回設定 |

仲間は毎周再加入する。過去に見たステージは表示を保持するが、入場・装備購入には今周の到達が必要。転生の女神へは今周の異次元の女神撃破で再入場でき、12種装着の儀式は繰り返さない。

既存セーブは保存バージョン2を維持して追加フィールドを移行。現在のクリア・所持品・装備から証明できる実績のみ復元し、過去の変換・解体・同時装着勝利を推測しない。移行した実績を大量の個別演出で再通知しない。

## 転生ツリー

第3版モックの140ノードと価格を採用。試練5件を除く135件を取得可能にする。前提・費用・効果と購入確認を表示し、払い戻しは設けない。空白ドラッグは既存の `TreeNavigation` を共用し、両軸スクロール・系統絞り込み・名前検索・前提への移動に対応。

- 個数・ゴールド・火力・HP・経験値は取得段階の最大値。前段階の倍率を重ねない。
- 経験値は報酬ステージへ指数を加えて正規化進捗を更新。Lv.100上限と3^(-20)以下を0とする規則を維持。
- レベル由来SPは `floor(L × (100 + 加算率) / 100) + 10Lv加算 × floor(L / 10)`。装備SPを別加算し、保存復元も同じ予算を使う。
- メイン素材無償化は通常10地域・全職・武器／防具の主道のみ。ゴールド・前提・今周の到達条件を保持。手動・一括・自動で同じ費用を使う。
- ジェム制作の大ボス素材軽減は欠片数を維持。地域Lv強化の結晶には適用しない。制作→解体で欠片を増殖できない。
- 方向容量・共通容量・専用容量を分離。専用容量を転生容量で代用しない。
- ドロップ率はパーティー共通で1回加算。ドロップ個数倍率は既存抽選後に整数倍し、増えたジェムは別個体として生成。ゴールド・固定初回報酬・制作・解体の出力へ個数倍率を掛けない。
- スキップ幅は＋2・＋3・＋4。通常の大ボスを飛び越さず、着地先の勝利時だけ途中を通過扱いにする。通過区間の経験値・素材・ゴールド・初クリア実績を与えず、加入と購入ゲートには反映。生涯の実クリアと通過も別に保持する。

戦闘中に変更した能力・報酬倍率は次の戦闘から反映する。戦闘開始時のエピック判定、倍率、能力を固定する。

## 自動化と実績

スキルは個別OFFと優先度1〜7。同順位は解放Lvの高いものを優先し、取得可能な1ランクを繰り返し購入する。編集画面で選んだ職の自動取得を止め、閉じると再評価する。

ジェムは各職・武器／防具ごとに、優先効果3件、最低レア度、エピック優先、同等なら容量節約、装着固定を設定。未装着と同じ部位の候補から、戦士→魔法使い→パラディン→忍者→呪術師→巫女、各職武器→防具の順に選ぶ。トレハンは単体数値ではなく合法な組合せの合計を比較し、重い1個より軽い2個が有利なら組合せを採用する。候補と探索件数を制限し、現在の合法な構成も比較に残す。画面更新ごと・1個入手ごとの全再探索はしない。

精算は報酬登録→自動装備強化→スキル自動取得→ジェム自動装備→残った未装着品の自動解体→保存→次戦闘。自動装備ON時は自動解体を保留して、装着した個体を先に守る。

実績は冒険・仲間・宝石・装備・工房・転生を収録。能力報酬は付けず、バッジと獲得日を残す。装備は職・部位・地域ごとの主道完成、ユニーク初取得／完成、全取得と、完成本数・完全装備を生涯の固有ツリーIDで数える。同じツリーを複数周完成させても本数を増やさない。おすすめは最大3件、装備の詳細は折りたたむ。
