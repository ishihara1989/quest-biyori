# 封印3種・孤道I〜IIIの本編実装

2026-10-22 JST。「これまでの結果から実装」の指示により、[解放ノード](sealed-trial-unlocks.md)に続いて、[封印の設計](../design/sealed-trials-and-progression.md)と[ソロの測定案](../design/solo-trial-balance.md)を本編へ採用した。

## 解放・戦闘条件

「輪廻の絆」「封印の試練」は各4,000 PT。封印の前提は試練の扉・闘志5・生命5・輪廻の絆。封印ノードを取得すると、封印3種と全6職の孤道Iを選べる。未実装の上位少人数ノード「孤星の旅路」は今回のI〜IIIの前提にしない。

| 試練 | 条件 | PT倍率 | 次周からの初クリア報酬 |
| --- | --- | ---: | --- |
| 無彩の誓約 | 全職・全部位のジェム装着と装着効果を封印 | 5 | 互換性のある全ジェム能力を固定加算、武器・防具容量による別枠倍率 |
| 半知の戒律 | 解放Lv.51以降のスキルを封印 | 1.5 | 総SPの100超過分1につき与ダメージ・HP＋1% |
| 幹道の誓約 | 装備メインノードのみ | 5 | 通常サブ・ユニーク由来の攻撃力・HP・防御力＋20% |
| 各職の孤道I | 指定職1人で出撃 | 職別 | 他職のソロ試練で小支援 |
| 各職の孤道II | 同職I・強靭2の初クリア、強靭2以上を必須併用 | 職別 | 他の試練で強支援。Iを置換 |
| 各職の孤道III | 同職II・女神の本気の初クリア、女神の本気を必須併用 | 職別 | その職の武器・防具の恒常エピック2効果 |

ソロは別職・別段階と同時選択できない。他の通常試練・封印は併用可能。IIの強靭2と任意の上位強靭は最高段階にまとめ、IIIの女神の本気も一度だけ適用する。IIIは道中の幻影・女神援護、両女神同時戦、両方の帰還を待つ勝利条件まで通常の「女神の本気」と同じ。

2026-10-23：次の周の選択では、別系統の前提も自動選択する。孤道IIは強靭2以上、孤道IIIは女神の本気とその前提の猛攻・頑強、女神の本気・ゲート解放は猛攻・頑強を選ぶ。前提を外すと依存する試練も連鎖して外れる。依存先だけを外した場合は前提の選択を保持する。同系統の下位段階は初クリアによる解放条件のため同時選択しない。今周の試練から候補を表示するときも同じ補完を行い、適用は次の周の開始時とする。

## 封印と恒常報酬

無彩の報酬はLv.10・品質1のレジェンダリーの**1能力欄**を基準にする。攻撃力・HP・防御力は3欄、他は1欄。エピック以外の現行効果を職適性に従って加算し、パッシブの割合強化前に入れる。MP回復・範囲・妨害・抵抗・被弾回復・レジェンダリー追撃などは既存の同じ能力フラグへ統合し、既存の間隔・上限を使う。

武器は与ダメージ、防具はHPへ `1+(攻撃容量+防御容量+補助容量+共通容量)/10000` を別枠乗算する。100未満を切り捨てず、職専用容量は含めない。SP報酬も `1+max(0,総SP−100)/100` の別枠乗算。未使用SPではなく獲得総SPを使い、スキル仕様の生成前に攻撃能力へ反映する。

幹道の報酬は通常地域1〜10のサブ・ユニークノードに直接書かれた対象能力だけを1.2倍にする。取得数ボーナス、容量、SP、ドロップ、女神装備は対象外。挑戦中は取得済みの非メイン効果・取得数・女神SP枝も無効。通常購入・経路一括・自動購入・復元で同じ制限を守る。

ジェム封印中もドロップ・所持・分解・制作は可能。手動・自動装着、保存データ内の装着効果は無効。スキル封印も解放Lv.51以降の購入・自動取得・既取得効果・復元を対象にする。放棄時は制限を解除し、新しい戦闘の編成・能力・人数表示を更新する。

**恒常報酬は再挑戦中も有効**とした。ソロIIIの恒常エピックもジェム封印中に有効。装着版と同じ効果キーを1へ統合するため重複しない。対応ジェムはドロップ・制作・自動装着の候補から外し、手動の再装着も不可。所持済み個体は削除せず、保護・分解の通常ルールを維持する。全12効果取得後はエピック抽選を空振りとし、他レア度の抽選区間を動かさない。

## ソロ・支援・巫女AI

指定職を戦闘の主キャラ位置へ置き、他の5職を編成から除く。戦士の仮キャラは残さない。選択職だけが経験値・取得・自動化の対象になり、最初はLv.1。本来の加入時のレベル・装備・スキルは支給しない。分身・契約霊など本人のスキルによる召喚は有効。HP／MP・スキル欄・各職の描画も主キャラの職に従う。

支援はウェーブ開幕と10秒ごと。門の小分け召喚でタイマーをリセットしない。戦闘外・終了後は発動しない。支援者を味方人数へ加えず、出撃中の各生存キャラの能力を基準にし、そのキャラ自身の職からの支援を除く。Iは他職ソロ、IIは他の試練でも有効。試練なしの周回では発動しない。

| 職 | I | II |
| --- | --- | --- |
| 戦士 | 近い4体へ100% | 近い8体へ合計450% |
| 魔法使い | 近い3体へ120% | 近い8体へ250%＋凍結1.5秒 |
| パラディン | HP5%バリア・3秒 | HP15%バリア・5秒 |
| 忍者 | 近い3体へ70% | 近い6体へ合計240% |
| 呪術師 | 近い1体の攻撃−10%・3秒 | 近い8体へ200%、攻撃・防御−20%・5秒 |
| 巫女 | HP5%回復 | HP15%・MP5%回復、霊威20%の神楽・5秒 |

攻撃は合計威力の1パケットで、追加クリティカル・ジェム追撃・命中MP回復を誘発しない。無敵・部位を対象外にし、攻撃対象不在の回は空振り。バリアは加算蓄積せず、回復阻害・既存の強い神楽を尊重する。採用済みの斬撃・氷・盾・影斬・呪印・神楽の画像を再利用して発動を描画する。

巫女はソロ出撃中に限り、味方1人でも祭儀を自動選択する。MP・クールダウン・敵HP・既存神楽・攻撃契約の条件は維持する。通常パーティーの祭儀選択条件は従来どおり。

## 保存・UI・再現

既存の保存形式v3を維持し、試練ID・初クリア・適用済み報酬へ追加した。初クリア直後は記録だけを更新し、転生／試練再出発時に報酬を適用する。戦闘開始時の条件と旅程番号を照合し、放棄前の勝利証拠や必須条件の欠けた記録で初クリアを得ない。

試練ツリーは計34ノード。前提・総倍率・必須条件・封印数・支援数・恒常エピック数を表示する。背景ドラッグは共通のTreeNavigationを使用。再出発確認にソロの職名を出し、能力画面の封印理由、所持品の装着不可、恒常エピックの部位表示・制作不可も接続した。

作業用ポートの `/development/labs/reincarnation-system.html` に「孤道III / 巫女」を追加。8,000 PT以下の全ノード、封印2報酬、全職II支援、女神装備なし・エピックなし、通常ジェム約半容量で両女神へ挑む。元のセーブは同タブの復元ボタンで戻せる。
