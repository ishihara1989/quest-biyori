# 呪術師の実装・素材・検証

2026-10-10 JST。[スキル仕様](../design/shaman-skill-design.md)に基づく本編実装。並行作業中のため、バランスは簡易確認までとする。

## 加入と育成

- 洞窟10（通算30）の初回クリア報酬処理後に加入。海岸1から5人同時出撃。
- 加入Lv30・経験値進捗0%。武器・防具のメイン30ノードを取得済み。Lv5〜30の6技をランク5で取得し、30SPを消費済み。
- 洞窟10クリア済みの古いセーブには未育成の呪術師を追加する。既存の育成データは保持する。
- 通常攻撃「呪弾」とLv5〜100の20アクティブを育成画面、無料振り直し、装備・ジェム、再使用表示へ接続。効果表示は名前と数値・パラメータのみ。

## 戦闘

`public/js/skills/shaman-skills.js` がランク・動作時間・作用点・表示パラメータを、`shaman-combat.js` が呪弾、呪い状態、陣、追加ダメージ、AIを管理する。

呪印は5個上限、各10秒寿命、共有の1秒周期。深呪は1枠で、同種は強い威力と長い期限を採用し、異種は残りダメージを比較する。攻撃力低下は敵の動作開始時に固定し、防御低下・DoT増幅・回復阻害は実際の判定時に適用する。

命中・被害に反応する追撃は本体ごとに0.6秒間隔、直近10秒で10回、同一動作1回、術者全体で直近1秒8回を共有する。部位は本体へ集約し、呪いDoT・追撃はクリティカルや再帰追撃を起こさない。死亡時は付与済みの呪印・深呪・能力低下を残し、詠唱・弾・陣・追撃を停止する。ウェーブ終了・敗北では全て消す。

洞窟・海岸の固定防御を共通ダメージ判定へ接続。呪いDoT・追撃・陣は60%、魂砕きは70%、命蝕は80%貫通。オオヤドカリの殻・回転の軽減は別に適用する。ステージのHP・攻撃力、装備費用、素材ドロップの再調整は行っていない。

## 生成素材

内蔵 `image_gen` で透過PNGを生成。元の呪術師を共通リファレンスにして各コマの足・杖・手の位置を指定し、通常の生成は3〜4コマ単位に分けた。登録位置・配色・透過・見切れを確認し、儀式の拡大率と光柱の上端を修正した。

| 追加モーション | コマ数 | 使用例 |
| --- | ---: | --- |
| `hex-weave` | 3 | 呪印を編む、呪鎖・反応呪い |
| `staff-plant` | 3 | 杖の打ち込み、各種陣 |
| `curse-pull` | 3 | 呪爆・呪終・怨結 |
| `ritual-raise` | 6（3+3） | 大呪法・百鬼蝕魂 |

追加エフェクトは27種・89コマ。髑髏弾、刻印、反応輪、追撃棘、怨火、蔓、呪鎖、呪蛾、杭、陣の開閉・脈動、収縮・爆発、魂の槍、百鬼、光柱、破砕、全身詠唱の怨霊、DoTの立ち上る霊影を用意した。21個のスキルアイコンは生成エフェクトから作成した。[全身詠唱・DoT・後半演出の拡張](../production/shaman-fx-enhancement.md)。

後半は複数の陣・周回する髑髏・霊影・残像・粒子を重ね、呪終・怨結の収縮と破裂、百鬼蝕魂の8回脈動と7本の光柱・破砕で強調する。陣と大きな霊影はキャラクターより後ろ、終撃は前に描く。同時刻・同一本体のDoT表示を紫の数値へ集約し、通常の脈動で画面を揺らさない。追撃の棘は判定の60ms後に描く。密集時の同一エフェクトを間引き、動きを減らす設定にも対応する。

- モーション：`public/assets/shaman/motions/{hex-weave,staff-plant,curse-pull,ritual-raise}/`
- エフェクト・アイコン：`public/assets/skills/shaman/`
- 生成プロンプトと登録指定：[`development/records/shaman-generation.json`](../../development/records/shaman-generation.json)、[`development/records/shaman-effect-generation.json`](../../development/records/shaman-effect-generation.json)、[`development/records/shaman-fx-upgrade-generation.json`](../../development/records/shaman-fx-upgrade-generation.json)
- 各素材の `source/`、`PROMPT.md`、`manifest.json` に生成原本・指示・再生情報を保持。光柱の修正前原本と修正履歴も保持する。
- `npm run build:shaman` で保存済み原本から再構築。追加の画像生成は不要。

## 確認

[`development/labs/shaman-skill-lab.html`](../../development/labs/shaman-skill-lab.html) は本編と同じ戦闘処理で全技を再生する。ランク、攻撃速度、左右反転、コマ送り、再生速度、エフェクト表示、地上・飛行・部位、密集・分散・36体、防御、移動停止、MP不足を切り替えられる。呪い状態はマウスとキーボードで確認できる。

- `npm run test:shaman`：加入・移行、全技×全ランク×左右、呪印寿命、深呪の位相、防御、追撃上限、部位、失敗時の消費、死亡・中断、生成素材の構造を確認。
- `npm run check:shaman-ui`：全21技、後半エフェクト、効果表示OFF時のダメージ一致、36体・部位・反転・速度・移動停止・MP不足、育成・返却・装備、本編5人出撃、洞窟10の加入画面をブラウザで確認。
- `npm run check:shaman-fx`：全身詠唱・DoTの表示範囲、36体の混在・部位、左右反転、攻撃速度10倍、連続再生、5人同時出撃の前半・後半ビルドを確認。画像と測定結果は `output/shaman-fx-upgrade/after/`。
- `npm run audit:shaman`：海岸1・5・10、各3シードで加入後の編成を簡易確認。5人編成は各3/3クリア。海岸10は4人で61.1〜72.8秒、5人で46.6〜49.5秒。海岸1・5は短時間のため、呪いが働く前に敵が倒れる場合がある。

検証スクリーンショット、回帰テストログ、簡易確認の全結果はローカルの `output/shaman-skills/` に出力する。これは総合的なバランス保証ではなく、今回の実装が本編で動作することの確認。
