# 基本4系統の試練

2026-10-22 JST。本編実装済み。転生ツリーの「試練の扉」（既存の前提・260 PT）を取得すると、冒険画面と転生画面で選択できる。封印・追加敵・少人数などの残り4ノードは未実装・Coming soonのままとする。今回の4系統は同時選択数の制限なく組み合わせる。

| 系統 | 戦闘効果 | 報酬 |
| --- | --- | --- |
| 強靭 | 全敵のHP・攻撃力・防御力をN倍。Nは2〜10の整数、OFFで通常 | N倍 |
| 猛攻 | 敵の行動クールを半減。通常行動・特殊行動・女神専用タイマーも対象 | 1.5倍 |
| 頑強 | 行動妨害の耐性（ゲージ容量）と抵抗力を3倍 | 1.5倍 |
| 女神の本気 | 異次元の女神・転生の女神のHP・攻撃力・防御力を3倍 | 女神戦のみ10倍 |

ステータス倍率は移動速度・射程・モーション・予告時間には作用しない。強靭と女神の本気は重なり、女神の能力は最大30倍。次元の門・混沌の門の無敵本体はHP1のままとし、召喚される敵は強化する。分身部位は強化済みの所有者の能力を継承する。既存の通常敵・ステージ定義は変更しない。

同じ系統は最高段階だけを採用し、異なる系統の報酬は乗算する。通常戦は最大22.5倍、女神戦は最大225倍。女神の本気を選択したまま通常戦へ移動しても、その戦闘の能力・報酬には適用しない。UIの合計倍率は選択中ステージに対応し、戦闘中と結果には開始時の適用倍率を表示する。

## 報酬と保存

- 素材・ジェムは既存の確率で抽選した後、転生のドロップ個数倍率と試練倍率を乗算。整数部分を確定付与し、端数は追加1個の抽選にする。ジェムの複製は別ID・別個体で生成し、自動装備・解体へ渡す。
- 撃破ゴールド・クリアゴールドは、トレハン・転生ゴールド倍率・試練倍率をそれぞれ1回適用。1未満の端数と、勝利時にまとめて受け取る仕組みを維持する。初回の回復薬・加入人数は増やさない。
- 経験値にも倍率を適用。倍率は3を底とする対数で既存の指数へ加え、レベル内の正規化進捗のまま計算する。正の巨大な累乗を計算しない。Lv.100上限・極小獲得量の0表示を維持する。
- 転生PTは100×報酬倍率。今周の転生の女神撃破のうち最高値を保存し、転生確定時に1回だけ付与する。低い試練で倒し直しても減らず、同じ条件の再撃破では加算されない。最大22,500 PT。
- 戦闘開始時に試練を固定する。途中で選択・解除しても実行中の敵・報酬・転生PTには影響しない。敗北・途中退出・再読込で未受取の戦闘報酬を得ない。
- 転生保存形式をv2に更新。v1の累計PTは従来どおり回数×100として移行し、撃破資格を保持。v2は実際に精算した累計PT・今周の精算予定PT・試練設定を再保存し、転生後も設定を保持する。
