## 戦闘

既存の7種の透過スプライト・9種の攻撃エフェクト・2層背景を本編で使用。攻撃順・発生時刻は `SwampCombat.sequence` を共有する。リッチはエネルギー弾、大魔法、召喚の3行動を循環。召喚は詠唱800ms×2→杖を振り下ろす420ms時点にスケルトン4体を同時出現させる。死亡・中断した詠唱は召喚しない。生存敵の上限24体を超えるときは4体とも出さず、部分召喚しない。召喚された敵もウェーブ完了の判定対象で、通常の素材・ゴールド抽選を行う。

毒液弾・闇の弾は発射位置から480msで着弾し、発射時の対象座標へ飛ぶ。泥の掴みは命中時の座標に2200ms拘束、毒は4秒間で1秒ごとにダメージ。重ね掛けは拘束位置を維持し、毒の威力は大きい方を維持する。死亡・ウェーブ終了・戦闘終了で解除。泥巨人の大技は振りかぶり2ループ→3倍ダメージ、ヒュドラは8回連続攻撃または溜め2ループ→毒ブレス。

## 育成と進行

経験値は保存用ステージID11〜20で既存の正規化処理を使用する。沼地10ではLv.19→20に1周、20→21に3周、21→22に9周。正の巨大な累乗は計算せず、3^(-20)以下の獲得量は0にする。UIはレベル内進捗の％表示。

キャラごとの武器・防具に沼地用100ノードを追加。森と地域別に表示し、取得数ボーナスも別集計。森の主道10→沼地の主道1から接続。主道はクリアしたステージでゲートし、同段の武器・防具を合わせても各ステージ約3周以内の期待素材量、レア素材なし。枝は低コスト・小効果から増加。各ツリー100取得で共通容量＋1を加算する。

基本編成の沼地10の期待ドロップは毒袋2.6、泥2.5、骨1.9、結晶1.9、鱗0.3。終端までに鱗90枚を要求し、全100ノードの予算はツリー1本約300周。ボスの追加召喚は予算見積もりに含めない。

進行設定が「次ステージへ」のとき森10→沼地1へ進む。最終実装ステージの沼地10は同ステージを周回する。敗北時は地域境界も含め1つ前へ戻り、同ステージ周回へ切り替える。既存の保存データを維持し、新素材・新ノード・沼地のクリア状況を保存・復元する。

## 検証

`npm run test:swamp-game` または `node --test tests/swamp-game.test.cjs`。編成、確率境界、経験値、装備予算、召喚の時刻・中断・上限・クリア判定、状態異常、フレーム間隔の決定性、画像の透過を検査。各ステージの想定レベル、前ステージまでの主道、少数の枝、アクティブスキル全振り、ジェムなし・薬なしで30配置ずつをクリア確認。

`npm run check:swamp-game-ui` または `node tools/verify/verify-swamp-game-ui.cjs`。地域選択、背景、敵・素材画像、100ノードツリー、購入と再読込、リッチの召喚、沼地10の結果、森10からの自動進行、390px表示を確認。スクリーンショットは `output/swamp-game/`。
