# UI名称の整理

2026-10-16実装。本編の上部メニュー、サイドバー、各メニューの子タブ・見出し・操作、開始・報酬・加入・解放画面を確認した。

上部メニューは表示名・ホバー表示・読み上げ名を同じ4文字以内の名称に統一した。画面上の操作は動作の名前、状態は短い状態名、条件は対象とパラメータで表示する。操作の補足はツールチップで参照する。初期化・解体の確認では対象と影響を確認できる説明を維持する。

## 検証

画面キャプチャと確認用の出力は `output/ui-labels/`。通常幅1440pxと狭幅390pxで上部8メニュー、育成タブ、ジェムの装備・工房・一括解体、素材変換、設定、資料館を確認する。報酬は勝利・敗北・加入・解放を固定条件で確認する。

- 上記の対象画面確認、メニュー内容の文章調の表示の再検索、UIスクリプトの構文確認が合格。
- `check:structure` が合格。
- `progression-cache`、`gem-inventory`、`forest-conversion`、`museum`、`auto-gear`、`gem-system` の既存テスト計65件が合格。
- 既存の `verify-party-ui.cjs` は文言・操作・通常幅と狭幅の確認を通過した後、今回変更していない装備画像の参照（魔法使い・パラディンの `weapon-castle.png` / `armor-castle.png`）の404で未合格。
- 既存の `verify-gem-dismantle-ui.cjs` は効果の表示件数の期待値が30件、現在のフィクスチャに表示される効果が18件で未合格。今回変更したのは表示文言であり、効果の表示条件・解体の処理には変更を加えていない。解体のフィルタ・保護・報酬処理は上記 `gem-system` テストの合格範囲に含む。
