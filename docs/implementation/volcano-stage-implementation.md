## 状態異常・地面・中断

溶岩床は最大2秒・同時3個、半径54。3個の円の合計面積が実際の歩行面854×167の20%未満になる。重なっても同じ人物への床tickは1秒に1回だけ。火傷と床は直接攻撃と同じ親技の後続被害予算を消費する。

危険技のダメージは適正レベル・前ステージ主道装備の固定参照から計算。現在の味方HPに合わせた補正は使わない。中断は未発射の予約を消し、発射済みの弾・着弾済みの床を維持する。敵の死亡だけでは発射済みの弾を消さず、波移行・勝敗・新しい戦闘で消去する。
