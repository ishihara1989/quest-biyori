# 共通エフェクトの生成画像化・検収

2026-10-16、本編採用済み。[調査一覧の72項目](../implementation/procedural-effects-inventory.md)をすべて画像へ置換した。危険技の予告、HP・残り時間などのUI、接地影、女神の背景調光は同一覧の適用外として維持する。

## 素材と生成記録

標準の組み込み `image_gen` を使用。透過背景を指定し、生成されたRGBAを保持した。共通の白〜銀の素材を職業・属性・地域色へ変えて再利用する。旧斬撃と氷河の状態マークには既存の採用画像を使用する。

| 素材ID | 用途 | 1コマのサイズ | コマ数 |
| --- | --- | --- | --- |
| aura | 発光・溜め・暗転・閃光・星鏡の透過マスク | 256×256 | 4 |
| ring | 光輪・足元・召喚・覚醒・崩壊 | 256×256 | 4 |
| mote | 火花・漂う粒子・状態の印・星弾 | 64×64 | 4 |
| streak | 軌跡・飛び道具の尾・光芯・接続・画像で構成する弧 | 256×64 | 4 |
| lightning | 連鎖雷・門の亀裂・出現時の裂け目 | 256×128 | 4 |
| portal | 開いた門の内部・星鏡 | 256×256 | 4 |

全素材140ms×4コマ、560msのループ。生成前に、発光は収束→膨張→最大→沈静、光輪と門は同じ中心でエネルギーが周回、粒子は小→開く→最大→小、軌跡と雷は両端を揃えて流動・明滅、という4コマの順序を指定した。2×2配置で生成し、コマ間と4→1の接続を確認した。

原画と初稿は `development/assets/effects/common/source/` に保存。発光・光輪はコマの余白を修正し、門は広い外周光と配置を修正した。修正時も初稿を参照した。採用PNG・実行時JSONは `public/assets/effects/common/`、6種の検証用GIF・生成記録・検収記録は開発側へ保存する。

登録時は2×2のセルを分割し、同じ素材の4コマに共通の縮尺を適用して中央へ揃える。ほぼ不可視のα8以下を境界算出から除き、原画の8pxの余白を含める。保持する画素のRGBAは変更せず、最近傍で縮小する。最終フレームには最低4pxの透明余白を確保する。

## 本編への接続

共通描画は [image-effects.js](../../public/js/render/image-effects.js)。生成PNGだけを入力に、フレーム選択・移動・拡縮・回転・色替えを行う。弧や曲がった尾は生成軌跡画像を向きに沿って並べる。色替えは元画像のRGBとαから合成し、図形を描いて素材の代用にする処理はない。色替えキャッシュは16MiBを上限とする。

各職、通常地域、女神、両方の門と共通描画へ接続。星鏡のボスは生成画像のαを使って切り抜き、発動後の範囲には予告用の図形関数を使用しない。資料館は既存の `asset.procedural` というメタデータ名を互換のため維持し、実際には同じ画像描画と読み込み待ちを共用する。

既存5職のスキル検証画面にも共通ローダーを追加した。検証時に見つかった氷河・火山・魔王城のデータ／戦闘モジュールの読込漏れも補い、本編と同じ依存を読み込むようにした。

## 検証結果

- 新規6種・24コマ：PNGの登録・透明余白・可視画素・フレームの相違・時間合計に合格。明暗背景で全コマを確認。通常／0.25倍速で各4コマが連続再生され、4→1もつながることを確認。検証GIFも各4コマ。
- 共通画像描画・既存再生・火山の形状互換：11テスト合格。読込失敗後の再試行、共有ロード、時間境界、親の透明度、無効座標、色替えキャッシュ上限を含む。
- 戦士・魔法使い・パラディン・忍者・呪術師・巫女素材・女神・門2種・資料館の関連テスト：105テスト合格。
- 本編：通常10地域、次元の門、混沌の門、女神を実際に開始し、素材読み込みと描画を確認。ジェム7種、旧斬撃、召喚、出血・毒・砂縛りも状態を固定して表示確認。
- 女神：歴代ボス20種の星鏡、星弾・流星、零界の溜め・光柱、覚醒、発動後の直線・扇形・円環、狭幅・動きを減らす設定を確認。
- 両方の門：各3段階を並べ、待機・開く・召喚中・閉じる・初期亀裂・画像片の崩壊・敵出現・崩壊光輪を通常／動きを減らす設定で確認。32シーン。対象Canvasで線・矩形塗り・円形グラデーション等を禁止しても描画が通ることを確認。
- スキル検証画面：5職×21スキルを各3時点で描画し、実行エラーなし。資料館は素材切替・コマ送り・連続再生・速度・背景・狭幅を含む既存の閲覧検証に合格。

成功した確認は再利用し、検証用入力の不足を修正した後は該当する残りの確認だけを実行した。戦闘数値・育成・保存仕様はこの画像化では変更していないため、30配置のバランス再計算は対象外。

再現コマンド：

```powershell
npm run build:common-effects
npm run test:image-effects
node --test tests/warrior-skills.test.cjs tests/mage-skills.test.cjs tests/paladin-skills.test.cjs tests/ninja-skills.test.cjs tests/shaman-skills.test.cjs tests/miko-assets.test.cjs tests/goddess.test.cjs tests/museum.test.cjs tests/dimensional-rift.test.cjs tests/chaos-gate.test.cjs
npm run check:image-effects-ui
node tools/verify/verify-museum-ui.cjs --browsing-only
npm run check:structure
```

ブラウザ検証は `output/image-effects/` へ画像と結果JSONを保存する。`--labs-only` と `--gates-only` で接続部分だけを確認でき、`--remaining` は既に合格した素材再生・通常地域を省いて女神と検証画面を続ける。これは通常実行時の合格範囲を狭める設定ではない。今回の結果は [検収記録](../../development/assets/effects/common/review.json) に保存。
