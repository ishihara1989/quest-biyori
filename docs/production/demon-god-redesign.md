# 魔神：二腕・無面・浮遊の再制作

2026-10-14 JST。魔王城の全体修正に先立つ魔神の素材修正。左向きの筋肉質な二腕、顔のパーツがない硬質な頭、浮遊姿勢を採用する制作候補。頭は追加要望に合わせ、金の外枠・浮き彫りと上部／後部の冠状装飾を加えた。顔に相当する黒曜石の面には目・口・鼻・耳・覗き穴を設けない。

組み込み `image_gen`、透過背景で生成。最初の装飾なし基準絵、頭部装飾後の固定基準絵、8枚の4コマ原画、断界の追加修正候補を保存した。初回素材は上書きしない。各モーションは常に同じ装飾入り基準絵を参照し、直前のモーションを次の基準にはしない。全文の実送信指定は各原画の `.generation.json` と集約生成記録にある。

| モーション | コマ | 動き |
| --- | --- | --- |
| 待機 | 4 | 上下の浮遊。腕・膝は脱力、腰布が遅れて揺れる |
| 浮遊移動 | 4 | 左へ滑空する姿勢。脚・腰布が後ろへ流れ、歩行接地をしない |
| 拳撃 | 4 | 両拳を引く構えから一方の拳を左へ突き出し復帰 |
| 魔腕の断界 | 4 | 上段から下段への二打。もう一方の腕は胸前で構える |
| 三界魔柱 | 4 | 胸核へ集め、両掌を上げて開く |
| 封声 | 4 | 胸前の構えから掌を立て、左へ押し出す |
| 終焉の交差 | 4 | 胸前で腕を交差、左上／左下の二方向へ掌を開く |
| 被弾 | 2 | 浮遊を保った反動と復帰 |
| 撃破 | 2 | 浮力を失い、脚を折って低く崩れる。最後の姿勢を保持 |

計32コマ、各384×384の透過PNG、GIF、全コマ一覧、マニフェストを用意した。GIFは検収用に反復するが、検収画面の撃破は終端保持して再生を止める。

拳撃の最初の原画2コマ目は、引く腕と突き出す腕の連続性が弱かった。両拳を引く断界1コマ目を流用してつなぐ。断界を左右交互の腕にする追加生成は意図どおりにならず選択しない。現行は同じ腕で上段→下段の二打とし、二本の腕の接続を保持する。この選択と未採用候補も記録に残す。

## 既存エフェクトの再利用

新しいエフェクト画像は生成していない。原画・配色を変えず、配置・縮尺・回転・再生時刻で接続する。攻撃判定と危険行動の数値は今回変更しない。

| 用途 | 既存素材 | 接続 |
| --- | --- | --- |
| 拳撃・断界 | 初回候補 `demon-impact` | 対象へ小さく短く表示。断界は0.9秒差 |
| 三界魔柱 | 初回候補 `demon-pillar` | 単柱を3位置へ0.9秒差で表示 |
| 呪い | 本編の呪術師 `mark` | 対象の頭上に表示 |
| 封声 | 本編の忍者 `seal` | 対象の頭上に表示 |
| 交差二帯 | 本編 `ruins-furnace-beam` | 単独光線を±28°で回転、1秒差。青白い色を保持 |
| 最後の輪 | 本編の忍者 `final-ring` | 低い楕円として表示 |

初回 `demon-arm-arc` は各コマに2拳が同時に入るため使用しない。初回 `end-cross` は不要な分岐と切り出し問題、`silence-seal` と `end-ring` は中央の塗りや背景の課題があり、上記の本編素材を流用する。初回素材の課題記録を合格へ書き換えない。再利用候補の本編最終採用は、魔王城実装時の判定範囲・発動点・縮尺に合わせて確認する。

## 切り出しと検収

透明な分離線で矩形切り出しし、元のRGBAを保持する。腕の切り貼り、描き足し、背景除去はしない。同じ生成シート内は全コマ同じ縮尺とし、シート単位の縮尺だけを最初の全身高さで揃える。胸核の原画実測座標を基準に登録し、設計した骨盤の移動量を加える。設計座標と胸核の実測をマニフェスト／QAで別々に残す。

基準絵と反応原画の冠は上端の余白が小さいが、元画像の外周に不透明画素はない。切り出し後は透明余白を付け、冠・輪・手・腰布・足先の見切れがないことを全32コマで確認する。

本編未登録の制作候補として保存する。本編戦闘上の表示・実際の発動時刻との照合とバランス確認は、魔王城の組み込み時に行う。

全32コマの原画・出力PNGと固定基準絵を目視検収。通常／0.25倍でCanvasを連続再生し、各9時点のキャプチャで動く順序・復帰・4→1の浮遊ループを確認した。撃破は終端保持、断界は0.9秒差、魔柱は3位置へ0.9秒差、交差二帯は1秒差で合格。1440px／390pxの表示、コマ送り・再生・エフェクトと背景の切替、コンソールと読込エラー0件を確認した。[フレームSHA256に結びついた目視検収記録](../../development/assets/demon-god-redesign/v2/review-notes.json)とQAへ保存。

アプリ内ブラウザはローカル接続を拒否したため、リポジトリの検証ツールからheadless Chromeで確認した。`npm run check:structure` と既存の配置テスト4件も合格。今回の保存先は開発側であり、本編やバランス処理の変更・再計算はしていない。

## 再現コマンド

```powershell
node tools/assets/build-demon-god-redesign.cjs
node tools/verify/verify-demon-god-redesign.cjs
node --test tests/repository-structure.test.cjs
npm run check:structure
```

素材ビルドは原画を再生成しない。同一フレームのSHA256に対応する検収記録だけを再利用する。ブラウザ検証のキャプチャと時刻別の結果は `output/demon-god-redesign/` に保存する。
