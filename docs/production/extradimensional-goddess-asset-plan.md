## 参照の固定と素材の分離

基本形は第1フェーズの修正版、浮遊状態は第2フェーズ、背景は界外の御座を参照する。追加生成・修正でも必ず元の基準画像を添え、直前の修正版だけを参照しない。

第1フェーズの背面装飾を第2フェーズの天環へつなぐ。玉座の石が本体へ融合したり、環が羽・腕へ変わったりしないよう、分離した基準を先に作る。

## 生成順と単位

1. 本体・空の玉座・天環の分離基準、共通セルの位置合わせ。
2. 第1・第2フェーズの待機、9コマの移行、背景との合成確認。
3. 指パッチンと星鏡の出現・消失、女性型1体・大ボス1体の代表技との接続。
4. 全地域の代表技、追尾流星、危険技の構え・発動、中断・休息・撃破、環境素材。
5. 本編への登録と正式検収。

1回の画像生成は1〜4コマ。6コマは3+3、9コマは3+3+3で作る。境界直前の画像と基準画像を両方添え、次の区間の開始位置を指定する。分割しても指・衣装・形が崩れる場合は該当コマを1枚ずつ生成する。

## 歴代ボス幻影と星鏡の接続

呼び出す10地域・20体と代表技は [企画の候補表](../design/extradimensional-goddess-design.md#呼び出す大技の候補) を正本とする。女神本体とは別に、元ボスの基準画像・完成済みモーション・FX・発射点を確認する。未制作の技は、静止画の平行移動だけで完成扱いにしない。

- 星鏡の舞台基準 P=(632,464)。縁の作業セルは512×512、床基準 (256,448)、鏡中心 (256,252)。女性型用の開口は幅180・高さ300、大ボス用は幅300・高さ360から始める。サイズは独立した縁の描画で変え、本体の縦横比を歪めない。
- 指パッチンF3を t=0 とし、指先光0.00〜0.12秒、開口0.12〜0.45秒、幻影のクリップ表示0.25〜0.60秒へ接続する。姿を揃えてから代表技の短い構えへ進み、最初の判定を出す。
- 幻影は元の接地点をPへ合わせる。体・翼・武器を本来の配色で描き、金の細い縁を追加する。半透明化しすぎて顔やシルエットが消えないようにする。
- 各技の攻撃起点・向き・コマ・最後の発射／直接判定時刻を一覧化してから合成する。蔓・根・触手などの床起点は、幻影本体の掌起点と分ける。
- 最後の発射／直接判定時刻を消失開始とする。0.20〜0.25秒で本体をクリップ分解して消し、鏡片を中心へ回収する。弾・波・光柱の描画と被害は独立した親行動へ残す。幻影を消したことで発射済みの技まで消さない。
- 持続ビームは独立FXを最終発射時に配置して本体を回収する。突進・薙ぎの幻影は最後の直接判定まで動き、その直後に消す。技全体を1回の被害予算へまとめる。
- 低モーションでも「開く→姿が揃う→放つ→消える」は残す。回収粒子の移動・背景の脈動・大きな揺れを減らす。

新しく四足の歩行を作る場合は [四足trotの制作基準](../policies/quadruped-trot-production.md) を適用する。今回の幻影は代表技に必要な構え・発動だけを用い、呼び出しのための歩行を追加しない。

各FXの作業セルは、星・着弾が256×256、開口・波・移行が512×512、広い切断光・柱は必要な縦横比のセルを別設計する。初稿を作る前に、FXごとの中心点・発生方向・最大外形・余白を確定する。

発生順の幾何目標は [fx-plan.json](../../development/assets/extradimensional-goddess/v1/fx-plan.json) に保存。数値はセル内の制作目標。帯・波は画像の光が予告判定を大幅に越えないよう、描画側のサイズと合わせる。追尾流星の芯は対象位置へ、尾は直前の軌道へ接続し、固定円の落滴FXとして再生しない。

### 生成前に確定する接続

- 星弾：掌を原点に、左向きへ進む。発射時の手の座標を毎フレーム移動に合わせる。
- 星鏡：指先光→開口→幻影→代表技→即回収。幻影と既存技FXの原点・最後の発射時刻を合わせる。
- 追尾流星：対象3人を重複なしで選択→頭上星印→上空3星→0.15秒差の発射→対象の現在位置へ追尾→各1 Hit。星印・弾・防護予測を同じ対象IDで管理し、死亡対象の星は別人へ飛ばさず消す。
- 裂け目：発生点→線→口→切断を別段階にし、本体の腕が動く前に発動光を出さない。
- 波：中心固定で内輪→中輪→外輪。段階間の1秒を粒子だけで埋め、追加の被害を挟まない。
- 零界：掌の中点から球が上昇。柱は別の固定地点へ落とす。球と柱を同じ発射体として誤接続しない。
- 決着：満足げな微笑み→会釈→手振り→本体が帰還→扉が閉じる→報酬光。天環の破砕や脱力して倒れる動作は使わない。報酬抽選と表示を複数コマで重複させない。[帰還の時刻と制作目標](../../development/assets/extradimensional-goddess/repair-v2/return-plan.json)を参照する。

## 検収と終了条件

今回の静止基準は、姿勢・顔・衣装・全体の収まり・透過を確認する。本編用の縮小表示、分離後のレイヤー接続、全コマと連続再生は後続制作時に行う。静止画を反復表示してモーション検収済みとは扱わない。

後続の各素材では、全コマを並べて次を確認する。

- 体格、顔、衣装、色調、光輪の形が元の基準と一致する。
- 手指と両脚の接続、頬杖の接点、脚をほどく順序、立つ前の接地、浮遊開始の順序。
- 透過、半透明縁の色、髪・袖・靴・環の見切れ、原点と床基準。
- 3→4、6→7の分割境界、待機4→1、移行9→浮遊待機1、攻撃→休息→待機。
- 指パッチンの指の接続、光→星鏡→幻影の順序、全20体の代表技の発射点、最後の発射直後の消失と残る弾。女性型と大ボスで鏡の大きさを変えても輪郭・接地点がずれない。
- 追尾流星の3対象の星印・尾・着弾が一致し、動いた後衛にも接続する。死亡・退場時の消去、生存3人未満の本数、発射途中のフェーズ終了も確認する。
- 連続再生で、呼吸・浮遊・髪の遅れが逆転せず、背景の足場からずれない。
- 本編の通常幅・狭い幅で予告と本体が見え、発射・着弾・命中判定が一致する。
- 第2フェーズの危険技は中断で未発動FXが消える。第1フェーズの呼び出しと通常の追尾流星に妨害バーを出さない。フェーズ移行・撃破・戦闘終了で幻影・対象印・一時状態が残らない。

必要な確認が合格し、新しい修正・失敗・懸念がなければ終了する。同じ素材検収や戦闘計算を報告書作成のために繰り返さない。元の静止候補と生成プロンプトは開発側へ残し、採用済み素材だけを本編側へ登録する。
