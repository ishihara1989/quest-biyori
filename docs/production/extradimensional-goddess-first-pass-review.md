## 一回目の検収結果

返された全111セルと元の基準画像を目視し、26アニメーションクリップをブラウザーのCanvasで通常速度再生した。うち25クリップは0.25倍でも確認。分離9点と中断入口1点は静止検収で、アニメーション合格とは扱っていない。欠落2モーションは取得区間だけを確認した。市松・暗色・明色背景を使用し、ブラウザーのエラーログは空だった。

主な課題は次のとおり。全36素材グループの具体的なコマと優先度は[課題一覧](../../development/assets/extradimensional-goddess/first-pass-v1/ISSUES.md)を参照する。

- p1-shot F3に発射腕が追加され、3本腕に見える。指パッチンは中指が掌へ落ちる動きが弱い。
- 移行F6→F7で浮遊から再び座位へ戻る。第2フェーズ攻撃でも座位寄りの脚が混入し、掌・体格・髪の分割接続が跳ぶ。
- p2-meteor F6が待機へ戻らず、ultimate F9は頬杖になる。中断は掌を落とす順序と休息姿勢が目標と異なる。
- down F4に複数の本体残像が残る。玉座に大環、天環に小冠が混入してレイヤーが重複する。
- **18ジョブにセル境界の可視画素**があり、等分切り出しでは見切れと隣セルの混入が生じる。これは原画全体の外周見切れとは別の問題で、原画外周の可視画素検査は0だった。
- 星弾の芯の原点が跳ぶ。星鏡・裂け口の形、波の半径変化、覚醒の床輪の明度、撃破FXの3→4と最終消散に調整が必要。
- 零界収束には透過があり、明色背景で不透明な黒い矩形は認めなかった。主な問題は広い半透明光とセル越境による隣段混入・柱上端の見切れ。背景除去や補正はしていない。
