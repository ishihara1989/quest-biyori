## 帰還への方針変更

ユーザー指定により、ダウンは力尽きて倒れる動作から、十分に楽しんだ女神が満足して異次元へ帰る演出へ変更した。微笑む→軽い会釈→別れの手振り→上昇する4コマ。姿勢を起こしたまま、同時に表示する本体は1体にする。

帰還口は別レイヤーで6コマ。天環のひび・崩壊と死亡爆発は使わない。本体を1000〜1450msで薄くして消し、1450ms以降に扉を狭め、1650〜1800msで最後の光も消す。1800〜2200msだけ報酬の仮光を1点表示し、2200ms以降は背景だけになる。仮光は所持品・報酬抽選に接続していない。

スプライトのID `down` は互換の名称として保持する。HP0による勝利・1回の撃破報酬というゲーム上の扱いを、この演出変更で変更しない。本編取り込み時は、第1フェーズ中のHP0でも開始姿が跳ばないこと、未発動攻撃・幻影・印・一時FXの清掃も確認する。[制作目標と時刻](../../development/assets/extradimensional-goddess/repair-v2/return-plan.json)を正本とする。

## 生成できなかった区間の再検証

内蔵 image_gen を使用し、通常構えF4〜F6と大技F4〜F6の計6コマを取得した。今回の15回の生成では出力拒否なし。原画取得とモーション合格は分けて記録する。

浮遊姿の固定基準と分離本体を参照し、座位の基準は第2フェーズへ添えなかった。衣装は不透明に保ち、裾の裏地で脚を覆う指定を追加。腕を上げる通常の術式姿として、動作とレイヤー分離を明記した。取得画像で衣装がすべて指定どおり変わったという判定はしていない。

頭上区間を前半・後半の参照にも加えた試行は、頭上姿がF3/F9へ混ざった。元の浮遊基準へ戻し、「胸前まで」「腕を下ろす」の短い順序へ絞って再生成。大技は胸前→顔前→頭上→左右解放→低い開掌の順になり、頬杖への誤復帰を解消した。

通常構え後半は3試行を保存。r2にはセル越境があり、採用していない。r3は人物が内側に収まったが画角が小さく、遠い余白に細い境界線が混入した。全3コマ共通の中央532×532窓（各724×724セルの96,96起点）を使い、人物を切らずに同じ画角へ戻した。個別の外接矩形合わせや体格の拡縮は行っていない。固定窓と元矩形はマニフェストに保存し、切り出しのRGB／アルファを原画と照合した。境界を跨いだr2を切り出し位置で合格扱いにしたものではない。

帰還口の原画ではF3→F4で中心が約66px右へずれた。アルファ>32の外接矩形中心を実測し、対応する輪を目視したうえで、FXだけ表示原点を固定。コマPNGとGIFには元の位置を残し、比較画面と背景合成で補正する。目標座標を実測済みとして扱っていない。

## 検収と検証

- 選択した全31コマと、破棄した試行も含めて返された15原画43セルを目視した。手足・顔・衣装・色調・透過・見切れ・分割境界を確認。静止2点と5アニメーションを区別する。
- 5アニメーションをブラウザーのCanvasで1倍・0.25倍再生し、全コマへ到達することを確認。市松・暗色・明色、1440px／390px幅、通常の操作と次のコマを確認。画面のエラー・読込失敗なし。
- 帰還の背景合成を0／450／850／1200／1450／1650／1800／2000／2300msで確認。1450msで本体、1800msで扉が消え、2300msのCanvasが背景画像のRGB／アルファと完全一致することを確認。原点修正後も同じ終了条件を再確認した。
- `node tools/assets/goddess-repair.cjs check`：11ジョブ・15原画のハッシュ、参照のハッシュ、選択31コマの矩形切り出しRGB／アルファ、欠落なし・切り出し境界の可視画素0を確認。これは素材全体の採用合格ではない。
- `node tools/verify/verify-goddess-repair.cjs`：7素材31コマ、静止2点＋5アニメーションの通常／低速計12再生確認、完全消失、表示幅、エラーなし。
- 一次検収の整合性確認と `npm run check:structure` を実行し、元の初稿・固定基準の保全と配置・リンクを確認。

ブラウザーの検収資料と機械確認は `output/goddess-repair/`。正式な検収メモと原画は `development/assets/extradimensional-goddess/repair-v2/` に保持する。共通戦闘処理・保存・バランス・本編登録は変更していないため、戦闘計算や全ゲームテストは対象にしていない。
