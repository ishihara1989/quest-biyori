# 氷河モーションの制作・検収

2026-10-13。本編採用は7種48モーション・174フレームと、11エフェクト44フレーム。基準絵、原画、全文プロンプト、SHA-256、不採用画像を `development/assets/glacier-motions/` に保持する。

四足3種は3+3コマで始めたが、両奥脚が同時に浮く出力や分割線への見切れを不採用にした。骨格の計算目標に加え、基準絵上で足を画像内の位置として識別するガイドを作り、1枚ずつ生成した18コマを採用。A=左後LH+右前RF、B=左前LF+右後RH。1・2・6でA、3・4・5でBが遊脚。各120ms、6コマ720ms。マンモスの3・4は原画の尾が外縁へ触れたため、同じ足運びを保持してV3へ修正した。

[原生成](../../development/assets/glacier-motions/PROMPTS.md)、[余白修正](../../development/assets/glacier-motions/REVISION-PROMPTS.md)、[単コマの指定と採用原画](../../development/assets/glacier-motions/SINGLE-TROT-PROMPTS.md) を参照。梱包は切り出し、最近傍による等比縮小、胴体の位置合わせのみ。

| 項目 | 検収結果 |
| --- | --- |
| 脚の接続・所属 | 四脚の付け根から毛の重なり、膝、足首、足先を追跡。別脚への接続、第五の足、独立した足首なし。奥後脚を横へ広げていない |
| 足運び・接地 | A/Bの交代を拡大コマで確認。3→4と6→1で脚の所属を維持。単コマ全体の大きさを揃え、胴体上端を登録 |
| キャラクター・色調 | 固定基準絵と顔、体格、紺白蒼の色、狼の尾・鬣、フェンリルの紋様、マンモスの鼻・二本牙・背の氷を比較 |
| 透過・見切れ | 実行用素材が参照する採用原画69枚で、四辺の不透明画素0。透過中心を含むエフェクトと実行用フレームの余白も検査 |
| 共通・個別の動作 | 待機・移動・被弾・撃破の188コマ表示を左右両方向で照合。撃破は終端保持。専用20行動の本体とエフェクトを確認 |
| 再生・実画面 | ブラウザで¼×と1×の各ループに全6コマが現れることを検証。背景上の表示、危険予告、発動、解除、スマホ幅390pxも確認 |

計算目標は `guides/<enemy>/coordinates.json`、切り出しと登録の実測は [registration-measurements.json](../../development/assets/glacier-motions/review/registration-measurements.json)。[足先の近似実測](../../development/assets/glacier-motions/review/paw-measurements.json) は最終フレームのピクセル座標で、目視誤差は狼±6px、他2種±8px。1024座標の制作目標とは別の座標系であり、数値の厳密一致は合格理由にしていない。毛に隠れた関節は、前後の見える接続で確認し、座標そのものは実測していない。
