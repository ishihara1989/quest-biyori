## 制作条件

組み込み `image_gen`、透過背景指定で生成。各ジョブ1回のみ。既存の火山 `monsters-v3.png` と魔王城 `monsters-v2.png` を固定基準とし、参照PNGとSHA256を保存した。既存の背景・配置物・ドロップのデザインは `mid-late-design/v1` にあるため今回の重複生成はしない。

四足4体には [trotの標準](../policies/quadruped-trot-production.md)に沿った関節・足先・接地の計算ガイドを用意した。計算座標と生成出力の足先実測は別物。ガイド遵守や全脚の自然さを技術検査から推定しない。魔神は6腕を個別に接続・保持する指定とし、戦闘用の左向きとの両立を検収対象にする。

原画の再塗装、脚の切り貼り、背景除去、再生成は行わない。切り出しと同一縮尺の最近傍縮小のみでプレビューを作る。原画の背景混入や自動切り出し失敗も原画を保持して課題に記録する。本編の素材登録・AI・描画・バランスには接続しない。

## 初回結果と確認範囲

121/121シートの全コマを原画で目視し、素材ごとの指摘を `review-notes.json` と `ISSUES.md` に残した。武器・翼・尾の見切れ、コマ間の体格・色調の変化、背景光の混入、手足の増加や所属の変化、飛行弾が爆発へ変化するなど用途と合わない動きが修正対象。共通のエフェクト指定が発生・最大・収束を重視しすぎた点も課題として残している。

透明な隙間で矩形切り出しできる原画から104件のアニメーションプレビューを作成した。21シートは安全な自動切り出しができず、原画シート表示へ切り替えた。粒子・半透明画素を消す連結成分マスク方式は採用していない。黒騎士の移動プレビューは後半3コマのみで、前半は原画を参照する。現行の一覧は `review-index.json`。以前の派生プレビューが一覧から外れた場合は `superseded: true` として残す。

機械検査では原画3シートの四辺に不透明画素を検出した。内部セル境界の見切れや背景混入は目視の指摘も参照する。原画・基準絵のSHA256、ジョブと生成記録・全文プロンプト・個別記録の対応、プレビューと原画リンクの検査は合格。検収画面のJavaScript構文検査とリポジトリ配置テストも合格した。

連続再生の目視確認は未実施。利用できるブラウザでローカル検収ページへの接続が制限され、通常速度・低速・ループの動作確認を完了できなかった。GIFとコマ送り・再生の検収ページを用意し、全素材の未確認事項として残した。四足の足先実測、全関節の接続、実際の再生での3→4・6→1、本編表示・発動時刻との対応は採用前に確認する。今回の素材は検収合格・本編採用済みではない。

本編コードを変更していないため戦闘・保存・バランスの再計算は実施していない。最終の `npm run check:structure` は合格し、文書・モジュール・ページのリンクも確認した。配置に関する既存テスト4件の合格結果は、対象処理の変更がないため再利用した。
