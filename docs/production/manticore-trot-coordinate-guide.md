# 座標ガイドによるマンティコアtrot改良

2026-10-13。trotへ移行する方針はユーザー確認済み。旧版は `backups/manticore-trot-v1-20261013/` に原画・登録画像・再生素材・設定・プロンプトを保存し、23ファイルのSHA256一致を確認した。

## 座標系と投影

前方（左向き）をUの正、手前（左脚側）をVの正、上をZの正とする。正射影のヨー20°、見下ろし13°を使う。

```text
x = 620 - cos(20°) U + sin(20°) V
y = 1020 + sin(13°) [sin(20°) U + cos(20°) V] - cos(13°) Z
```

3Dモデルから実測したカメラではなく、基準絵へ合わせた制作ガイド用の投影。脚ごとの振幅・持ち上げ量を操作できる。接地点マーカーは足先の最下点で、足全体の中心ではない。奥脚は先に描き、手前脚に隠れる場合は隠してよい。

## 軌道

位相qをAペアは `(t+0.25)%1`、Bペアは `(t+0.75)%1` とし、前後変位は `-振幅 × cos(2πq)`。q<0.5を遊脚とし、その高さは `持ち上げ量 × sin(2πq)`、支持中は0。固定付け根から足首まで2節の逆運動学で関節位置も求める。足裏から足首までは48。

| 脚 | 前後振幅（±） | 持ち上げ最大 |
| --- | ---: | ---: |
| 左前脚 | 70 | 76 |
| 右前脚 | 64 | 64 |
| 左後脚 | 64 | 70 |
| 右後脚 | 44 | 60 |

## 比較と再生成

`http://127.0.0.1:4191/manticore-trot-guide.html` で旧版・改良試作・連続計算ガイドを同時に再生する。4脚の前後振幅と高さを別々に変えられ、設定と6コマ分の座標をJSON保存できる。スライダーは計算ガイドを変えるもので、生成済みPNGを変形するものではない。
「座標・生成記録」の足先計測を有効にし、脚を選んでV2の足先の最下点をクリックすると、原画座標と目標との差を記録できる。計測値もJSON保存に含まれる。

```powershell
node tools/assets/build-manticore-trot-guide.cjs --config <保存したJSON> --out trot-v3
```

これにより設定を読み込み、別フォルダへ6枚のPNG・SVGガイド、連続GIF、全座標、`GUIDE.md`を書き出せる。画像生成は組み込みImagegenで別途行い、同じ固定基準画像と各コマのガイドを参照する。

## 今回の生成結果と限界

初回は固定基準・骨格ガイド・座標文章で6枚を生成した。足先の位置には無視できない差があり、初回の概算計測を `trot-v2/initial-measurements.json` に保存した。これは手動で選んだ足領域の中央と爪下端による概算で、約15〜25pxの計測誤差を含む。自動の解剖学的検出ではない。
生成画像に足先の目標を重ねたガイドでも修正を試したが、複数脚を一度に動かすと接地ペアや脚数が崩れる例があり、不採用にした。
1〜2本に絞った後脚の修正では②の右後脚を手前の後脚に隠す方向へ改善したため、比較試作の①②に採用。③〜⑥は初回ガイド版を使う。前脚だけの修正も試したが、完全な6コマの軌道には安定して揃わず、比較版には採用していない。

このV2は計算座標に完全一致した完成版ではない。計算側では右後脚①→②が約36px、左前脚③→④→⑤は約57pxずつに制御されるが、生成PNGの移動量が同じ数値とは限らない。奥脚が隠れた場合、見える爪だけから足全体の中心を正確に実測することもできない。
高原の既存確認ページはV1を保持し、V2は比較用に分離した。移行方針としてのtrotは採用し、画像生成による座標精度は継続して評価する。

原画、採用・不採用の理由、全文指定は `trot-v2/generation.json` と `trot-v2/PROMPTS.md`。
技術検証は4本の脚の接地順、ループ連続性、関節長の保持、脚ごとの独立調整、23ファイルのバックアップハッシュ、6コマのPNG/GIF、比較画面・計測・JSON保存・390px幅まで通過した。これは生成画像の足先座標一致や全コマの自然さを保証する検証ではない。
