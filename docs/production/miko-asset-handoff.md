## 素材の入口

- `public/assets/skills/miko/catalog.json`：全モーションのmanifestへのパスと15種の一覧。
- `public/assets/skills/miko/skill-assets.json`：20技の本体動作・発動時刻・召喚・大型演出・アイコンの対応。
- `public/assets/skills/miko/summons/`：独立型11種。待機・行動、地上5種の歩行6コマ、火車の炎輪移動4コマ、金獅子の爪撃3コマ。
- `public/assets/skills/miko/possessions/`：疾狼・剣鬼・守熊・命蛇。顕現3コマ・待機4コマ・行動3コマ・解除3コマ。
- `public/assets/skills/miko/guardians/`：独立型11種の大型顕現3コマ・維持4コマ・分霊3コマ。
- `public/assets/skills/miko/effects/`：鳥居の顕現・維持・解除、社、霊衣、神紋、攻撃・回復・保護、終撃など23種。
- `public/assets/skills/miko/icons/`：生成素材から切り出した20技の透過アイコン。
- `public/assets/miko/motions/{summon-forward,spirit-send,blessing-up,kagura-finish}/`：既存の祈り・一回転につなぐ本体追加4動作。

各モーションは連番PNG、横並びPNGシート、`manifest.json`、暗色背景の`review.png`、連続確認用`preview.gif`を持つ。元のImageGen出力は`source/`、使用プロンプトと参照画像は`generation/`と各`PROMPT.md`に保存する。歩行の合成シートは別生成の前後3コマを結合した6コマで、元の前半・後半も残す。

110組の生成原画から359コマを整理し、歩行の合成シート5組を含む115モーション・389コマを収録。合成歩行の30コマは元の前半・後半と同じ画像で、別ポーズの数には含めない。金獅子の爪撃と岩亀・鈴梟・金獅子の維持は、隣のコマの尾や翼が横方向だけ重なるため、透明な隙間に沿って個体と付属粒子を分離してから切り出した。色の変更、補間、新しい絵の描き足しは行っていない。個別生成を試した追加の岩亀2枚・鈴梟1枚は、生成枠の上限でその列を完成できなかったため参照原画として保存した。

終撃のピークは上へ続く光柱。`edgeBehavior`に記録したとおり、光柱の上端を戦闘画面の上端より外へ配置して使う。閉じた円形の単独エフェクトとして配置する場合は、同梱の霊撃神紋を使う。ほかの素材は尾・翼・御幣などの主要形状を透過セル内へ収めた。

## 描画と発動

最近傍で描画し、`pivot`を召喚獣の接地・飛行中心・憑依対象の接地へ合わせる。独立個体は128×128、大型守護霊・憑依・演出は512×512、本体新動作は既存と同じ320×256・接地(160,239)。全フレームの`bounds`と`durationMs`をmanifestに記録する。同じ霊の動作は共通倍率で整える。

Hはキャラクター本体の頭頂から接地まで。透明セル全体をHの計算へ含めず、描かれた外形を基準にする。通常の顕現は3H前後、鹿・獅子は4H、九尾は5H。憑依は成立時3.2H、維持中2.5Hを基準にする。神楽は画面幅の鳥居と全員の全身霊衣を合わせる。

地面の神紋→守護霊／憑依霊／全身霊衣→本人と敵→接触点の効果→HPとUIの順。神楽の霊衣は6人が密集すると隣の顔まで覆うため、プレビューでは本人たちより先に描画する。外形の大きさを維持したまま、顔、武器先、接地点を前へ見せる。前面へ翼や尾を回す場合は外縁だけを別レイヤーにする。大きな装飾の外縁を判定範囲として使わない。

| 型 | 既存動作と追加動作 | 発動 | 全体 |
| --- | --- | ---: | ---: |
| M1 | 祈り720ms→招来300ms→復帰100ms | 820ms | 1120ms |
| M2 | 祈り720ms→送霊330ms→復帰110ms | 830ms | 1160ms |
| M3 | 祈り720ms→回復召喚330ms→復帰110ms | 830ms | 1160ms |
| M4 | 祈り720ms→一回転800ms→締め300ms→復帰180ms | 1260ms | 2000ms |
| Lv100 | 祈り1440ms→一回転800ms→締め300ms→復帰180ms | 1980ms | 2720ms |

本体の速度変更で発動イベントへ到達する時刻だけを変え、召喚の寿命・支援の持続・神楽の協撃待ち時間をモーション時間から再計算しない。顕現・分霊・霊衣・終撃は演出素材であり、追加の契約・攻撃・回復には数えない。仕様と数値は [スキル設計](../design/miko-skill-design.md) を参照。

## 再構築

`npm run build:miko-assets` は保存済みの生成原画を分割し、位置合わせと最近傍リサイズをしてパッケージを再構築する。画像生成APIは呼ばない。`npm run test:miko-assets` で欠落、透過、見切れ、PNGシートと連番の一致、歩行の結合、時間、20技のリンクを検証する。`npm run check:miko-assets-ui` で専用画面の再生・コマ送り・合成表示を確認する。
