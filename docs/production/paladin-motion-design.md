# パラディンの追加モーション

基準は `public/assets/paladin/idle-01.png` と元デザイン。右向き、金髪、白銀と金の鎧、濃紺の布、左腕の白金の盾、右手の短い棘付きメイスを維持する。
生成は透過PNG。各3コマ、前進だけ前半／後半を別々に3コマずつ生成する。左右とは歩行の左右の脚を交互に踏み出す半周期で、向きの反転ではない。

## 座標設計

生成セルの正規化座標（左上0,0／右下1,1）。基準接地(.50,.90)、頭頂(.50,.34)、盾は正面右側、メイスは右手から伸びる。足は生成後に同一の接地ピボットへ登録する。上半身の縮尺は武器の挙上で変えない。

前進は盾を正面に固定し、上体を少し前傾。ワールド座標の移動はシミュレーションが担当する。スプライト内でキャラクター全体を水平移動させない。
攻撃判定は横打ち2コマ目、叩きつけ3コマ目、盾挙上／突き立て3コマ目に同期する。
コマ送り、挙上→叩きつけ、前進3→4／6→1、色調、RGBA、見切れを確認する。
