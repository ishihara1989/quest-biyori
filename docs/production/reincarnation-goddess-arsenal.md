# 転生の女神：SF兵器・トラック・帰還ゲート制作

2026-10-20追記：24素材77コマを本編登録。原画は変更せず、再生メタデータを本編形式へ正規化。[本編の実装・検証](../implementation/reincarnation-system.md)を参照。以下は制作時の記録。

2026-10-20 JST。**本編未登録の制作候補。** 通常のSF兵器5種と、別枠の大型トラック大技を制作する。

[設計・範囲・想定効果](../design/reincarnation-goddess-arsenal.md) / [素材・再構築](../../development/assets/reincarnation-goddess/arsenal-v1/README.md) / [検収画面](../../development/labs/reincarnation-goddess-arsenal.html)

内蔵 image_gen を使用する。既存の左向き基準を固定参照とし、女神5動作15コマ、トラックの乗車・企み待機・突進・涙目中断12コマ、専用FX11種33コマ、計60コマを3コマずつ生成する。生成前の順序・位置・表情・目標座標は jobs.json と全文プロンプトへ記録。原画と参照のハッシュ、返却元、実測切り出しと配置、全コマの検査は素材領域に保存する。

帰還本体は基本版の6コマをコピーして再利用し、ゲートの開口・閉口各3コマを別レイヤーにする。旧版の原画と検収画面を保持する。新素材は development/assets/ に置き、ゲームからの参照は追加しない。

画像の加工は原画の切り出し、均等な最近傍縮小、平行移動、シート化と検収用GIFに限る。キャラクターやエフェクトをコードで描き足さない。コマ間の拡大縮小や色の補正で形の問題を隠さない。スプライト同士が重なる場合は再生成し、等分線が通るだけの場合は透明な隙間を実測して切り出す。輪郭を削って収めない。

再構築コマンドは素材READMEに記載。検収結果と制約は review/qa.json と REVIEW.md を正本とする。本編のダメージ・妨害・転生処理は対象外のため戦闘バランスを実測したとは扱わない。
