# 転生の女神：基本モーション制作と検収

2026-10-20 JST。**敵キャラ用素材の制作候補。本編未登録。** 金髪・可愛い顔・生意気な表情・偉そうな姿勢という確認済みデザインを基準とする。既存の異次元の女神とは別素材。

[素材と再構築手順](../../development/assets/reincarnation-goddess/basic-v1/README.md) / [検収画面](../../development/labs/reincarnation-goddess.html)

## 制作範囲

待機4コマ、浮遊移動4コマ、被弾3コマ、帰還6コマ、計17コマ。左向きを基本とし、帰還だけ左向きから正面・右向き・側面・背面へ回す。攻撃・スキル・戦闘データの追加は含めない。

内蔵 image_gen を使用。イラスト案からドット絵の左向き基準を作り、雪女の既存スプライトを輪郭・ドットの密度の参照とした。生成単位は4・4・3・3+3コマ。帰還後半には前半と固定基準を両方添えた。全入力・修正前出力の理由・原画のハッシュは素材領域の generation.json と PROMPTS.md に保存。

腰に手を当てた全身参照を被弾に使用すると余分な腰の手が残ったため、その出力は不採用。同じ固定原画から顔と衣装を切り出した部分参照へ切り替え、両手を頬に当てる3コマを生成し直した。帰還は腕組みで怒る姿を作り、初稿の閉じたスカートを固定原画と同じドレープへ修正した。

## 登録と検収

共通512×512セル。原画の透明な隙間と腰の位置を測定し、部位基準で揃える。髪が長いためアルファ領域の中心で体を揃えない。区間内は一様な最近傍倍率、帰還後半は前半の倍率を継承。原画のRGBAを保つ。色・アルファの再生成や手描き補完は行わない。

node tools/assets/build-reincarnation-goddess.cjs で、空画像、原画・出力の不透明画素の端接触、透過率、12px以上の安全余白、全GIFのフレーム数と時間を確認。新しい本編登録・共通処理変更はないため、戦闘バランス監査や既存全地域のテストは対象外。

全コマ比較と通常／低速再生で、顔・手足・衣装・色・透過・見切れ、待機と移動の4→1、帰還の3→4と5→6、待機→移動→被弾→帰還を検収する。結果は素材領域の review/qa.json に記録する。

本編への敵データ登録と本編表示は、この素材候補を採用して接続するときに行う。現時点は専用画面での素材検収まで。
