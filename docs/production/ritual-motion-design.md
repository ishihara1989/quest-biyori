# 忍者・呪術師・巫女の追加モーション

基準は各職の `public/assets/<職>/idle-01.png` と `public/assets/references/<職>-original.png`。透過PNG、既存のドット絵の配色・頭身・装備を維持する。生成単位は3コマ、巫女の祈りだけ4コマ。6コマの回転は前半・後半を別々に生成する。

## コマの設計

座標は生成セル内の正規化座標。接地はおおむね (.50,.91)、基準は右向き。武器を上げても体の大きさは変えない。追加素材は320×256pxの枠、接地ピボット (160,239) に合わせる。待機との接続はワールド接地座標を共有する。透明な余白を調整して装備と髪を切り落とさない。

|職・動作|コマ順・武器／手の位置|再生|
|---|---|---|
|忍者・印|胸元 (.60,.48) → 顎下 (.59,.40) → 胸元 (.60,.46)、両手で印|3コマ、720msループ|
|忍者・手裏剣|肩後ろ (.35,.40) → 手を伸ばして放す (.79,.44) → 空の手を下げる (.74,.54)|3コマ、520ms、180msで投擲|
|呪術師・通常攻撃|杖の頭 (.28,.26) → (.78,.42) → (.83,.57)|3コマ、540ms|
|呪術師・詠唱|閉眼、杖を立てる。胸前の空いた手と髪が呼吸に合わせて上下|3コマ、720msループ|
|呪術師・詠唱終了|立てた杖 (.71,.22) → 斜め前 (.78,.34) → 左手で杖を持って前へ伸ばし、右手は開いて後ろへ。首元に骨の首飾り|3コマ、540ms、詠唱から接続|
|巫女・通常攻撃|棒の頭 (.29,.30) → (.79,.43) → (.82,.62)|3コマ、540ms|
|巫女・祈り|閉眼。棒を上げ、左 (.32,.12) → 中央上 (.50,.08) → 右 (.77,.12) → 中央戻り (.50,.13)|4コマ、720msループ|
|巫女・祈り終了 A|棒を掲げて右向き → 背面右 → 背面左|各3コマを別生成、Bに接続|
|巫女・祈り終了 B|左向き → 正面 → 右向きで棒を前へ (.84,.36)|計6コマ、800ms、一回転して待機へ|

回転は垂直軸まわりの体の向きで表す。スプライト全体をキャンバス上で回す演出は使わない。回転終了を逆再生せず、最終姿勢を保って待機に戻す。

## 接続と確認

`ritual-lab.html` で待機→通常攻撃→待機、詠唱／祈り2周期→終了動作→待機を再生する。印・詠唱・祈りの単独ループも確認できる。手裏剣の飛翔は投擲コマ終了から同じ生成素材の切り出しPNGでつなぐ。両向き、コマ送り、時間指定、低速再生を用意する。

`index.html` の各職にも8種類の個別モーションを登録する。PNG・GIF・manifest・生成元・プロンプトを各モーションディレクトリに保存する。現在の冒険パーティは戦士・魔法使い・パラディンであり、この追加は3職のモーション素材とプレビューを対象とする。

ビルドは画像のセル切り出し、足位置合わせ、最近傍縮小、透過PNGのシート化のみ。回転後半は生成時の体の大きさに合わせて一律90%に登録し、全体を同じ縮尺で書き出す。体の形やポーズをコードで描き直さない。元のRGBAを保持し、各フレームの輪郭・色調・武器の余白、回転の前半／後半、祈りの最後→最初を目視とアセット検査で確認する。

呪術師の詠唱終了3コマ目は、左手で杖を前へ出す修正素材を同じ接地位置・体の高さに登録する。杖は下端から握りを経て頭部まで一本の軸でつなぎ、首元の骨・牙の首飾りを見せる。元の生成シートを保持し、1・2コマ目は変更せず、3コマ目だけを差し替える。修正の生成元・登録座標・プロンプトは `development/records/ritual-generation.json` の `frameEdits` とモーションの `PROMPT.md` に残す。
