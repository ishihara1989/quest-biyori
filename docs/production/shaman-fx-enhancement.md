# 呪術師の全身詠唱・DoT・後半演出の拡張

2026-10-10 JST。全体のエフェクトが小さく、混戦でDoTが見えにくいという要望を反映。本編と呪法検証ページで同じ描画を使用する。

## 表現

- Lv5から、足元の呪紋と2体の怨霊が全身の両側を上がる。詠唱の最大描画は幅320・高さ350を基準にし、序盤から頭上に髑髏と尾を見せる。キャラクターはその前に描く。
- 呪印・深呪は大きな足元の輪と、敵の頭上へ立ち上る霊影で持続を示す。怨火は炎、怨念蓄積は段階で膨らむ髑髏、命蝕は蔦と追加の霊影で区別する。
- 手前に出る継続脈動は薄くし、呪印のパルスは足元へ配置する。体・武器・攻撃予告を読み取れるよう、大きな霊影の本体は背後へ置く。印の刻み、状態アイコン、付与・追撃の着弾も拡大。
- Lv35・70・95で詠唱の高さと幅を増やし、後半は百鬼の輪と追加霊影を重ねる。呪杭は高さ210、陣の骨色・青緑の輪は明るくする。
- 百鬼蝕魂は周回する髑髏9体、内向きの呪弾18体、7本の終撃光柱、破砕と粒子で強調。中心の光柱は高さ465。強い中心光は短く、霊影・光柱・破砕の余韻を残す。
- 描画領域の端では詠唱の横幅を抑える。大量の敵には装飾霊影の描画予算を設け、状態表示と戦闘判定を維持する。動きを減らす設定では装飾粒子・周回移動を省く。

## 追加生成素材

内蔵 `image_gen` を使用。既存の百鬼素材を色調・画風の基準にし、足元とコマごとの顔・尾の位置を指定して生成した。DoT素材は単独の髑髏に修正し、各セルの横位置を揃え、共通倍率と接地位置で切り出した。

| 素材 | コマ | 保存先 |
| --- | ---: | --- |
| 全身詠唱の怨霊 | 4 | [`cast-wraith/`](../../public/assets/skills/shaman/effects/cast-wraith) |
| DoTの立ち上る霊影 | 3 | [`dot-wraith/`](../../public/assets/skills/shaman/effects/dot-wraith) |

各フォルダには透過PNGシート、個別コマ、`manifest.json`、`PROMPT.md`、`source/` の生成原本を保持。最終プロンプト・基準画像・切り出し指定は [`development/records/shaman-fx-upgrade-generation.json`](../../development/records/shaman-fx-upgrade-generation.json)。`node tools/assets/build-shaman-assets.cjs --effects` で既存25種と追加2種を再構築する。合計27種・89コマ。

## 確認

- 呪術師の15テストと全21技のブラウザ確認が成功。
- 前半の詠唱はキャラクターの全身を超える表示範囲、DoTは敵の頭上まで見えることを、エフェクトON/OFFの画像差分と目視で確認。
- 密集5体・36体の地上/飛行混在・部位付き標的、左右反転、攻撃速度10倍、連続再生、状態のキーボードフォーカスを確認。
- 本編の海岸10で、5人同時出撃のLv40・Lv100呪術師ビルドを撮影し、他職の演出と重なる状態を確認。
- エフェクトON/OFFでダメージが一致。戦闘数値は従来仕様を使用する。

検証コマンドは `node tools/verify/verify-shaman-fx.cjs` と `node tools/verify/verify-shaman-ui.cjs`。変更前の画像は `output/shaman-fx-upgrade/before/`、変更後・混戦の画像と測定結果は `output/shaman-fx-upgrade/after/`。
