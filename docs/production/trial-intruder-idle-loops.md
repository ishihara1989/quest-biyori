# 試練追加敵：左向き待機ループの制作と検収

2026-10-24 JST。11体の待機素材候補。本編未登録。[素材・全文プロンプト](../../development/assets/trial-intruders/idle-v1/README.md) ／ [検収画面](../../development/labs/trial-intruder-idles.html)

## 範囲と基準

ユーザーが選択したSFデザインを基準に、通常10地域の大ボス戦用追加敵10体と、転生の女神の後に登場予定の外宇宙の女神1体の左向き待機を制作した。遺跡は女形の記録官、玉座は女王型機械の修正版を使用。女神は追加指示で全身の向きを左へ統一し、瞳を淡い氷紫色と艶・発光感のある表現へ変更した。

攻撃・移動・被弾・撃破などの追加モーション、本編の敵定義、進行、能力、報酬、保存は変更していない。

## 生成と配置

組み込み ImageGen を使用。生成前に全11体の基準位置と4コマの動き、接地／浮遊、4→1のつながりを plan.json へ記録した。1体ごとに同じ固定参照を使い、4コマ単位で生成した。接地型は脚を運ばず、浮遊型は上下動と付属部品の小さな揺れを基本とする。歩行ではないため四足trotは制作しない。

女神は先行版の胴体のねじれと濃い目を追加指示に合わせて作り直し、修正した全身参照から4コマを生成。氷河の初回は正面寄りだったため、コア・前側装甲を左に向けた立体表現へ修正。原画・不採用理由・全文プロンプトを generation.json に保持した。

最終採用は11体・43枚。高原は原画4の翼の動きが大きいため、中間姿勢を通る1→2→3→4→3→2。氷河は原画2で結晶が重なるため、このコマを外した3枚で1→2→3→2。残り9体は4枚を順に再生する。全体を1.44秒周期に揃え、個別GIFと全体一覧GIFの末尾も同じ周期で接続する。

node tools/assets/build-trial-intruder-idles.cjs は透明な区間を実測して原画を切り出し、敵ごとに共通倍率の最近傍拡縮と平行移動で512×512へ配置する。RGBAは保持し、色・アルファの閾値加工や反転・手描き補完は行わない。閾値32は見切れ・実測範囲の判定にだけ用いる。位置合わせの代理基準と計画値は registration.json に分けて記録した。
