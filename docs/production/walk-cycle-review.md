# 8枚の歩行・後退 再制作基準（2026-10-06）

ユーザーの追加指示により全6人の前進・後退を再生成する。前回の「近脚・遠脚が入れ替わる」という表現は誤り。画面内の前後（x）は変わるが、カメラに対する左右の脚の奥行きと装備は変わらない。

## 固定した足のIDとカメラ

- 解剖学的左脚=L、右脚=R。画面の左端にある脚を「左脚」と呼ばない。
- 今回の右向き3/4ビューではLを手前、Rを奥に固定。歩行半周期でもカメラを変えない。交差時はLがRを遮蔽する。
- 忍者: Lは網タイツ＋金バックルの脚、Rは素肌＋黒帯の脚。8枚すべて同じ。前進8・後退1/8の既存の入れ替わりを必ず修正。meshのある脚を奥に移さない。
- 呪術師: Lは素肌に白い紋様＋固有の金/緑装具がある脚、Rは暗い脚衣を着た脚。白い紋様や装具がもう一方の脚へ移らない。
- 他4人も足IDを固定。靴のつま先は全コマ右。装備の持ち側・顔・髪・体格・カメラは待機基準。

## 連続した8相

必ず1→2→3→4→5→6→7→8→1。1と5は同じ脚のコピーではなく反対の足が前にある。

| コマ | L（固定した左脚、手前） | R（固定した右脚、奥） |
| --- | --- | --- |
| 1 | 体より右/前で接地 | 体より左/後ろ、つま先接地 |
| 2 | 前から体下へ戻る、荷重 | 後ろから体下へ戻る、足を小さく上げる |
| 3 | 体下で接地し支持 | 体下でLの後ろを通過、足首のxがほぼ重なる |
| 4 | 体下から左/後ろへ、踵を上げる | 体下から右/前へ送り、低い位置で伸ばす |
| 5 | 左/後ろ、つま先/離地 | 右/前で接地 |
| 6 | 後ろから体下へ戻る、足を小さく上げる | 前から体下へ戻る、荷重 |
| 7 | 体下でRの前を通過、足首のxがほぼ重なる | 体下で接地し支持 |
| 8 | 右/前へ伸ばし、1の接地直前 | 左/後ろへ、踵を上げる |

足の水平位置は跳ばず、連続した弧を描く。3/7は足が大きく左右に開いた姿勢や高い膝蹴りにしない。クロスとは自然な通過と遮蔽であり、膝関節をX字にねじらない。8→1は特に足の位置、奥行き、装備、腰位置が連続する。

後退も1=L前、5=R前の8相と足IDを保持し、歩幅を小さくして右への視線・胸前の守りを維持。前進と別原画を生成する。

## 作業・確認

組み込みimage_genを使用。各motionに4列×2行の本物の8姿勢を作り、新版原画として保存。旧版は保持。使用した生成/修正の全文をPROMPT.mdに記録する。切り出し・最近傍・背景合成によるQA以外でコードから姿勢を再描画/複製/補間しない。

view_imageで透明部分のhidden RGBが見えることがある。背景の問題はRGBA alphaを調べ、sharp.flattenで確認してから判断する。セル分割で装備が切れる場合は透明ガターへmanual rectを設定。

腰を基準に位置合わせし、1コマ256×224、pivot(128,207)、横8コマ2048×224、前進80ms×8、後退90ms×8を維持する。

各motion/QA.mdに8コマすべてのL/R位置・脚装備・交差時の遮蔽と8→1の所見を記録。足IDと装備が維持される根拠を、少なくとも1/3/5/7/8を拡大したQA画像で示す。姿勢が要件を外れるなら再生成してから採用する。機械検査が通るだけで合格にしない。
